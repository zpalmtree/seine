seine menambang Blocknet dengan GPU NVIDIA bersama CPU Anda. Panduan ini membahas penyiapan Windows dan Linux, pemilihan kartu, share yang diterima, serta perbandingan terukur dengan RTX 5090. Perintahnya berlaku untuk seine v0.3.0 dan jaringan Argon2id saat ini per Oktober 2026.

## Bagaimana cara mulai menambang Blocknet dengan GPU NVIDIA?

<Answer>
Unduh arsip seine untuk Windows x86_64 atau Linux x86_64, siapkan driver NVIDIA dan pustaka runtime untuk platform Anda, lalu jalankan penambang. Masukkan alamat pembayaran dan terima pool bawaan. seine otomatis memilih CPU dan kartu NVIDIA yang terdeteksi, kemudian menyiapkan serta menyetel setiap backend GPU.
</Answer>

Pilih arsip di [bagian unduhan](/id/#download): `seine-windows-x86_64.zip` untuk Windows atau `seine-linux-x86_64.tar.gz` untuk Linux x86_64. [Panduan umum penambangan](/id/blog/how-to-mine-blocknet/) menjelaskan cara mendapatkan alamat pembayaran dan membuat koneksi pertama.

Mulailah dengan pengaturan bawaan. Jangan atur kernel, batas register, jumlah lane GPU, dan jumlah thread CPU agar seine dapat memilih konfigurasinya. Panel Devices menunjukkan backend yang berkontribusi setelah inisialisasi selesai.

## Menyiapkan runtime NVIDIA di Windows atau Linux

| Platform | Yang perlu disiapkan | Perintah mulai |
|---|---|---|
| Windows x86_64 | Driver tampilan NVIDIA; DLL runtime bawaan di samping berkas program | `.\seine.exe` |
| Linux x86_64 | driver NVIDIA | `./seine` |

Di Windows, ekstrak seluruh ZIP ke folder yang dapat ditulisi. Simpan `nvrtc64_120_0.dll` dan `nvrtc-builtins64_128.dll` di samping `seine.exe`. Rilis dalam paket menggunakan pustaka bawaan ini; instalasi CUDA Toolkit terpisah tidak diperlukan.

![Arsip Windows dalam tabel unduhan resmi seine](/assets/blog/windows-download.png)

Instal driver untuk kartu dan sistem operasi Anda dari [halaman driver NVIDIA](https://www.nvidia.com/en-us/drivers/). [Panduan penyiapan Windows](/id/blog/mine-blocknet-on-windows/) menjelaskan langkah unduhan, checksum, dan ekstraksi.

Di Linux, driver NVIDIA sudah cukup. Seine memakai NVRTC jika terpasang dan jika tidak, memuat kernel bawaan seine, yang mencakup kartu GeForce seri GTX 10 dan yang lebih baru. [Persyaratan NVIDIA seine](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) memuat detailnya.

Jalankan berkas biner dari foldernya. Gunakan kembali direktori kerja yang sama agar pengaturan tersimpan tetap berada di `seine-data`. Pada peluncuran pertama, masukkan alamat penerimaan Anda dan terima `stratum+tcp://bntpool.com:3333` sebagai pool.

## Bisakah memilih satu kartu NVIDIA sambil tetap menambang dengan CPU?

Pilih kedua backend dan indeks perangkat. Di PowerShell, perintah ini mempertahankan penambangan CPU dan memilih perangkat NVIDIA `0`:

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

Gunakan opsi yang sama dengan program Linux:

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

Perintah ini menggunakan alamat dan pool yang tersimpan atau memintanya saat program dimulai. Untuk menentukan koneksi secara eksplisit, tambahkan alamat penerimaan publik dengan `--address` dan URL pool dengan `--pool-url`.

Indeks mengidentifikasi GPU yang didaftarkan oleh runtime NVIDIA. Pastikan daftar perangkat sudah benar setelah program dimulai. `--nvidia-devices 0,1` memilih kedua kartu tersebut; tanpa pemilih ini, semua perangkat NVIDIA yang terdeteksi akan digunakan.

Untuk menambang hanya dengan GPU, pilih `nvidia`:

```bash
./seine --backend nvidia
```

Di PowerShell, gunakan `.\seine.exe --backend nvidia`. Sertakan `cpu` dalam daftar backend jika ingin menggunakan kedua jenis perangkat keras. Mulai ulang seine dengan perintah yang diinginkan ketika mengubah pilihan tersebut.

## Bagaimana memastikan GPU sedang menambang?

<Answer>
Lihat baris backend NVIDIA di panel Devices beserta hashrate saat ini dan rata-ratanya. Selama inisialisasi, suatu baris dapat menampilkan kemajuan saat kernel CUDA disiapkan. Setelah penghitungan hash dimulai, periksa log untuk peristiwa share dari backend tersebut dan panel Mining untuk share yang diterima.
</Answer>

Backend NVIDIA tampil sebagai `nvidia#1`, `nvidia#2`, dan seterusnya; CPU memiliki baris tersendiri. Hashrate keseluruhan mencakup semua backend aktif. [Panduan dasbor](/id/blog/seine-dashboard-explained/) menjelaskan panel lainnya dan label log.

![Sesi seine nyata dengan RTX 5090, hashrate perangkat, dan share yang diterima](/assets/blog/nvidia-rtx5090-session.png)

Tangkapan ini menunjukkan sesi pool langsung dengan RTX 5090. Benchmark berwaktu di bawah dijalankan secara terpisah. Hashrate perangkat mengukur aktivitas lokal; share yang diterima mengonfirmasi bahwa pool mengkreditkan pekerjaan yang dikirim. Ikuti pekerjaan yang dikreditkan dengan [panduan pelacakan penambang](https://bntpool.com/blog/track-your-miner-on-bntpool/).

Peluncuran pertama menyiapkan dan menyetel kernel GPU. seine menyimpan hasil penyetelan otomatis NVIDIA di `seine-data/seine.nvidia-autotune.json`. Gunakan kembali direktori data tersebut agar peluncuran berikutnya dapat memuat hasil tersimpan yang kompatibel, atau pilih direktori secara eksplisit dengan `--data-dir`.

## Seberapa cepat RTX 5090 dalam pengujian kami?

Diukur pada 31 Oktober 2026: hanya RTX 5090, Windows 11 native, driver 610.88, build pengembangan publik. Hashrate stabil sudah memperhitungkan biaya miner; kerja CPU tidak disertakan.

| Mode | Rata-rata H/s |
|---|---|
| RTX 5090 saja | 13,8 |

## Apa yang perlu diperiksa jika baris NVIDIA tidak muncul?

Periksa driver terlebih dahulu. Di Windows, simpan juga DLL NVRTC bawaan di samping `seine.exe`. Di Linux, instal driver NVIDIA di lingkungan tempat Anda menjalankan miner.

Kemudian periksa perintah Anda. `--backend cpu` hanya memilih CPU. Gunakan perintah bawaan atau `--backend cpu,nvidia` untuk keduanya. Jika menetapkan `--nvidia-devices`, pastikan indeks tersebut ada di komputer Anda.

Baca log awal backend tersebut: log membedakan persiapan yang masih berjalan dengan kesalahan inisialisasi. Perbaiki masalah runtime atau pemilihan yang dilaporkan, lalu mulai ulang. [Panduan NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) juga membahas persyaratan kompilasi dari kode sumber.

Untuk beban Argon2id saat ini, setiap lane GPU aktif membutuhkan area 2 GiB ditambah kebutuhan tambahan runtime. seine menentukan ukuran pekerjaan GPU berdasarkan memori perangkat yang tersedia dan pemeriksaan alokasi. Biarkan pengaturan manual lane tidak ditetapkan; kapasitas VRAM yang diiklankan saja tidak menentukan jumlah lane yang tersedia selama sesi desktop.

Jika perangkat menghitung hash tetapi pool menunjukkan nol, ikuti [daftar pemeriksaan hashrate pool](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate) untuk memeriksa alamat, koneksi, dan share yang diterima.
