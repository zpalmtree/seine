seineはCPUとともにNVIDIA GPUでもBlocknetをマイニングします。このガイドでは、WindowsとLinuxの設定、カードの選択、受理されたシェアの確認、RTX 5090での実測比較を解説します。コマンドはseine v0.3.0と、2026年10月時点のArgon2idネットワークに基づいています。

## NVIDIA GPUでBlocknetのマイニングを始めるには？

<Answer>
Windows x86_64またはLinux x86_64向けのseineアーカイブをダウンロードし、使用する環境に合わせてNVIDIAドライバーとランタイムライブラリを準備して、マイナーを実行します。支払い先アドレスを入力し、既定のプールを選んでください。seineはCPUと検出されたNVIDIAカードを自動的に選択し、各GPUバックエンドの準備と調整を行います。
</Answer>

[ダウンロード欄](/ja/#download)で、Windowsなら`seine-windows-x86_64.zip`、Linux x86_64なら`seine-linux-x86_64.tar.gz`を選んでください。支払い先アドレスの取得と初回接続については、[基本のマイニングガイド](/ja/blog/how-to-mine-blocknet/)で解説しています。

まずは既定の設定を使いましょう。カーネル、レジスタ上限、GPUレーン数、CPUスレッド数は指定せず、seineに構成を選ばせます。初期化が終わると、Devicesパネルでどのバックエンドが動作しているか確認できます。

## WindowsまたはLinuxでNVIDIAランタイムを準備する

| プラットフォーム | 準備するもの | 起動コマンド |
|---|---|---|
| Windows x86_64 | NVIDIAディスプレイドライバー、実行ファイルと同じフォルダーに置く同梱ランタイムDLL | `.\seine.exe` |
| Linux x86_64 | NVIDIAドライバー | `./seine` |

Windowsでは、書き込み可能なフォルダーにZIP全体を展開します。`nvrtc64_120_0.dll`と`nvrtc-builtins64_128.dll`は、`seine.exe`と同じフォルダーに置いてください。配布済みのリリースはこれらの同梱ライブラリを使用するため、CUDA Toolkitを別途インストールする必要はありません。

![seine公式ダウンロード表に表示されたWindowsアーカイブ](/assets/blog/windows-download.png)

[NVIDIAのドライバーページ](https://www.nvidia.com/en-us/drivers/)から、カードとOSに合ったドライバーをインストールしてください。[Windows設定ガイド](/ja/blog/mine-blocknet-on-windows/)では、ダウンロード、チェックサムの確認、展開の手順を説明しています。

LinuxではNVIDIAドライバーがあれば十分です。seineはNVRTCがインストールされていればそれを使い、なければseineに組み込まれたカーネルを読み込みます。これはGeForce GTX 10 series以降のカードに対応しています。詳細は[seineのNVIDIA要件](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)をご覧ください。

実行ファイルがあるフォルダーから起動してください。同じ作業ディレクトリを使い続けると、`seine-data`に保存した設定を維持できます。初回起動時には受取アドレスを入力し、プールに`stratum+tcp://bntpool.com:3333`を選びます。

## NVIDIAカードを1枚選び、CPUのマイニングも続けられますか？

両方のバックエンドとデバイスインデックスを指定します。PowerShellでは、次のコマンドでCPUのマイニングを続けながらNVIDIAデバイス`0`を選択できます。

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

Linuxの実行ファイルでも同じオプションを使います。

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

これらのコマンドは保存済みのアドレスとプールを使用し、未設定なら起動時に入力を求めます。接続先を明示するには、`--address`で公開の受取アドレスを、`--pool-url`でプールのURLを指定してください。

インデックスは、NVIDIAランタイムが列挙するGPUを識別します。起動後にデバイス一覧を確認してください。`--nvidia-devices 0,1`はその2枚のカードを選択します。この選択オプションを省略すると、検出されたすべてのNVIDIAデバイスを使用します。

GPUのみでマイニングするには、`nvidia`を選びます。

```bash
./seine --backend nvidia
```

PowerShellでは`.\seine.exe --backend nvidia`を使います。両方のハードウェアを使用する場合は、バックエンド一覧に`cpu`も含めてください。選択を変更するときは、目的のコマンドでseineを再起動します。

## GPUがマイニングしていることを確認するには？

<Answer>
DevicesパネルでNVIDIAバックエンドの行を探し、現在と平均のハッシュレートを確認します。初期化中はCUDAカーネルの準備に合わせて起動の進捗が表示される場合があります。ハッシュ計算が始まったら、ログでそのバックエンドのシェアイベントを、Miningパネルで受理されたシェアを確認してください。
</Answer>

NVIDIAバックエンドは`nvidia#1`、`nvidia#2`などと表示され、CPUには独立した行があります。全体のハッシュレートには、稼働中のすべてのバックエンドが含まれます。[ダッシュボードガイド](/ja/blog/seine-dashboard-explained/)では、その他のパネルとログのラベルについて説明しています。

![RTX 5090を使用した実際のseineセッション。デバイスのハッシュレートと受理済みシェアを表示](/assets/blog/nvidia-rtx5090-session.png)

この画像は、RTX 5090で実際にプールへ接続しているセッションです。以下の時間を定めたベンチマークは別途実行しました。デバイスのハッシュレートはローカルの動作を測る指標であり、受理されたシェアは送信した作業がプールに計上されたことを示します。計上された作業は、[マイナー追跡ガイド](https://bntpool.com/blog/track-your-miner-on-bntpool/)に沿って確認できます。

初回起動時にはGPUカーネルの準備と調整が行われます。seineはNVIDIAの自動調整結果を`seine-data/seine.nvidia-autotune.json`に保存します。このデータディレクトリを再利用すると、次回以降の起動で互換性のある保存結果を読み込めます。`--data-dir`でディレクトリを明示的に指定することもできます。

## テストでのRTX 5090の速度は？

2026年10月31日測定。RTX 5090単体、ネイティブのWindows 11、ドライバー610.88、公開開発ビルドを使用。安定時のマイニング速度はマイナー手数料控除後の値で、CPUの処理は含みません。

| モード | 平均 H/s |
|---|---|
| RTX 5090のみ | 13.8 |

## NVIDIAの行が表示されないときは何を確認しますか？

まずドライバーを確認してください。Windowsでは、付属のNVRTC DLLも `seine.exe` と同じフォルダーに置いておきます。Linuxでは、マイナーを起動する環境にNVIDIAドライバーをインストールします。

次にコマンドを確認します。`--backend cpu`はCPUのみを選択します。両方を使うには、既定のコマンドか`--backend cpu,nvidia`を使用します。`--nvidia-devices`を指定した場合は、そのインデックスが使用中のマシンに存在することを確認してください。

該当するバックエンドの起動ログを読んでください。準備の途中なのか、初期化エラーが起きたのかを区別できます。報告されたランタイムやデバイス選択の問題を修正し、再起動します。[NVIDIAガイド](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)には、ソースからビルドする場合の要件も記載されています。

現在のArgon2idの処理では、稼働するGPUレーンごとに2 GiBのメモリ領域とランタイムの追加メモリが必要です。seineは、利用可能なデバイスメモリとメモリ割り当ての確認結果に基づいてGPUの作業量を決めます。レーン数は手動で上書きせずに使用してください。公称VRAM容量だけでは、デスクトップを使用している間に利用できるレーン数は決まりません。

デバイスがハッシュを計算しているのにプールがゼロと表示する場合は、[プールのハッシュレート確認リスト](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate)に沿って、アドレス、接続、受理されたシェアを確認してください。
