Seine mina Blocknet con tu GPU NVIDIA junto con la CPU. Esta guía explica la configuración en Windows y Linux, la selección de tarjetas, los shares aceptados y una comparación medida con una RTX 5090. Los comandos corresponden a seine v0.3.0 y a la red Argon2id actual en octubre de 2026.

## ¿Cómo empezar a minar Blocknet con una GPU NVIDIA?

<Answer>
Descarga el archivo de seine para Windows x86_64 o Linux x86_64, prepara el controlador NVIDIA y las bibliotecas de ejecución para tu plataforma e inicia el minero. Introduce tu dirección de pago y acepta el pool predeterminado. Seine selecciona automáticamente la CPU y las tarjetas NVIDIA detectadas, y prepara y ajusta cada backend GPU.
</Answer>

Elige tu archivo en la [sección de descargas](/es/#download): `seine-windows-x86_64.zip` para Windows o `seine-linux-x86_64.tar.gz` para Linux x86_64. La [guía general de minería](/es/blog/how-to-mine-blocknet/) explica cómo obtener una dirección de pago y conectarte por primera vez.

Empieza con los valores predeterminados. Deja sin configurar el kernel, el límite de registros, el número de lanes GPU y los hilos de CPU para que seine elija la configuración. El panel Devices muestra qué backends contribuyen al terminar la inicialización.

## Preparar el entorno NVIDIA en Windows o Linux

| Plataforma | Qué preparar | Comando de inicio |
|---|---|---|
| Windows x86_64 | Controlador de pantalla NVIDIA; DLL de ejecución incluidas junto al ejecutable | `.\seine.exe` |
| Linux x86_64 | driver de NVIDIA | `./seine` |

En Windows, extrae todo el ZIP en una carpeta con permisos de escritura. Conserva `nvrtc64_120_0.dll` y `nvrtc-builtins64_128.dll` junto a `seine.exe`. La versión empaquetada usa estas bibliotecas incluidas; no requiere instalar CUDA Toolkit por separado.

![El archivo de Windows en la tabla oficial de descargas de seine](/assets/blog/windows-download.png)

Instala el controlador de tu tarjeta y sistema operativo desde la [página de controladores NVIDIA](https://www.nvidia.com/en-us/drivers/). La [guía de Windows](/es/blog/mine-blocknet-on-windows/) detalla la descarga, la suma de comprobación y la extracción.

En Linux, el driver de NVIDIA basta. Seine usa NVRTC cuando está instalado y, si no, carga los kernels incluidos en seine, que cubren las tarjetas GeForce de la serie GTX 10 y posteriores. Los [requisitos de NVIDIA de seine](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) dan los detalles.

Ejecuta el binario desde su carpeta. Reutiliza el mismo directorio de trabajo para conservar los ajustes guardados en `seine-data`. En el primer inicio, introduce tu dirección de recepción y acepta `stratum+tcp://bntpool.com:3333` como pool.

## ¿Puedes seleccionar una tarjeta NVIDIA y mantener la minería con CPU?

Selecciona ambos backends y el índice del dispositivo. En PowerShell, esto mantiene la CPU y selecciona el dispositivo NVIDIA `0`:

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

Usa las mismas opciones con el ejecutable de Linux:

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

Estos comandos usan la dirección y el pool guardados o los solicitan al iniciar. Para indicar la conexión explícitamente, añade tu dirección pública de recepción con `--address` y la URL del pool con `--pool-url`.

El índice identifica una GPU enumerada por el entorno NVIDIA. Confirma la lista de dispositivos tras iniciar. `--nvidia-devices 0,1` selecciona esas dos tarjetas; omitir el selector usa todas las GPU NVIDIA detectadas.

Para minar solo con GPU, selecciona `nvidia`:

```bash
./seine --backend nvidia
```

En PowerShell, usa `.\seine.exe --backend nvidia`. Incluye `cpu` en la lista de backends si quieres ambos tipos de hardware. Reinicia seine con el comando deseado al cambiar esta selección.

## ¿Cómo confirmar que la GPU está minando?

<Answer>
Busca las filas de backends NVIDIA en Devices y comprueba sus hashrates actuales y medios. Durante la inicialización, una fila puede mostrar el progreso mientras se preparan los kernels CUDA. Cuando empiece a calcular hashes, busca eventos de shares de ese backend en el registro y shares aceptados en el panel Mining.
</Answer>

Los backends NVIDIA aparecen como `nvidia#1`, `nvidia#2`, etc.; la CPU tiene su propia fila. El hashrate total incluye todos los backends activos. La [guía del panel](/es/blog/seine-dashboard-explained/) explica los demás paneles y etiquetas del registro.

![Una sesión real de seine con una RTX 5090, hashrates por dispositivo y shares aceptados](/assets/blog/nvidia-rtx5090-session.png)

Esta captura muestra una sesión real en el pool con la RTX 5090. Las pruebas cronometradas de abajo se realizaron por separado. El hashrate de un dispositivo mide actividad local; un share aceptado confirma que el pool acreditó el trabajo enviado. Consulta ese trabajo con la [guía de seguimiento del minero](https://bntpool.com/blog/track-your-miner-on-bntpool/).

El primer inicio prepara y ajusta los kernels GPU. Seine guarda los resultados del ajuste NVIDIA en `seine-data/seine.nvidia-autotune.json`. Reutiliza ese directorio para cargar resultados guardados compatibles en futuros inicios, o elige uno explícitamente con `--data-dir`.

## ¿Qué comprobar si falta una fila NVIDIA?

Comprueba primero el driver. En Windows, mantén además las DLL de NVRTC incluidas junto a `seine.exe`. En Linux, instala el driver de NVIDIA en el entorno desde el que inicias el minero.

Revisa después el comando. `--backend cpu` selecciona solo la CPU. Usa el comando predeterminado o `--backend cpu,nvidia` para ambos. Si indicas `--nvidia-devices`, verifica que los índices existan en tu equipo.

Lee el registro de inicio de ese backend: distingue una preparación en curso de un error de inicialización. Corrige el problema de entorno o selección indicado y reinicia. La [guía NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) también cubre los requisitos para compilar desde el código fuente.

En la carga Argon2id actual, cada lane GPU activo necesita un área de 2 GiB más la memoria adicional de ejecución. Seine dimensiona el trabajo GPU según la memoria disponible y las comprobaciones de asignación. Deja los lanes sin modificar; la VRAM anunciada por sí sola no determina cuántos están disponibles durante una sesión de escritorio.

Si el dispositivo calcula hashes pero el pool muestra cero, sigue la [lista de comprobación del hashrate del pool](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate) para revisar dirección, conexión y shares aceptados.
