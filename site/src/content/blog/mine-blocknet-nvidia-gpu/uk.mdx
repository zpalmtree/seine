seine майнить Blocknet на GPU NVIDIA разом із CPU. Цей посібник описує налаштування Windows і Linux, вибір відеокарт, прийняті шари та порівняння режимів на RTX 5090 за результатами вимірювань. Команди стосуються seine v0.3.0 і поточної мережі Argon2id станом на жовтень 2026 року.

## Як почати майнити Blocknet на GPU NVIDIA?

<Answer>
Завантажте архів seine для Windows x86_64 або Linux x86_64, підготуйте драйвер NVIDIA та бібліотеки середовища виконання для своєї платформи й запустіть майнер. Введіть адресу для виплат і прийміть типовий пул. seine автоматично вибере CPU та виявлені відеокарти NVIDIA, а потім підготує й налаштує кожен бекенд GPU.
</Answer>

Виберіть архів у [розділі завантажень](/uk/#download): `seine-windows-x86_64.zip` для Windows або `seine-linux-x86_64.tar.gz` для Linux x86_64. [Загальний посібник із майнінгу](/uk/blog/how-to-mine-blocknet/) описує отримання адреси для виплат і перше підключення.

Почніть із типових налаштувань. Не задавайте обчислювальне ядро, обмеження регістрів, кількість ліній GPU та потоків CPU, щоб seine самостійно вибрав конфігурацію. Після завершення ініціалізації панель Devices покаже, які бекенди працюють.

## Підготуйте середовище NVIDIA у Windows або Linux

| Платформа | Що підготувати | Команда запуску |
|---|---|---|
| Windows x86_64 | Драйвер NVIDIA; DLL середовища виконання з архіву поруч із виконуваним файлом | `.\seine.exe` |
| Linux x86_64 | драйвер NVIDIA | `./seine` |

У Windows розпакуйте весь ZIP у папку з дозволом на запис. Залиште `nvrtc64_120_0.dll` і `nvrtc-builtins64_128.dll` поруч із `seine.exe`. Готова збірка використовує ці бібліотеки з архіву; окремо встановлювати CUDA Toolkit не потрібно.

![Архів Windows в офіційній таблиці завантажень seine](/assets/blog/windows-download.png)

Установіть драйвер для своєї відеокарти й операційної системи зі [сторінки драйверів NVIDIA](https://www.nvidia.com/en-us/drivers/). [Посібник із налаштування Windows](/uk/blog/mine-blocknet-on-windows/) покроково описує завантаження, перевірку контрольної суми та розпакування.

У Linux достатньо драйвера NVIDIA. Seine використовує NVRTC, якщо він установлений, а інакше завантажує ядра, вбудовані в seine, які підтримують GeForce GTX 10 series і новіші карти. Подробиці є у [вимогах seine до NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md).

Запускайте виконуваний файл із його папки. Використовуйте ту саму робочу папку, щоб зберігати налаштування в `seine-data`. Під час першого запуску введіть адресу отримання й прийміть `stratum+tcp://bntpool.com:3333` як адресу пула.

## Чи можна вибрати одну відеокарту NVIDIA і зберегти майнінг на CPU?

Виберіть обидва бекенди та індекс пристрою. У PowerShell ця команда зберігає майнінг на CPU й вибирає пристрій NVIDIA `0`:

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

У Linux використовуйте ті самі параметри з відповідним виконуваним файлом:

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

Ці команди використовують збережені адресу та пул або запитують їх під час запуску. Щоб явно задати підключення, додайте публічну адресу отримання через `--address`, а URL пула — через `--pool-url`.

Індекс позначає GPU в переліку пристроїв середовища NVIDIA. Перевірте список після запуску. `--nvidia-devices 0,1` вибирає ці дві відеокарти; без параметра вибору використовуються всі виявлені пристрої NVIDIA.

Для майнінгу лише на GPU виберіть `nvidia`:

```bash
./seine --backend nvidia
```

У PowerShell використовуйте `.\seine.exe --backend nvidia`. Додайте `cpu` до списку бекендів, якщо хочете використовувати обидва типи обладнання. Змінюючи цей вибір, перезапустіть seine з потрібною командою.

## Як переконатися, що GPU майнить?

<Answer>
Знайдіть рядки бекендів NVIDIA на панелі Devices і перевірте їхній поточний та середній хешрейт. Під час ініціалізації рядок може показувати перебіг запуску, поки готуються ядра CUDA. Коли почнеться обчислення хешів, перевіряйте журнал на наявність подій із шарами цього бекенда, а панель Mining — на наявність прийнятих шар.
</Answer>

Бекенди NVIDIA позначаються як `nvidia#1`, `nvidia#2` тощо; CPU має власний рядок. Загальний хешрейт включає всі активні бекенди. [Посібник із панелі майнера](/uk/blog/seine-dashboard-explained/) пояснює решту панелей і позначення в журналі.

![Реальний сеанс seine з RTX 5090, хешрейтом пристроїв і прийнятими шарами](/assets/blog/nvidia-rtx5090-session.png)

Цей знімок показує реальний сеанс роботи з пулом на RTX 5090. Наведені нижче тести з вимірюванням часу виконувалися окремо. Хешрейт пристрою вимірює локальну роботу; прийнята шара підтверджує, що пул зарахував надіслану роботу. Відстежуйте її за допомогою [посібника зі спостереження за майнером](https://bntpool.com/blog/track-your-miner-on-bntpool/).

Перший запуск готує й налаштовує ядра GPU. seine зберігає результати автоналаштування NVIDIA у `seine-data/seine.nvidia-autotune.json`. Використовуйте цю папку даних, щоб наступні запуски завантажували сумісні збережені результати, або явно виберіть папку через `--data-dir`.

## Яку швидкість показала RTX 5090 у нашому тесті?

Виміряно 31 жовтня 2026 року: лише RTX 5090, нативна Windows 11, драйвер 610.88, публічна збірка для розробки. Стабільний хешрейт наведено після комісії майнера; робота CPU не врахована.

| Режим | Середнє H/s |
|---|---|
| Лише RTX 5090 | 13,8 |

## Що перевірити, якщо рядок NVIDIA відсутній?

Спершу перевірте драйвер. У Windows також тримайте постачані DLL NVRTC поруч із `seine.exe`. У Linux установіть драйвер NVIDIA в тому середовищі, з якого запускаєте майнер.

Потім перевірте команду. `--backend cpu` вибирає лише CPU. Використовуйте типову команду або `--backend cpu,nvidia` для обох типів обладнання. Якщо ви задали `--nvidia-devices`, переконайтеся, що такі індекси є на вашому комп'ютері.

Прочитайте журнал запуску цього бекенда: він дає змогу відрізнити підготовку, що ще триває, від помилки ініціалізації. Виправте зазначену проблему середовища виконання або вибору пристроїв і перезапустіть майнер. [Посібник для NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) також описує вимоги до збирання з вихідного коду.

Для поточного навантаження Argon2id кожній активній лінії GPU потрібна область пам'яті розміром 2 GiB плюс додаткові витрати середовища виконання. seine визначає обсяг роботи GPU за доступною пам'яттю пристрою та перевірками виділення пам'яті. Не задавайте кількість ліній вручну: лише заявлений обсяг VRAM не визначає, скільки ліній доступно під час роботи за комп'ютером.

Якщо пристрій обчислює хеші, а пул показує нуль, пройдіть [перевірки хешрейту пула](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate), щоб перевірити адресу, підключення та прийняті шари.
