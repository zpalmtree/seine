seine ขุด Blocknet ด้วย GPU NVIDIA ควบคู่กับ CPU คู่มือนี้ครอบคลุมการตั้งค่า Windows และ Linux การเลือกการ์ด แชร์ที่ได้รับการยอมรับ และการเปรียบเทียบจากการวัดด้วย RTX 5090 คำสั่งต่าง ๆ อ้างอิง seine v0.3.0 และเครือข่าย Argon2id ปัจจุบัน ณ เดือนตุลาคม ค.ศ. 2026

## จะเริ่มขุด Blocknet ด้วย GPU NVIDIA ได้อย่างไร?

<Answer>
ดาวน์โหลดไฟล์บีบอัด seine สำหรับ Windows x86_64 หรือ Linux x86_64 เตรียมไดรเวอร์ NVIDIA และไลบรารีรันไทม์สำหรับแพลตฟอร์มของคุณ แล้วเปิดโปรแกรมขุด ป้อนที่อยู่รับเงินและยอมรับพูลเริ่มต้น seine จะเลือก CPU และการ์ด NVIDIA ที่ตรวจพบโดยอัตโนมัติ จากนั้นเตรียมและปรับแต่งแบ็กเอนด์ GPU แต่ละตัว
</Answer>

เลือกไฟล์ใน[ส่วนดาวน์โหลด](/th/#download): `seine-windows-x86_64.zip` สำหรับ Windows หรือ `seine-linux-x86_64.tar.gz` สำหรับ Linux x86_64 [คู่มือการขุดทั่วไป](/th/blog/how-to-mine-blocknet/) อธิบายการเตรียมที่อยู่รับเงินและการเชื่อมต่อครั้งแรก

เริ่มจากค่าเริ่มต้น โดยไม่กำหนดเคอร์เนล เพดานรีจิสเตอร์ จำนวนเลน GPU และจำนวนเธรด CPU เพื่อให้ seine เลือกการตั้งค่าเอง แผง Devices จะแสดงว่าแบ็กเอนด์ใดกำลังช่วยขุดเมื่อการเตรียมเริ่มต้นเสร็จสมบูรณ์

## เตรียมรันไทม์ NVIDIA บน Windows หรือ Linux

| แพลตฟอร์ม | สิ่งที่ต้องเตรียม | คำสั่งเริ่มทำงาน |
|---|---|---|
| Windows x86_64 | ไดรเวอร์จอแสดงผล NVIDIA และไฟล์ DLL รันไทม์ที่ให้มา วางไว้ข้างไฟล์โปรแกรม | `.\seine.exe` |
| Linux x86_64 | ไดรเวอร์ NVIDIA | `./seine` |

บน Windows ให้แตกไฟล์ ZIP ทั้งหมดลงในโฟลเดอร์ที่เขียนข้อมูลได้ เก็บ `nvrtc64_120_0.dll` และ `nvrtc-builtins64_128.dll` ไว้ข้าง `seine.exe` รุ่นที่จัดชุดมาให้ใช้ไลบรารีเหล่านี้ จึงไม่จำเป็นต้องติดตั้ง CUDA Toolkit แยกต่างหาก

![ไฟล์บีบอัด Windows ในตารางดาวน์โหลดอย่างเป็นทางการของ seine](/assets/blog/windows-download.png)

ติดตั้งไดรเวอร์ที่ตรงกับการ์ดและระบบปฏิบัติการของคุณจาก[หน้าดาวน์โหลดไดรเวอร์ NVIDIA](https://www.nvidia.com/en-us/drivers/) [คู่มือตั้งค่า Windows](/th/blog/mine-blocknet-on-windows/) อธิบายขั้นตอนดาวน์โหลด ตรวจสอบเช็กซัม และแตกไฟล์

บน Linux แค่มีไดรเวอร์ NVIDIA ก็พอ seine จะใช้ NVRTC เมื่อติดตั้งไว้ และหากไม่มีก็จะโหลดเคอร์เนลที่ฝังอยู่ใน seine ซึ่งรองรับการ์ด GeForce GTX 10 series และใหม่กว่า ดูรายละเอียดได้ใน[ข้อกำหนด NVIDIA ของ seine](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)

เปิดไฟล์โปรแกรมจากโฟลเดอร์ของมัน ใช้ไดเรกทอรีทำงานเดิมเพื่อเก็บการตั้งค่าที่บันทึกไว้ใน `seine-data` เมื่อเปิดครั้งแรก ให้ป้อนที่อยู่รับเงินและยอมรับ `stratum+tcp://bntpool.com:3333` เป็นพูล

## เลือกการ์ด NVIDIA ใบเดียวและยังขุดด้วย CPU ได้หรือไม่?

เลือกแบ็กเอนด์ทั้งสองแบบและดัชนีอุปกรณ์ ใน PowerShell คำสั่งนี้จะคงการขุดด้วย CPU และเลือกอุปกรณ์ NVIDIA `0`:

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

ใช้ตัวเลือกเดียวกันกับไฟล์โปรแกรม Linux:

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

คำสั่งเหล่านี้ใช้ที่อยู่และพูลที่บันทึกไว้ หรือขอให้ป้อนเมื่อเริ่มทำงาน หากต้องการระบุการเชื่อมต่อโดยตรง ให้เพิ่มที่อยู่รับเงินสาธารณะด้วย `--address` และ URL ของพูลด้วย `--pool-url`

ดัชนีระบุ GPU ในรายการที่รันไทม์ NVIDIA ตรวจพบ ตรวจสอบรายการอุปกรณ์หลังเริ่มทำงาน `--nvidia-devices 0,1` เลือกการ์ดสองใบนั้น หากไม่ระบุตัวเลือกนี้ โปรแกรมจะใช้อุปกรณ์ NVIDIA ทั้งหมดที่ตรวจพบ

หากต้องการขุดด้วย GPU เท่านั้น ให้เลือก `nvidia`:

```bash
./seine --backend nvidia
```

ใน PowerShell ให้ใช้ `.\seine.exe --backend nvidia` เพิ่ม `cpu` ในรายการแบ็กเอนด์เมื่อต้องการใช้ฮาร์ดแวร์ทั้งสองประเภท เมื่อเปลี่ยนการเลือกนี้ ให้เริ่ม seine ใหม่ด้วยคำสั่งที่ต้องการ

## จะยืนยันได้อย่างไรว่า GPU กำลังขุด?

<Answer>
มองหาแถวแบ็กเอนด์ NVIDIA ในแผง Devices แล้วตรวจสอบแฮชเรตปัจจุบันและค่าเฉลี่ย ระหว่างการเตรียมเริ่มต้น แถวนั้นอาจแสดงความคืบหน้าขณะเตรียมเคอร์เนล CUDA เมื่อเริ่มคำนวณแฮชแล้ว ให้ตรวจสอบบันทึกเหตุการณ์เกี่ยวกับแชร์จากแบ็กเอนด์นั้น และดูแชร์ที่ได้รับการยอมรับในแผง Mining
</Answer>

แบ็กเอนด์ NVIDIA ปรากฏเป็น `nvidia#1`, `nvidia#2` และต่อไปตามลำดับ ส่วน CPU มีแถวของตัวเอง แฮชเรตรวมครอบคลุมแบ็กเอนด์ทั้งหมดที่กำลังทำงาน [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายแผงอื่น ๆ และป้ายกำกับในบันทึกเหตุการณ์

![เซสชัน seine จริงบน RTX 5090 พร้อมแฮชเรตของอุปกรณ์และแชร์ที่ได้รับการยอมรับ](/assets/blog/nvidia-rtx5090-session.png)

ภาพนี้แสดงเซสชันที่เชื่อมต่อพูลจริงบน RTX 5090 ส่วนการทดสอบประสิทธิภาพแบบกำหนดเวลาด้านล่างทำแยกกัน แฮชเรตของอุปกรณ์วัดการทำงานในเครื่อง ขณะที่แชร์ที่ได้รับการยอมรับยืนยันว่าพูลนับงานที่ส่งไปแล้ว ติดตามงานที่พูลนับให้ได้ด้วย[คู่มือติดตามเครื่องขุด](https://bntpool.com/blog/track-your-miner-on-bntpool/)

การเปิดครั้งแรกจะเตรียมและปรับแต่งเคอร์เนล GPU โดย seine บันทึกผลการปรับแต่ง NVIDIA อัตโนมัติไว้ใน `seine-data/seine.nvidia-autotune.json` ใช้ไดเรกทอรีข้อมูลนี้ซ้ำ เพื่อให้การเปิดครั้งต่อไปโหลดผลที่บันทึกไว้และยังเข้ากันได้ หรือเลือกไดเรกทอรีโดยตรงด้วย `--data-dir`

## RTX 5090 ทำความเร็วได้เท่าไรในการทดสอบของเรา?

วัดเมื่อวันที่ 31 ตุลาคม 2026: ใช้เฉพาะ RTX 5090 บน Windows 11 โดยตรง ไดรเวอร์ 610.88 และบิลด์พัฒนาแบบสาธารณะ อัตราขุดคงที่เป็นค่าหลังหักค่าธรรมเนียมโปรแกรมขุด และไม่รวมงานของ CPU

| โหมด | H/s เฉลี่ย |
|---|---|
| RTX 5090 เท่านั้น | 13.8 |

## ควรตรวจสอบอะไรหากแถว NVIDIA ไม่ปรากฏ?

ตรวจสอบไดรเวอร์ก่อน บน Windows ให้เก็บไฟล์ NVRTC DLL ที่มาด้วยไว้ข้าง `seine.exe` ด้วย บน Linux ให้ติดตั้งไดรเวอร์ NVIDIA ในสภาพแวดล้อมที่คุณเปิดโปรแกรมขุด

จากนั้นตรวจสอบคำสั่ง `--backend cpu` เลือกเฉพาะ CPU ใช้คำสั่งเริ่มต้นหรือ `--backend cpu,nvidia` เพื่อใช้ทั้งสองแบบ หากกำหนด `--nvidia-devices` ให้ตรวจสอบว่าดัชนีเหล่านั้นมีอยู่บนเครื่องของคุณ

อ่านบันทึกตอนเริ่มทำงานของแบ็กเอนด์นั้น เพื่อแยกว่าระบบยังเตรียมการอยู่หรือเกิดข้อผิดพลาดในการเริ่มต้น แก้ปัญหารันไทม์หรือการเลือกอุปกรณ์ตามที่รายงาน แล้วเริ่มใหม่ [คู่มือ NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) ยังอธิบายข้อกำหนดสำหรับการบิลด์จากซอร์สโค้ดด้วย

สำหรับงาน Argon2id ปัจจุบัน เลน GPU แต่ละเลนที่ทำงานต้องใช้พื้นที่หน่วยความจำ 2 GiB รวมกับหน่วยความจำเพิ่มเติมของรันไทม์ seine กำหนดขนาดงาน GPU จากหน่วยความจำอุปกรณ์ที่ว่างและการตรวจสอบการจัดสรรหน่วยความจำ ไม่ต้องกำหนดจำนวนเลนเอง เพราะความจุ VRAM ที่ระบุเพียงอย่างเดียวไม่ได้บอกจำนวนเลนที่ใช้งานได้ระหว่างใช้เดสก์ท็อป

หากอุปกรณ์กำลังคำนวณแฮชแต่พูลแสดงศูนย์ ให้ทำตาม[รายการตรวจสอบแฮชเรตของพูล](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate) เพื่อตรวจสอบที่อยู่ การเชื่อมต่อ และแชร์ที่ได้รับการยอมรับ
