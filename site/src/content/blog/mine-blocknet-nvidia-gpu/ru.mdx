seine майнит Blocknet на GPU NVIDIA вместе с CPU. В этом руководстве описаны настройка Windows и Linux, выбор видеокарт, принятые шары и сравнение режимов на RTX 5090 по результатам измерений. Команды относятся к seine v0.2.26 и текущей сети Argon2id по состоянию на октябрь 2026 года.

## Как начать майнить Blocknet на GPU NVIDIA?

<Answer>
Скачайте архив seine для Windows x86_64 или Linux x86_64, подготовьте драйвер NVIDIA и библиотеки среды выполнения для своей платформы и запустите майнер. Введите адрес для выплат и примите пул по умолчанию. seine автоматически выберет CPU и обнаруженные видеокарты NVIDIA, затем подготовит и настроит каждый бэкенд GPU.
</Answer>

Выберите архив в [разделе загрузок](/ru/#download): `seine-windows-x86_64.zip` для Windows или `seine-linux-x86_64.tar.gz` для Linux x86_64. В [общем руководстве по майнингу](/ru/blog/how-to-mine-blocknet/) описаны получение адреса для выплат и первое подключение.

Начните с настроек по умолчанию. Не задавайте вычислительное ядро, ограничение регистров, число линий GPU и потоков CPU: seine выберет конфигурацию самостоятельно. После инициализации панель Devices покажет, какие бэкенды участвуют в работе.

## Подготовьте среду выполнения NVIDIA в Windows или Linux

| Платформа | Что подготовить | Команда запуска |
|---|---|---|
| Windows x86_64 | Драйвер NVIDIA; DLL среды выполнения из архива рядом с исполняемым файлом | `.\seine.exe` |
| Linux x86_64 | Драйвер NVIDIA и совместимые библиотеки NVRTC | `./seine` |

В Windows извлеките весь ZIP в папку, доступную для записи. Оставьте `nvrtc64_120_0.dll` и `nvrtc-builtins64_128.dll` рядом с `seine.exe`. Готовая сборка использует эти библиотеки из архива; отдельно устанавливать CUDA Toolkit не требуется.

![Архив Windows в официальной таблице загрузок seine](/assets/blog/windows-download.png)

Установите драйвер для своей видеокарты и операционной системы со [страницы драйверов NVIDIA](https://www.nvidia.com/en-us/drivers/). [Руководство по настройке Windows](/ru/blog/mine-blocknet-on-windows/) пошагово описывает загрузку, проверку контрольной суммы и распаковку.

В Linux установите драйвер NVIDIA и совместимые пакеты NVRTC для своего дистрибутива. NVRTC компилирует ядра CUDA для seine во время выполнения. В [документации NVRTC](https://docs.nvidia.com/cuda/nvrtc/) описаны компилятор и соответствующая библиотека builtins; [требования seine для NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) описывают необходимую майнеру среду выполнения.

Запускайте исполняемый файл из его папки. Используйте одну рабочую папку, чтобы сохранять настройки в `seine-data`. При первом запуске введите адрес получения и примите `stratum+tcp://bntpool.com:3333` в качестве адреса пула.

## Можно ли выбрать одну видеокарту NVIDIA и продолжить майнинг на CPU?

Выберите оба бэкенда и индекс устройства. В PowerShell следующая команда сохраняет майнинг на CPU и выбирает устройство NVIDIA `0`:

```powershell
.\seine.exe --backend cpu,nvidia --nvidia-devices 0
```

В Linux используйте те же параметры с соответствующим исполняемым файлом:

```bash
./seine --backend cpu,nvidia --nvidia-devices 0
```

Эти команды используют сохранённые адрес и пул или запрашивают их при запуске. Чтобы явно задать подключение, добавьте публичный адрес получения с помощью `--address`, а URL пула — с помощью `--pool-url`.

Индекс обозначает GPU в списке устройств среды выполнения NVIDIA. Проверьте список после запуска. `--nvidia-devices 0,1` выбирает эти две видеокарты; если не указывать параметр выбора, используются все обнаруженные устройства NVIDIA.

Для майнинга только на GPU выберите `nvidia`:

```bash
./seine --backend nvidia
```

В PowerShell используйте `.\seine.exe --backend nvidia`. Добавьте `cpu` в список бэкендов, если хотите использовать оба типа оборудования. При изменении выбора перезапустите seine с нужной командой.

## Как убедиться, что GPU майнит?

<Answer>
Найдите строки бэкендов NVIDIA на панели Devices и проверьте их текущий и средний хешрейт. При инициализации строка может показывать ход запуска, пока подготавливаются ядра CUDA. Когда начнётся вычисление хешей, проверяйте журнал на наличие событий с шарами этого бэкенда, а панель Mining — на наличие принятых шар.
</Answer>

Бэкенды NVIDIA обозначаются как `nvidia#1`, `nvidia#2` и так далее; CPU имеет собственную строку. Общий хешрейт включает все активные бэкенды. [Руководство по панели майнера](/ru/blog/seine-dashboard-explained/) объясняет остальные панели и обозначения в журнале.

![Реальный сеанс seine с RTX 5090, хешрейтом устройств и принятыми шарами](/assets/blog/nvidia-rtx5090-session.png)

На снимке показан реальный сеанс работы с пулом на RTX 5090. Приведённые ниже тесты с замером времени выполнялись отдельно. Хешрейт устройства отражает локальную работу; принятая шара подтверждает, что пул зачёл отправленную работу. Для её отслеживания используйте [руководство по наблюдению за майнером](https://bntpool.com/blog/track-your-miner-on-bntpool/).

При первом запуске подготавливаются и настраиваются ядра GPU. seine сохраняет результаты автонастройки NVIDIA в `seine-data/seine.nvidia-autotune.json`. Используйте эту папку данных, чтобы при следующих запусках загружались совместимые сохранённые результаты, или явно выберите папку через `--data-dir`.

## Что проверить, если строка NVIDIA отсутствует?

Сначала проверьте извлечённый исполняемый файл и библиотеки среды выполнения. В Windows оставьте DLL NVRTC из архива рядом с `seine.exe`. В Linux установите драйвер и библиотеки NVRTC в среде, из которой запускаете майнер.

Затем проверьте команду. `--backend cpu` выбирает только CPU. Используйте команду по умолчанию или `--backend cpu,nvidia` для обоих типов оборудования. Если задан `--nvidia-devices`, убедитесь, что указанные индексы существуют на вашем компьютере.

Прочитайте журнал запуска этого бэкенда: он позволяет отличить продолжающуюся подготовку от ошибки инициализации. Устраните указанную проблему среды выполнения или выбора устройств и перезапустите майнер. [Руководство по NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) также описывает требования к сборке из исходного кода.

Для текущей нагрузки Argon2id каждой активной линии GPU нужна область памяти размером 2 GiB плюс накладные расходы среды выполнения. seine определяет объём работы GPU с учётом доступной памяти устройства и проверок выделения памяти. Не задавайте число линий вручную: один лишь заявленный объём VRAM не определяет, сколько линий доступно во время работы за компьютером.

Если устройство вычисляет хеши, но пул показывает ноль, пройдите [проверки хешрейта пула](https://bntpool.com/blog/track-your-miner-on-bntpool/#zero-hashrate), чтобы проверить адрес, подключение и принятые шары.
