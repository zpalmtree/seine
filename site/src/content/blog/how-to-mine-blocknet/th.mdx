คู่มือนี้พาคุณตั้งแต่ดาวน์โหลด **seine** ไปจนถึงแชร์แรกที่ได้รับการยอมรับและการรับเงินจากพูล bntpool.com บน Windows, macOS หรือ Linux หากเพิ่งเริ่มขุด อ่าน[การขุดคริปโตทำงานอย่างไร](/th/blog/how-crypto-mining-works/) เพื่อทำความเข้าใจบล็อก ความยาก และพูลก่อน

## ขุด Blocknet อย่างไร?

<Answer>
รับที่อยู่ Blocknet หรือชื่อสั้นของ Blocknet ID ดาวน์โหลด seine สำหรับระบบของคุณ เปิดโปรแกรม แล้ววางที่อยู่เมื่อโปรแกรมถาม ยอมรับพูลเริ่มต้น bntpool.com เท่านี้คุณก็เริ่มขุดแล้ว โปรแกรมขุด seine เริ่มคำนวณแฮชทันที และปรับจูนจำนวนเธรดกับเคอร์เนลของ CPU ต่อเนื่องขณะทำงาน
</Answer>

## ต้องเตรียมอะไรบ้างก่อนเริ่ม?

- **ที่อยู่ Blocknet** ติดตั้งกระเป๋าเงินทางการของ Blocknet ไม่ว่าจะเป็น[กระเป๋าเงินแบบบรรทัดคำสั่ง](https://github.com/blocknetprivacy/blocknet/releases/latest) หรือ[กระเป๋าเงินเดสก์ท็อป](https://github.com/blocknetprivacy/blocknet-gui/releases/latest) แล้วคัดลอกที่อยู่ของคุณ [คู่มือกระเป๋าเงิน](/th/blog/blocknet-wallet-for-mining/) อธิบายทีละขั้นตอน เก็บกระเป๋าเงินและวลีกู้คืนไว้บนคอมพิวเตอร์ของคุณเอง อย่านำไปไว้บนริกขุดที่ใช้ร่วมกับผู้อื่น
- **หรือใช้ชื่อสั้น** หากคุณมี[ชื่อสั้นของ Blocknet ID](/th/blog/blocknet-id-pay-by-name/) จาก [blocknet.id](https://blocknet.id) คุณสามารถขุดไปยัง `@name` แทนการวางที่อยู่ยาวได้
- **RAM ประมาณ 2 GB ต่อเธรดขุด** โปรแกรมขุด seine ปรับการใช้ทรัพยากรให้เหมาะกับเครื่องและเผื่อหน่วยความจำให้ระบบ คุณจึงไม่ต้องคำนวณเองก่อน
- **Windows, macOS หรือ Linux** NVIDIA — Windows: ไดรเวอร์จอแสดงผล NVIDIA และไฟล์ DLL รันไทม์ที่ให้มา วางไว้ข้างไฟล์โปรแกรม; Linux: ไดรเวอร์ NVIDIA และไลบรารีรันไทม์ NVRTC ที่เข้ากันได้.

## ขั้นที่ 1: ดาวน์โหลด seine

ดาวน์โหลดไฟล์สำหรับระบบของคุณจาก[ส่วนดาวน์โหลด](/th/#download) ไม่ต้องติดตั้งอะไร เพียงแตกไฟล์ก็พร้อมใช้

| ระบบ | ไฟล์ดาวน์โหลด | การ์ดจอ |
|---|---|---|
| Windows (x86_64) | `seine-windows-x86_64.zip` | NVIDIA; รวม CUDA runtime มาให้แล้ว |
| Linux (x86_64) | `seine-linux-x86_64.tar.gz` | ไดรเวอร์ NVIDIA และไลบรารีรันไทม์ NVRTC ที่เข้ากันได้; glibc ≥ 2.39 |
| Linux (ARM64) | `seine-linux-aarch64.tar.gz` | CPU (glibc 2.39 หรือใหม่กว่า) |
| macOS (Apple Silicon) | `seine-macos-aarch64.tar.gz` | CPU |
| macOS (Intel) | `seine-macos-x86_64.tar.gz` | CPU |

แต่ละรุ่นมีไฟล์ `SHA256SUMS.txt` ให้ด้วย คุณจึงตรวจสอบได้ว่าไฟล์ที่ดาวน์โหลดตรงกับไฟล์ของรุ่นนั้น

## ขั้นที่ 2: เปิดโปรแกรม

บน Windows ให้ดับเบิลคลิก `seine.exe` บน macOS หรือ Linux ให้เปิดเทอร์มินัลในโฟลเดอร์ที่แตกไฟล์แล้วและรัน:

```sh
./seine
```

## ขั้นที่ 3: ใส่ที่อยู่แล้วเริ่มขุด

โปรแกรมขุด seine จะถามที่อยู่รับเงินหรือ `@shortname` ของคุณ แล้วจึงถามพูล กด Enter เพื่อยอมรับค่าเริ่มต้น `stratum+tcp://bntpool.com:3333` ไม่นาน[แดชบอร์ด](/th/blog/seine-dashboard-explained/) จะแสดงแฮชเรตและแชร์แรกของคุณ

จากนั้น seine จะปรับจูนต่อไปขณะขุด โปรแกรมเปรียบเทียบจำนวนเธรดและเคอร์เนลของ CPU ด้วยงานขุดจริง เปลี่ยนเมื่อยืนยันได้ว่าเร็วขึ้นเท่านั้น ลดการใช้ทรัพยากรเมื่อหน่วยความจำเริ่มตึงตัว และจดจำค่าที่ได้ผลไว้ใช้ครั้งถัดไป การปรับจูนนี้ไม่ต้องเชื่อมต่อพูลใหม่ จึงไม่ทำให้คุณเสียเวลาขุด

## ต้องรอนานแค่ไหนจึงจะได้เงิน?

พูล bntpool.com ใช้ PPLNS โดยแบ่งรางวัลของแต่ละบล็อกให้กับแชร์ที่ส่งในช่วงหกชั่วโมงก่อนพบบล็อกนั้น รางวัลจะยังใช้จ่ายไม่ได้จนกว่าบล็อกจะอยู่ลึก 60 บล็อก ซึ่งใช้เวลาประมาณห้าชั่วโมงที่เวลาบล็อกห้านาทีของ Blocknet เมื่อยอดที่ยืนยันแล้วถึง 0.1 BNT พูลจะส่งเงินไปยังที่อยู่ของคุณ

คุณติดตามแฮชเรต แชร์ และยอดเงินได้บน [bntpool.com](https://bntpool.com) โดยค้นหาที่อยู่ของคุณ พูลจะแสดงรางวัลจากบล็อกที่ยังไม่ยืนยันแยกต่างหาก เพราะยอดเหล่านั้นยังเปลี่ยนแปลงได้

## คอมพิวเตอร์ของคุณจะขุดได้เร็วแค่ไหน?

แฮชเรตขึ้นอยู่กับแบนด์วิดท์หน่วยความจำและจำนวนเธรดที่ RAM รองรับเป็นหลัก ต่อไปนี้คือผลที่ดีที่สุดที่วัดด้วย seine สำหรับแต่ละรุ่น:

| ฮาร์ดแวร์ | เธรด | แฮชเรต |
|---|---|---|
| AMD EPYC · Zen 5 (EPYC 9355P) | 64 | 97.1 H/s |
| เซิร์ฟเวอร์ Arm (AWS Graviton4) | 32 | 39.3 H/s |
| AMD EPYC · Zen 4 (EPYC 9R14) | 32 | 45.3 H/s |
| Apple M4 Max (48 GB MacBook Pro) | 16 | 30.9 H/s |
| Intel Xeon (Sapphire Rapids 8488C) | 32 | 26.0 H/s |

การตั้งค่าที่เร็วที่สุดในการวัดเหล่านี้คือ AMD EPYC 9355P ที่ 97.1 H/s โดยใช้ 64 เธรดขุดและ RAM 192 GiB บน Linux ด้วยการตั้งค่าเริ่มต้นของ seine

ผลของ CPU ทุกตัวที่ทดสอบอยู่ใน[หน้าประสิทธิภาพ](https://github.com/zpalmtree/seine/blob/master/docs/PERFORMANCE.md) และ[คู่มือฮาร์ดแวร์ขุด Blocknet](/th/blog/blocknet-mining-hardware-hashrate/) อธิบายว่า RAM และแบนด์วิดท์หน่วยความจำกำหนดตัวเลขเหล่านี้อย่างไร

## seine ใช้ CPU เดิมให้ได้มากขึ้นอย่างไร?

โปรแกรมขุด seine มีเคอร์เนล Argon2id หลายแบบสำหรับหน่วยประมวลผลแต่ละตระกูล และวัดผลบนเครื่องของคุณขณะขุด บนฮาร์ดแวร์ที่เราทดสอบ การเลือกเคอร์เนลที่เหมาะสมทำให้ผลต่างชัดเจน:

- **AWS Graviton4:** เคอร์เนล SHA3 ที่ใช้ prefetching ขุดเร็วกว่า NEON แบบปกติ 56% (จาก 13.80 เป็น 21.50 H/s)
- **AMD EPYC 9R45 (Zen 5):** เคอร์เนลแบบ streaming ขุดเร็วกว่า AVX2 30% (จาก 34.47 เป็น 44.74 H/s ที่ 24 เธรด)

คุณไม่ต้องเลือกเอง โปรแกรมขุด seine เปลี่ยนเคอร์เนลเมื่อยืนยันได้ว่าเร็วขึ้นเท่านั้น และจดจำผลไว้ใช้เมื่อเปิดโปรแกรมครั้งถัดไป

## เพิ่มแฮชเรตได้อย่างไร?

- **ขุดด้วย CPU และ GPU พร้อมกัน** โปรแกรมขุด seine ทำเช่นนี้เป็นค่าเริ่มต้นบน Windows และ Linux โดยแฮชเรตของทั้งสองส่วนรวมกัน
- **สำรอง huge pages บน Linux และ WSL** การใช้เพจขนาด 2 MiB รองรับหน่วยความจำของแต่ละเธรดเพิ่มความเร็วประมาณ 4–6% บนเครื่องที่ใช้ตรวจสอบ และเพจขนาด 1 GiB เพิ่มได้อีกราว 2% [คู่มือ huge pages](/th/blog/huge-pages-blocknet-mining/) มีคำสั่งให้ใช้
- **ให้เซิร์ฟเวอร์ขนาดใหญ่กระจายงาน** บน Linux โปรแกรมขุด seine จัดเธรดกระจายไปตามโหนด NUMA และกลุ่มแคชโดยอัตโนมัติ [คู่มือเซิร์ฟเวอร์ขนาดใหญ่](https://github.com/zpalmtree/seine/blob/master/docs/guides/large-servers.md) อธิบายรายละเอียด
- **ใช้การขุดด้วย CPU อย่างเดียวบน Apple Silicon** นี่เป็นตัวเลือกที่เร็วที่สุดบน Mac ตระกูล M และเป็นค่าเริ่มต้นของ seine

## ขุด Blocknet แบบเดี่ยวได้ไหม?

ได้ หากคุณมีโหนด Blocknet ของตัวเองที่ซิงก์แล้ว ให้เปิด seine ด้วย `./seine --mode daemon` แล้วโปรแกรมจะขุดกับโหนดโดยตรงแทนพูล คุณได้รับทุกบล็อกที่พบ แต่จะได้เงินต่อเมื่อพบบล็อกเต็มเท่านั้น คนส่วนใหญ่จึงเริ่มจากพูล [คู่มือขุดเดี่ยว](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md) อธิบายวิธีตั้งค่า

<Note>
Blocknet วางแผนอัปเกรดเครือข่ายชื่อ Faraday ประมาณวันที่ 16 กุมภาพันธ์ 2027 ตามข้อมูลจาก [blocknetcrypto.com](https://blocknetcrypto.com/#faraday) โดยมีแผนเปลี่ยน Proof of Work จึงควรอัปเดต seine ให้เป็นรุ่นล่าสุดเสมอ โปรแกรมจะตรวจสอบรุ่นใหม่เมื่อเริ่มทำงานและทุก 12 ชั่วโมง
</Note>
