このガイドでは、**seine** のダウンロードから、bntpool.com のマイニングプールで最初のシェアが受理され支払いを受け取るまでを、Windows、macOS、Linux それぞれについて説明します。マイニングが初めての方は、まず[暗号資産マイニングの仕組み](/ja/blog/how-crypto-mining-works/)でブロック、難易度、プールについてご覧ください。

## Blocknet はどうやってマイニングしますか？

<Answer>
Blocknet アドレスまたは Blocknet ID のショートネームを用意し、お使いのシステム向けの seine をダウンロードして実行し、求められたらアドレスを貼り付けます。デフォルトのプールである bntpool.com をそのまま使えば、マイニングが始まります。seine はすぐにハッシュ計算を開始し、実行中もスレッド数と CPU カーネルの調整を続けます。
</Answer>

## 始める前に何が必要ですか？

- **Blocknet アドレス。** 公式の Blocknet ウォレット（[コマンドライン版ウォレット](https://github.com/blocknetprivacy/blocknet/releases/latest)または[デスクトップ版ウォレット](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)）をインストールし、アドレスをコピーします。手順は[ウォレットガイド](/ja/blog/blocknet-wallet-for-mining/)で一つずつ説明しています。ウォレットとそのリカバリーフレーズは自分のコンピューターに保管し、共用のマイニングリグには置かないでください。
- **またはショートネーム。** [blocknet.id](https://blocknet.id) で取得した [Blocknet ID のショートネーム](/ja/blog/blocknet-id-pay-by-name/)があれば、長いアドレスを貼り付ける代わりに `@name` 宛てにマイニングできます。
- **マイニングスレッド 1 つにつき約 2 GB の RAM。** seine はマシンに合わせて自動で設定を決め、システム用の余裕も残すので、事前に計算する必要はありません。

## ステップ 1：seine をダウンロード

[ダウンロードセクション](/ja/#download)からお使いのシステム向けのアーカイブを入手します。インストールは不要です。展開すればすぐに使えます。

## ステップ 2：実行

Windows では `seine.exe` をダブルクリックします。macOS または Linux では、展開したフォルダーでターミナルを開いて次を実行します。

```sh
./seine
```

## ステップ 3：アドレスを入力してマイニング開始

seine はまず受け取りアドレスまたは `@shortname` を尋ね、次にプールを尋ねます。Enter キーを押すとデフォルトの `stratum+tcp://bntpool.com:3333` が選ばれます。すぐに[ダッシュボード](/ja/blog/seine-dashboard-explained/)にハッシュレートと最初のシェアが表示されます。

ここから seine はマイニングしながら調整を続けます。実際のマイニング処理でスレッド数と CPU カーネルを比較し、向上が確認できたときだけ切り替え、メモリが逼迫すれば設定を下げ、うまくいった設定を次回の起動のために記憶します。この間プールへの再接続は行わないので、調整によってマイニング時間が失われることはありません。

## 支払いを受け取るまでどれくらいかかりますか？

bntpool.com のマイニングプールは PPLNS を採用しています。各ブロックの報酬は、そのブロックが見つかる前の 6 時間に提出されたシェアで分配されます。報酬はそのブロックの上に 60 ブロックが積まれるまで使えず、Blocknet の 5 分のブロック時間でおよそ 5 時間です。承認済みの残高が 0.1 BNT に達すると、プールがあなたのアドレスへ送金します。

[bntpool.com](https://bntpool.com) で自分のアドレスを検索すると、ハッシュレート、シェア、残高を確認できます。まだ承認されていないブロックからの報酬は変わる可能性があるため、別に表示されます。

## お使いのコンピューターはどれくらいの速さでマイニングできますか？

ハッシュレートは主にメモリ帯域幅と、RAM が許すスレッド数で決まります。以下は seine で世代ごとに測定した最高の結果です。

| ハードウェア | スレッド | ハッシュレート |
|---|---|---|
| AMD EPYC · Zen 5（EPYC 9355P） | 64 | 97.1 H/s |
| Arm サーバー（AWS Graviton4） | 32 | 39.3 H/s |
| AMD EPYC · Zen 4（EPYC 9R14） | 32 | 45.3 H/s |
| Apple M4 Max（48 GB MacBook Pro） | 16 | 30.9 H/s |
| Intel Xeon（Sapphire Rapids 8488C） | 32 | 26.0 H/s |

これらの測定で最も速い構成はAMD EPYC 9355Pの97.1 H/sです。マイニングスレッド64本、RAM 192 GiBを使い、Linux上でseineのデフォルト設定のまま動作させました。Blocknetのマイニングにはメモリ帯域幅と、1スレッドあたり2 GiBを確保できるRAM容量が役立ちます。NVIDIAカードはCPUにハッシュレートを加算できます。

テストしたすべての CPU の結果は[パフォーマンスページ](https://github.com/zpalmtree/seine/blob/master/docs/PERFORMANCE.md)に掲載しています。RAM とメモリ帯域幅がこれらの数値をどう決めるかは [Blocknet マイニングハードウェアガイド](/ja/blog/blocknet-mining-hardware-hashrate/)で説明しています。

## ハッシュレートをさらに上げるには？

- **CPU と GPU で一緒にマイニングする。** Windows と Linux では seine がデフォルトでこれを行い、両方のハッシュレートが合算されます。
- **Linux と WSL でヒュージページを確保する。** 検証用マシンでは、各スレッドのメモリを 2 MiB ページで確保すると約 4〜6%、1 GiB ページではさらに約 2% 向上しました。コマンドは[ヒュージページガイド](/ja/blog/huge-pages-blocknet-mining/)にあります。
- **大型サーバーではスレッドを分散させる。** Linux では、seine がスレッドを NUMA ノードとキャッシュグループに自動で配置します。詳しくは[大型サーバーガイド](https://github.com/zpalmtree/seine/blob/master/docs/guides/large-servers.md)をご覧ください。
- **Apple シリコンでは CPU のみでマイニングする。** M シリーズの Mac ではこれが最速の選択で、seine もデフォルトでそうします。

## Blocknet はソロマイニングできますか？

はい。同期済みの自分の Blocknet ノードを運用している場合は、`./seine --mode daemon` で seine を起動すると、プールではなくノードに対して直接マイニングします。見つけたブロックはすべて自分のものになりますが、支払いはブロックを丸ごと見つけたときにしか届かないため、多くの人はプールから始めます。設定方法は[ソロマイニングガイド](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)で説明しています。

<Note>
