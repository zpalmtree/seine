本指南带你从下载 **seine** 开始，到在 bntpool.com 矿池上获得第一批被接受的份额和收益，适用于 Windows、macOS 和 Linux。刚接触挖矿？[加密货币挖矿原理](/zh-hans/blog/how-crypto-mining-works/)先讲解了区块、难度和矿池。

## 如何挖 Blocknet？

<Answer>
准备一个 Blocknet 地址或 Blocknet ID 短名称，下载适合你系统的 seine，运行它，并在提示时粘贴你的地址。接受默认矿池 bntpool.com，就已经在挖矿了。seine 会立即开始计算哈希，并在运行中持续调整线程数和 CPU 计算内核。
</Answer>

## 开始之前需要准备什么？

- **一个 Blocknet 地址。** 安装官方 Blocknet 钱包，即[命令行钱包](https://github.com/blocknetprivacy/blocknet/releases/latest)或[桌面钱包](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)，然后复制你的地址。[钱包指南](/zh-hans/blog/blocknet-wallet-for-mining/)会一步步带你完成。请把钱包和助记词保存在你自己的电脑上，不要放在与他人共用的矿机上。
- **或者一个短名称。** 如果你在 [blocknet.id](https://blocknet.id) 注册了 [Blocknet ID 短名称](/zh-hans/blog/blocknet-id-pay-by-name/)，就可以直接挖到 `@name`，不必粘贴很长的地址。
- **每个挖矿线程约 2 GB 内存。** seine 会根据你的机器自动确定线程数，并为系统预留余量，所以无需事先计算。

## 第 1 步：下载 seine

在[下载区](/zh-hans/#download)获取适合你系统的压缩包。无需安装：解压即可使用。

## 第 2 步：运行

在 Windows 上，双击 `seine.exe`。在 macOS 或 Linux 上，在解压后的文件夹中打开终端并运行：

```sh
./seine
```

## 第 3 步：输入地址并开始挖矿

seine 会先询问你的收款地址或 `@shortname`，然后询问矿池。按回车接受默认矿池 `stratum+tcp://bntpool.com:3333`。片刻之后，[仪表盘](/zh-hans/blog/seine-dashboard-explained/)上就会显示你的算力和第一批份额。

此后 seine 会边挖边调优。它用真实的挖矿任务比较不同的线程数和 CPU 计算内核，只有在确认有提升后才会切换；内存紧张时会自动回退，并记住有效的设置供下次启动使用。整个过程不会重新连接矿池，因此调优不会浪费挖矿时间。

## 多久能收到收益？

bntpool.com 采用 PPLNS：每个区块的奖励在其被找到前六小时内提交的份额之间分配。区块奖励要等该区块获得 60 个确认后才能使用，按 Blocknet 五分钟的出块时间计算约为五小时。当你已确认的余额达到 0.1 BNT 时，矿池会把它发送到你的地址。

你可以在 [bntpool.com](https://bntpool.com) 上查询自己的地址，查看算力、份额和余额。尚未确认的区块带来的奖励会单独显示，因为这些奖励仍可能变化。

## 你的电脑挖矿有多快？

算力主要取决于内存带宽，以及你的内存能支持的线程数。以下是 seine 在各代硬件上实测的最佳结果：

| 硬件 | 线程数 | 算力 |
|---|---|---|
| AMD EPYC · Zen 5（EPYC 9355P） | 64 | 97.1 H/s |
| Arm 服务器（AWS Graviton4） | 32 | 39.3 H/s |
| AMD EPYC · Zen 4（EPYC 9R14） | 32 | 45.3 H/s |
| Apple M4 Max（48 GB MacBook Pro） | 16 | 30.9 H/s |
| Intel Xeon（Sapphire Rapids 8488C） | 32 | 26.0 H/s |

这些测量中最快的配置是达到 97.1 H/s 的 AMD EPYC 9355P：64 个挖矿线程、192 GiB RAM，在 Linux 上使用 seine 的默认设置。

所有已测 CPU 的结果见[性能页面](https://github.com/zpalmtree/seine/blob/master/docs/PERFORMANCE.md)，[Blocknet 挖矿硬件指南](/zh-hans/blog/blocknet-mining-hardware-hashrate/)则解释了内存容量和内存带宽如何决定这些数字。

## 如何获得更高的算力？

- **CPU 和显卡一起挖。** 在 Windows 和 Linux 上 seine 默认如此，两者的算力会叠加。
- **在 Linux 和 WSL 上预留大页内存。** 在用于验证的测试机上，用 2 MiB 页面承载每个线程的内存可提升约 4–6%，1 GiB 页面还能再提升约 2%。[大页内存指南](/zh-hans/blog/huge-pages-blocknet-mining/)中有相关命令。
- **让大型服务器分散线程。** 在 Linux 上，seine 会自动把线程分布到各个 NUMA 节点和缓存组。详情见[大型服务器指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/large-servers.md)。
- **在 Apple 芯片上只用 CPU 挖矿。** 这是 M 系列 Mac 上最快的选择，也是 seine 的默认做法。

## Blocknet 可以独立挖矿（solo）吗？

可以。如果你运行着自己已同步的 Blocknet 节点，用 `./seine --mode daemon` 启动 seine，它就会直接对接节点挖矿，而不经过矿池。你找到的每个区块都归你所有，但只有找到完整区块时才有收益，所以大多数人会先从矿池开始。设置方法见[独立挖矿指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)。
