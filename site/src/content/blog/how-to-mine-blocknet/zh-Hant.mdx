本指南帶你從下載 **seine** 開始，到在 bntpool.com 礦池上獲得第一批被接受的份額與收益，適用於 Windows、macOS 與 Linux。剛接觸挖礦？[加密貨幣挖礦原理](/zh-hant/blog/how-crypto-mining-works/)先說明了區塊、難度與礦池。

## 如何挖 Blocknet？

<Answer>
準備一個 Blocknet 地址或 Blocknet ID 短名稱，下載適合你系統的 seine，執行它，並在提示時貼上你的地址。接受預設礦池 bntpool.com，就已經在挖礦了。seine 會立即開始計算雜湊，並在執行中持續調整執行緒數與 CPU 運算核心程式。
</Answer>

## 開始之前需要準備什麼？

- **一個 Blocknet 地址。** 安裝官方 Blocknet 錢包，即[命令列錢包](https://github.com/blocknetprivacy/blocknet/releases/latest)或[桌面錢包](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)，然後複製你的地址。[錢包指南](/zh-hant/blog/blocknet-wallet-for-mining/)會一步步帶你完成。請把錢包與助記詞保存在你自己的電腦上，不要放在與他人共用的礦機上。
- **或者一個短名稱。** 如果你在 [blocknet.id](https://blocknet.id) 註冊了 [Blocknet ID 短名稱](/zh-hant/blog/blocknet-id-pay-by-name/)，就可以直接挖到 `@name`，不必貼上很長的地址。
- **每個挖礦執行緒約 2 GB 記憶體。** seine 會依你的電腦自動決定執行緒數，並為系統預留餘裕，所以無需事先計算。

## 第 1 步：下載 seine

在[下載區](/zh-hant/#download)取得適合你系統的壓縮檔。無需安裝：解壓縮即可使用。

## 第 2 步：執行

在 Windows 上，雙擊 `seine.exe`。在 macOS 或 Linux 上，在解壓縮後的資料夾中開啟終端機並執行：

```sh
./seine
```

## 第 3 步：輸入地址並開始挖礦

seine 會先詢問你的收款地址或 `@shortname`，然後詢問礦池。按 Enter 接受預設礦池 `stratum+tcp://bntpool.com:3333`。片刻之後，[儀表板](/zh-hant/blog/seine-dashboard-explained/)上就會顯示你的算力與第一批份額。

此後 seine 會邊挖邊調校。它用真實的挖礦工作比較不同的執行緒數與 CPU 運算核心程式，只有在確認有提升後才會切換；記憶體吃緊時會自動調降，並記住有效的設定供下次啟動使用。整個過程不會重新連線礦池，因此調校不會浪費挖礦時間。

## 多久能收到收益？

bntpool.com 採用 PPLNS：每個區塊的獎勵在其被找到前六小時內提交的份額之間分配。區塊獎勵要等該區塊獲得 60 個確認後才能使用，以 Blocknet 五分鐘的出塊時間計算約為五小時。當你已確認的餘額達到 1 BNT 時，礦池會把它發送到你的地址。

你可以在 [bntpool.com](https://bntpool.com) 上查詢自己的地址，查看算力、份額與餘額。尚未確認的區塊帶來的獎勵會分開顯示，因為這些獎勵仍可能變動。

## 你的電腦挖礦有多快？

算力主要取決於記憶體頻寬，以及你的記憶體能支援的執行緒數。以下是 seine 在各代硬體上實測的最佳結果：

| 硬體 | 執行緒數 | 算力 |
|---|---|---|
| AMD EPYC · Zen 5（EPYC 9355P） | 64 | 97.1 H/s |
| Arm 伺服器（AWS Graviton4） | 32 | 39.3 H/s |
| AMD EPYC · Zen 4（EPYC 9R14） | 32 | 45.3 H/s |
| Apple M4 Max（48 GB MacBook Pro） | 16 | 30.9 H/s |
| Intel Xeon（Sapphire Rapids 8488C） | 32 | 26.0 H/s |

這些測量中最快的配置是達到 97.1 H/s 的 AMD EPYC 9355P：64 個挖礦執行緒、192 GiB RAM，在 Linux 上使用 seine 的預設設定。

所有已測試 CPU 的結果請見[效能頁面](https://github.com/zpalmtree/seine/blob/master/docs/PERFORMANCE.md)，[Blocknet 挖礦硬體指南](/zh-hant/blog/blocknet-mining-hardware-hashrate/)則說明了記憶體容量與記憶體頻寬如何決定這些數字。

## 如何獲得更高的算力？

- **CPU 與顯示卡一起挖。** 在 Windows 與 Linux 上 seine 預設如此，兩者的算力會相加。
- **在 Linux 與 WSL 上預留大分頁記憶體。** 在驗證用的機器上，用 2 MiB 分頁承載每個執行緒的記憶體可提升約 4–6%，1 GiB 分頁還能再提升約 2%。[大分頁記憶體指南](/zh-hant/blog/huge-pages-blocknet-mining/)中有相關指令。
- **讓大型伺服器分散執行緒。** 在 Linux 上，seine 會自動把執行緒分配到各個 NUMA 節點與快取群組。詳情請見[大型伺服器指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/large-servers.md)。
- **在 Apple 晶片上只用 CPU 挖礦。** 這是 M 系列 Mac 上最快的選擇，也是 seine 的預設做法。

## Blocknet 可以單獨挖礦（solo）嗎？

可以，有兩種方式。最簡單的是在 bntpool.com 上單獨挖礦：在地址前加上 `solo:`，例如 `./seine --address solo:YOUR_ADDRESS`，礦池就會把你的礦機找到的每個區塊的全部獎勵支付給你，無需執行節點。[在 bntpool.com 上單獨挖礦](https://bntpool.com/blog/zh-hant/solo-mine-blocknet-on-bntpool/)說明了設定方式。如果你執行著自己已同步的 Blocknet 節點，也可以用 `./seine --mode daemon` 直接對接節點挖礦，[單獨挖礦指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/solo-mining.md)說明了具體做法。單獨挖礦的收益以整個區塊入帳，因此適合占全網算力比例較大的礦工。

<Note>
根據 [blocknetcrypto.com](https://blocknetcrypto.com/#faraday)，Blocknet 計畫在 2027年2月16日前後進行名為 Faraday 的網路升級，屆時工作量證明演算法預計會改變。seine v0.3.1 已為此做好準備：礦池挖礦會自動切換到新的工作量證明，開啟自動更新後，seine 會為你安裝更新的版本。
</Note>
