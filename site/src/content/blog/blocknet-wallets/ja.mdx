Blocknetには、今すぐインストールできるウォレットアプリが3つあります。公式デスクトップウォレット、公式コマンドライン版ウォレット、そしてコマンドラインツールを内蔵したグラフィカルなウォレットのGyroidです。このガイドでは、それぞれの対応環境と得意なことを比べ、ダウンロードの確認方法を示し、選んだアプリの手順ガイドを案内します。

## どのBlocknetウォレットを使えばよい？

<Answer>
Windows、macOS、Linux、Androidでクリック操作のアプリを使うなら公式デスクトップウォレットを選んでください。サーバー、スクリプト、ターミナルでの利用には公式コマンドライン版ウォレットを選びます。グラフィカルなウォレットとコマンドラインツールをひとつのプログラムで使いたいならGyroidを選びます。3つとも鍵を自分のパソコンに保管し、Blocknet coreを自動で動かします。
</Answer>

| ウォレット | インターフェース | 対応環境 |
|---|---|---|
| [デスクトップウォレット](https://github.com/blocknetprivacy/blocknet-gui/releases/latest) v0.23.0 | グラフィカル | Windows x64、macOS（Apple siliconとIntel）、Linux x64、Android arm64 |
| [コマンドライン版ウォレット](https://github.com/blocknetprivacy/blocknet/releases/latest) v1.2.1 | ターミナル | Windows x64、macOS（x64とarm64）、Linux（x64とarm64）、Android arm64 |
| [Gyroid](https://github.com/obselate/gyroid/releases/latest) v0.2.9 | グラフィカルとターミナル | Windows x64、Linux x64、Apple silicon搭載のmacOS |

バージョンは2026年11月5日時点の最新リリースです。各プロジェクトのリリースページには常に最新版があります。

## 公式デスクトップウォレット

デスクトップウォレットは、Blocknetプロジェクトが公開しているグラフィカルなアプリです。Blocknet coreを同梱しているため、ひとつのパッケージをインストールするだけでノードとウォレットがそろいます。パスワードを設定してウォレットを作成し、復元用単語を保存したら、サイドバーから残高、受取アドレス、支払い、履歴を使えます。

現在のリリースには、Windows用インストーラー、Linux用のAppImage・Debian・RPM・Flatpakパッケージ、Apple silicon搭載MacとIntel Mac向けに分かれたmacOS版、そしてAndroidパッケージがあります。初めてBlocknetを使う人にはいちばん簡単な方法です。[デスクトップウォレットの使い方](/ja/blog/blocknet-desktop-wallet/)では、開始画面から最初の支払いまで、各手順を画面付きで説明しています。

## 公式コマンドライン版ウォレット

`blocknet` プログラムは、Blocknetプロジェクトのターミナル用ウォレットです。Blocknet coreをインストール、起動、更新し、残高、アドレス、支払い、履歴、証明、閲覧鍵を扱う対話型のウォレットシェルを提供します。シェルを閉じてもcoreはバックグラウンドで動き続けるため、サーバーや常時稼働のパソコンに向いています。

3つの中で対応環境がもっとも広く、LinuxとmacOSのx64版とarm64版に加え、WindowsとAndroid版もあります。コマンドは繰り返しやスクリプト化が簡単で、送金のたびに確定前のプレビューが表示されます。[マイニング用ウォレットのガイド](/ja/blog/blocknet-wallet-for-mining/)では、このウォレットでの作成、復元用単語のバックアップ、アドレスのコピーを説明しています。

## Gyroid：コマンドラインツール付きのグラフィカルなウォレット

Gyroidは、Blocknet coreのコントリビューターであるobselateが開発したオープンソースのBlocknetウォレットで、MITライセンスで公開されています。ひとつのプログラムにグラフィカルなインターフェースとターミナルコマンド一式が入っているため、同じウォレットをどちらの方法でも管理できます。

グラフィカル側は日常的に必要な機能をそろえています。

- ウォレットの作成、復元、インポートと、複数のウォレットをひとつのライブラリで管理
- 受け取り、メモ付きの送金、履歴の確認
- Blocknet IDの `@name` への支払いや `blocknet://` 支払いリンクを開く操作
- アドレス帳、ウォレット間のメッセージ、自動ロックのタイマー、同期・ネットワーク・マイニング状況の画面

<img src="/assets/blog/gyroid-wallet-library.jpg" alt="Gyroid のウォレット一覧。Create、12 語からの Restore、Import view keys、Open file。フォルダーのパスはぼかしています。" width="1280" height="800" loading="lazy" />

ターミナル側も同じ機能を、`gyroid status`、`gyroid balance`、`gyroid address`、`gyroid history`、そして送金前に支払いをプレビューする `gyroid send <address> <amount> --dry-run` などのコマンドで提供します。全コマンドは `gyroid --help` で確認でき、メッセージ署名、支払い証明、閲覧専用ウォレットも含まれます。

Gyroidはインストール済みのBlocknet coreを使います。見つからない場合は最新のcoreリリースをダウンロードし、そのリリースのチェックサムリストと照合してから起動するため、ノードを自分で用意する必要はありません。

### Gyroidの動作に必要なものは？

WindowsとLinuxでは、GyroidにはVulkanグラフィックドライバーが必要です。Linuxではさらに、Waylandセッションとglibc 2.38以降が必要です。MacではApple siliconとmacOS 14以降が必要で、ディスクイメージから `Gyroid.app` をアプリケーションにコピーします。アプリは署名済みですがAppleの公証は受けていないため、初めて開くときはシステム設定のプライバシーとセキュリティで「このまま開く」を選んで許可してください。

## ウォレットのダウンロードが本物か確認するには？

<Answer>
同じリリースページからアーカイブとSHA256SUMSファイルをダウンロードし、アーカイブのSHA-256ハッシュを計算して、SHA256SUMSの該当行と比べます。3つのウォレットはすべて、リリースごとにこのファイルを公開しています。ハッシュが完全に一致した場合だけアーカイブをインストールし、ダウンロードは公式のリリースページからのみ行ってください。
</Answer>

LinuxまたはmacOSでは、両方のファイルがあるフォルダーで次を実行します。

```sh
sha256sum --ignore-missing --check SHA256SUMS.txt
```

`sha256sum` がないMacでは `shasum -a 256 -c SHA256SUMS.txt` を実行し、自分のファイルの行を確認してください。Gyroidのリストは `SHA256SUMS.txt` ではなく `SHA256SUMS` という名前です。`OK` で終わる行は、ファイルが一致したことを示します。

Windowsでは、ダウンロードフォルダーでPowerShellを開き、ハッシュを表示します。

```powershell
Get-FileHash .\gyroid-0.2.9-win-x64.zip
```

ファイル名をダウンロードしたアーカイブに置き換え、表示されたハッシュをチェックサムファイルの該当行と比べてください。[ウイルス対策ソフトの警告についてのガイド](/ja/blog/antivirus-flags-crypto-miner/)でも、seineのダウンロードに同じ確認方法を使っています。

## 同じウォレットを複数のアプリで使える？

はい。3つのアプリはどれも内部でBlocknet coreを動かすため、ウォレットが特定のアプリに縛られることはありません。別のアプリで12語の復元用単語から復元するか、ウォレットファイルのコピーをパスワードで読み込めば、ウォレットがチェーンをスキャンし終えた時点で同じアドレスと履歴が表示されます。

切り替える前に新しいバックアップを作り、復元用単語はオフラインで保管してください。移行後は、共有したり報酬の支払い先に設定したりする前に、受取アドレス全体を以前のアプリと照合します。[バックアップと復元のガイド](/ja/blog/blocknet-wallet-backup-restore/)では、両方の方法と、古いコピーを使わなくなる前に行う確認を手順ごとに説明しています。

## ウォレットのアドレスでBlocknetをマイニングする

どのウォレットを選んでも、その受取アドレスがマイニング報酬の支払い先アドレスになります。コピーしてseineに貼り付ければ、CPUとグラフィックカードでbntpool.comでのマイニングが始まります。報酬は同じウォレットに届き、ハッシュレートと残高はプールのMy Statsページで確認できます。[ウォレット・ノード・マイナーのガイド](/ja/blog/blocknet-wallet-node-miner/)では、マイニング中に開いておく必要があるプログラムを説明しています。
