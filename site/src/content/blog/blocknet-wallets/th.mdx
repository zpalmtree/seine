Blocknet มีแอปกระเป๋าสามแบบที่ติดตั้งได้วันนี้ ได้แก่ กระเป๋าเดสก์ท็อปทางการ กระเป๋าแบบบรรทัดคำสั่งทางการ และ Gyroid ซึ่งเป็นกระเป๋าแบบกราฟิกที่มีเครื่องมือบรรทัดคำสั่งในตัว คู่มือนี้เปรียบเทียบว่าแต่ละแบบใช้กับระบบใดและเด่นด้านใด แสดงวิธีตรวจไฟล์ที่ดาวน์โหลด และแนะนำคู่มือทีละขั้นตอนของแบบที่คุณเลือก

## ควรใช้กระเป๋า Blocknet แบบไหน?

<Answer>
เลือกกระเป๋าเดสก์ท็อปทางการหากต้องการแอปที่ใช้งานด้วยการคลิกบน Windows, macOS, Linux หรือ Android เลือกกระเป๋าแบบบรรทัดคำสั่งทางการสำหรับเซิร์ฟเวอร์ สคริปต์ และการใช้งานในเทอร์มินัล เลือก Gyroid หากต้องการกระเป๋าแบบกราฟิกพร้อมเครื่องมือบรรทัดคำสั่งในโปรแกรมเดียวกัน ทั้งสามแบบเก็บกุญแจไว้บนคอมพิวเตอร์ของคุณเองและรัน Blocknet core ให้คุณ
</Answer>

เวอร์ชันในตารางเป็นรุ่นล่าสุด ณ วันที่ 5 พฤศจิกายน 2026 หน้ารุ่นของแต่ละโปรเจกต์มีเวอร์ชันปัจจุบันเสมอ

## กระเป๋าเดสก์ท็อปทางการ

กระเป๋าเดสก์ท็อปคือแอปแบบกราฟิกที่เผยแพร่โดยโปรเจกต์ Blocknet แอปนี้รวม Blocknet core มาด้วย การติดตั้งแพ็กเกจเดียวจึงได้ทั้งโหนดและกระเป๋า คุณสร้างกระเป๋าด้วยรหัสผ่าน บันทึกคำกู้คืน แล้วใช้แถบด้านข้างเพื่อดูยอดคงเหลือ ที่อยู่รับเงิน การชำระเงิน และประวัติ

รุ่นปัจจุบันมีตัวติดตั้งสำหรับ Windows แพ็กเกจ AppImage, Debian, RPM และ Flatpak สำหรับ Linux บิลด์ macOS แยกสำหรับ Mac ที่ใช้ Apple silicon และ Mac Intel และแพ็กเกจ Android นี่คือทางที่ตรงที่สุดหากคุณไม่เคยใช้ Blocknet มาก่อน [คู่มือกระเป๋าเดสก์ท็อป](/th/blog/blocknet-desktop-wallet/) พาคุณตั้งแต่หน้าต้อนรับจนถึงการชำระเงินครั้งแรก พร้อมภาพหน้าจอทุกขั้นตอน

## กระเป๋าแบบบรรทัดคำสั่งทางการ

โปรแกรม `blocknet` คือกระเป๋าแบบเทอร์มินัลของโปรเจกต์ Blocknet โปรแกรมนี้ติดตั้ง เริ่ม และอัปเดต Blocknet core แล้วให้เชลล์กระเป๋าแบบโต้ตอบสำหรับยอดคงเหลือ ที่อยู่ การชำระเงิน ประวัติ หลักฐาน และกุญแจสำหรับดู การปิดเชลล์จะปล่อยให้ core ทำงานต่อในเบื้องหลัง จึงเหมาะกับเซิร์ฟเวอร์หรือคอมพิวเตอร์ที่เปิดตลอดเวลา

กระเป๋านี้รองรับแพลตฟอร์มมากที่สุดในสามแบบ มีบิลด์ x64 และ arm64 สำหรับ Linux และ macOS รวมถึง Windows และ Android คำสั่งต่างๆ ทำซ้ำและเขียนเป็นสคริปต์ได้ง่าย และการส่งเงินทุกครั้งจะแสดงตัวอย่างก่อนให้คุณยืนยัน [คู่มือกระเป๋าสำหรับนักขุด](/th/blog/blocknet-wallet-for-mining/) อธิบายการสร้างกระเป๋าด้วยโปรแกรมนี้ การสำรองคำกู้คืน และการคัดลอกที่อยู่ของคุณ

## Gyroid: กระเป๋าแบบกราฟิกที่มีเครื่องมือบรรทัดคำสั่ง

Gyroid เป็นกระเป๋า Blocknet แบบโอเพนซอร์สโดย obselate ผู้ร่วมพัฒนา Blocknet core เผยแพร่ภายใต้สัญญาอนุญาต MIT โปรแกรมเดียวมีทั้งอินเทอร์เฟซแบบกราฟิกและชุดคำสั่งเทอร์มินัลครบถ้วน คุณจึงจัดการกระเป๋าเดียวกันได้ทั้งสองแบบ

ฝั่งกราฟิกครอบคลุมสิ่งที่ต้องใช้ในชีวิตประจำวัน:

- สร้าง กู้คืน หรือนำเข้ากระเป๋า และเก็บหลายกระเป๋าไว้ในคลังเดียว
- รับเงิน ส่งเงินพร้อมบันทึกช่วยจำ และติดตามประวัติ
- ชำระเงินให้ Blocknet ID `@name` หรือเปิดลิงก์ชำระเงิน `blocknet://`
- สมุดที่อยู่ ข้อความระหว่างกระเป๋า ตัวจับเวลาล็อกอัตโนมัติ และหน้าจอสถานะการซิงก์ เครือข่าย และการขุด

ฝั่งเทอร์มินัลทำได้เหมือนกันด้วยคำสั่งอย่าง `gyroid status`, `gyroid balance`, `gyroid address`, `gyroid history` และ `gyroid send <address> <amount> --dry-run` เพื่อดูตัวอย่างการชำระเงินก่อนส่ง รัน `gyroid --help` เพื่อดูรายการทั้งหมด ซึ่งรวมถึงการลงนามข้อความ หลักฐานการชำระเงิน และกระเป๋าแบบดูอย่างเดียว

Gyroid ใช้ Blocknet core ที่ติดตั้งไว้แล้ว หากไม่พบ จะดาวน์โหลด core รุ่นล่าสุดและตรวจกับรายการ checksum ของรุ่นนั้นก่อนเริ่มใช้งาน คุณจึงไม่ต้องตั้งค่าโหนดเอง

### Gyroid ต้องใช้อะไรบ้างในการรัน?

บน Windows และ Linux นั้น Gyroid ต้องใช้ไดรเวอร์กราฟิก Vulkan บน Linux ยังต้องใช้เซสชัน Wayland และ glibc 2.38 ขึ้นไป บน Mac ต้องใช้ Apple silicon และ macOS 14 ขึ้นไป ให้คัดลอก `Gyroid.app` จากดิสก์อิมเมจไปยัง Applications แอปนี้ลงนามแล้วแต่ไม่ได้ผ่าน notarization ของ Apple ดังนั้นครั้งแรกที่เปิด ให้อนุญาตที่ System Settings, Privacy & Security, Open Anyway

## จะตรวจได้อย่างไรว่าไฟล์กระเป๋าที่ดาวน์โหลดเป็นของแท้?

<Answer>
ดาวน์โหลดไฟล์บีบอัดและไฟล์ SHA256SUMS จากหน้ารุ่นเดียวกัน แล้วคำนวณแฮช SHA-256 ของไฟล์บีบอัดและเทียบกับบรรทัดที่ตรงกันใน SHA256SUMS กระเป๋าทั้งสามแบบเผยแพร่ไฟล์นี้ในทุกรุ่น ติดตั้งไฟล์บีบอัดเฉพาะเมื่อแฮชตรงกันทุกตัว และดาวน์โหลดจากหน้ารุ่นทางการเท่านั้น
</Answer>

บน Linux หรือ macOS ให้รันคำสั่งนี้ในโฟลเดอร์ที่มีทั้งสองไฟล์:

```sh
sha256sum --ignore-missing --check SHA256SUMS.txt
```

บน Mac ที่ไม่มี `sha256sum` ให้รัน `shasum -a 256 -c SHA256SUMS.txt` แล้วอ่านบรรทัดของไฟล์คุณ รายการของ Gyroid ชื่อ `SHA256SUMS` ไม่ใช่ `SHA256SUMS.txt` บรรทัดที่ลงท้ายด้วย `OK` หมายความว่าไฟล์ตรงกัน

บน Windows ให้เปิด PowerShell ในโฟลเดอร์ดาวน์โหลดแล้วแสดงแฮช:

```powershell
Get-FileHash .\gyroid-0.2.9-win-x64.zip
```

เปลี่ยนชื่อไฟล์เป็นไฟล์บีบอัดที่คุณดาวน์โหลด แล้วเทียบแฮชกับบรรทัดของไฟล์นั้นในไฟล์ checksum [คู่มือเรื่องคำเตือนของแอนตี้ไวรัส](/th/blog/antivirus-flags-crypto-miner/) ใช้วิธีตรวจเดียวกันนี้กับไฟล์ดาวน์โหลดของ seine

## ใช้กระเป๋าเดียวกันในหลายแอปได้หรือไม่?

ได้ ทั้งสามแอปรัน Blocknet core อยู่เบื้องหลัง กระเป๋าจึงไม่ได้ผูกกับแอปใดแอปหนึ่ง กู้คืนกระเป๋าในอีกแอปด้วยคำกู้คืน 12 คำ หรือโหลดสำเนาไฟล์กระเป๋าพร้อมรหัสผ่าน แล้วคุณจะได้ที่อยู่และประวัติเดิมเมื่อกระเป๋าสแกนเชนเสร็จ

ก่อนสลับแอป ให้สำรองข้อมูลใหม่และเก็บคำกู้คืนไว้แบบออฟไลน์ หลังย้ายแล้ว ให้เทียบที่อยู่รับเงินแบบเต็มกับแอปเดิมก่อนแชร์หรือตั้งเป็นปลายทางรับเงินขุด [คู่มือสำรองและกู้คืน](/th/blog/blocknet-wallet-backup-restore/) อธิบายทั้งสองวิธีทีละขั้นตอน รวมถึงสิ่งที่ต้องตรวจก่อนเลิกใช้สำเนาเดิม
