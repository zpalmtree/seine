Ce guide vous accompagne du téléchargement du ZIP Windows jusqu’aux shares acceptés sur bntpool.com. Vous extrairez les fichiers, saisirez votre adresse de paiement et confirmerez que votre CPU et vos éventuelles cartes NVIDIA compatibles minent. Les commandes ci-dessous utilisent PowerShell et Windows en natif.

## Comment commencer à miner Blocknet sous Windows ?

<Answer>
Téléchargez `seine-windows-x86_64.zip`, extrayez toute l’archive et ouvrez `seine.exe`. Saisissez votre adresse Blocknet ou votre `@name` enregistré, puis acceptez `stratum+tcp://bntpool.com:3333` comme pool. seine sélectionne les moteurs CPU et NVIDIA disponibles, adapte le nombre de threads à la mémoire et commence ses réglages pendant le minage.
</Answer>

Préparez votre adresse publique de paiement avant d’ouvrir le mineur. Le [guide du portefeuille](/fr/blog/blocknet-wallet-for-mining/) explique comment en obtenir une. Saisissez uniquement l’adresse de réception : le mineur n’a besoin ni de la phrase de récupération ni des clés de dépense de votre portefeuille. Un [Blocknet ID](/fr/blog/blocknet-id-pay-by-name/) enregistré fonctionne aussi : vous pouvez donc utiliser `@name` à la place de la longue adresse.

## Étape 1 : télécharger la bonne version

Ouvrez la [section de téléchargement](/fr/#download) et choisissez Windows x86_64. L’archive s’appelle `seine-windows-x86_64.zip`.

![ZIP Windows dans le tableau officiel des téléchargements de seine](/assets/blog/setup-download.webp)

## Étape 2 : extraire et lancer

Dans l’Explorateur de fichiers, faites un clic droit sur le ZIP téléchargé et choisissez **Extraire tout**. Sélectionnez un dossier dans lequel vous pouvez écrire, puis ouvrez le dossier extrait. Gardez `seine.exe` et les DLL qui l’accompagnent ensemble : l’archive Windows contient les bibliothèques d’exécution NVIDIA utilisées par le mineur.

Double-cliquez sur `seine.exe` depuis le dossier extrait. Si vous préférez un terminal, ouvrez PowerShell dans ce dossier et exécutez :

```powershell
.\seine.exe
```

## Étape 3 : saisir l’adresse de votre portefeuille

Collez votre adresse publique de réception Blocknet ou votre `@name` enregistré, puis appuyez sur Entrée pour accepter `stratum+tcp://bntpool.com:3333`. Le [guide du portefeuille](/fr/blog/blocknet-wallet-for-mining/) explique où trouver votre adresse. Seine n’a besoin ni de votre phrase de récupération ni de vos clés de dépense. Il attribue automatiquement un nom au worker du pool.

## Étape 4 : vérifier les shares acceptées

<Answer>
Vérifiez que le tableau de bord de seine affiche un taux de hachage et des shares acceptés, puis recherchez la même adresse de paiement sur la page My Stats de bntpool.com. Le tableau de bord décrit le travail actuel du mineur ; le pool enregistre les shares soumis et les récompenses. Laissez le réglage automatique se stabiliser avant de comparer les taux ou de modifier les paramètres.
</Answer>

Le [guide du tableau de bord](/fr/blog/seine-dashboard-explained/) explique le taux de hachage, l’état du minage et les panneaux du pool. Un taux de hachage actif indique une activité locale de calcul ; un share accepté confirme que le travail est arrivé au pool. Ouvrez [My Stats](https://bntpool.com/stats?lang=fr) et saisissez la même adresse ou le même nom court pour suivre les shares et le solde de cette machine.

## Miner avec le CPU et NVIDIA sur le même PC

seine utilise par défaut le CPU et les cartes NVIDIA compatibles ensemble. Installez un pilote NVIDIA récent ; le ZIP Windows contient déjà les bibliothèques d’exécution, vous n’avez donc pas besoin d’installer séparément le CUDA Toolkit. Laissez les DLL extraites à côté de l’exécutable lorsque vous déplacez le dossier du mineur.

Au premier lancement, seine règle chaque GPU et mémorise ses paramètres. Le réglage du CPU s’effectue aussi pendant le minage. Le [guide du matériel](/fr/blog/blocknet-mining-hardware-hashrate/) explique le dimensionnement de la mémoire et les résultats mesurés, tandis que le [guide NVIDIA](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md) traite de l’utilisation de plusieurs cartes. Pour arrêter proprement, appuyez sur `q` dans le tableau de bord ou sur `Ctrl+C` dans le terminal.
