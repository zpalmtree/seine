本指南將帶你從下載 Windows ZIP，一直到在 bntpool.com 取得已接受的份額。你將解壓縮檔案、填寫收款地址，並確認 CPU 和支援的 NVIDIA 顯示卡正在挖礦。以下指令使用直接在 Windows 上執行的 PowerShell。

## 如何在 Windows 上開始挖 Blocknet？

<Answer>
下載 `seine-windows-x86_64.zip`，完整解壓縮，然後開啟 `seine.exe`。輸入 Blocknet 地址或已註冊的 `@name`，再接受 `stratum+tcp://bntpool.com:3333` 作為礦池。seine 會選擇可用的 CPU 和 NVIDIA 後端，依記憶體決定執行緒數，並在挖礦的同時開始調校。
</Answer>

開啟礦工程式前，請準備好公開收款地址。[錢包指南](/zh-hant/blog/blocknet-wallet-for-mining/)說明了如何取得地址。只需輸入收款地址：礦工程式不需要錢包助記詞或支出金鑰。已註冊的 [Blocknet ID](/zh-hant/blog/blocknet-id-pay-by-name/) 也可以使用，因此你能用 `@name` 代替長地址。

## 第 1 步：下載適合的版本

開啟[下載區域](/zh-hant/#download)，選擇 Windows x86_64。壓縮檔名為 `seine-windows-x86_64.zip`。

![seine 官方下載清單中的 Windows ZIP](/assets/blog/setup-download.webp)

## 第 2 步：解壓縮並啟動

在檔案總管中，以滑鼠右鍵按一下下載的 ZIP，選擇**全部解壓縮**。選擇有寫入權限的資料夾，然後開啟解壓縮後的資料夾。將 `seine.exe` 與附帶的 DLL 放在一起：Windows 壓縮檔包含礦工程式使用的 NVIDIA 執行階段程式庫。

在解壓縮後的資料夾中按兩下 `seine.exe`。如果偏好終端機，可以在該資料夾開啟 PowerShell 並執行：

```powershell
.\seine.exe
```

## 第 3 步：輸入錢包地址

貼上你的公開 Blocknet 收款地址或已註冊的 `@name`，然後按 Enter 接受 `stratum+tcp://bntpool.com:3333`。[錢包指南](/zh-hant/blog/blocknet-wallet-for-mining/)說明了在哪裡找到地址。seine 不需要復原詞組或支出金鑰，並會自動分配礦池礦機名稱。

## 第 4 步：查看已接受的份額

<Answer>
檢查 seine 儀表板是否顯示雜湊率和已接受的份額，然後在 bntpool.com 的 My Stats 頁面查詢同一收款地址。儀表板顯示礦工程式目前的工作；礦池記錄提交的份額與獎勵。比較速率或修改設定前，請先等待自動調校穩定下來。
</Answer>

[儀表板指南](/zh-hant/blog/seine-dashboard-explained/)介紹了雜湊率、挖礦狀態和礦池面板。運作中的雜湊率表示本機正在計算雜湊；已接受的份額則確認工作已送達礦池。開啟 [My Stats](https://bntpool.com/stats?lang=zh-hant)，輸入相同的地址或短名，即可追蹤這台礦機的份額和餘額。

## 在同一台 PC 上使用 CPU 和 NVIDIA 挖礦

seine 預設同時使用 CPU 和支援的 NVIDIA 顯示卡。安裝目前版本的 NVIDIA 驅動程式即可；Windows ZIP 已包含執行階段程式庫，因此不必另行安裝 CUDA Toolkit。移動礦工程式資料夾時，請將解壓縮後的 DLL 留在可執行檔旁邊。

首次啟動時，seine 會調校每張 GPU 並記住設定。CPU 調校也會在挖礦期間進行。[硬體指南](/zh-hant/blog/blocknet-mining-hardware-hashrate/)介紹了記憶體配置和實測結果，[NVIDIA 指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)則涵蓋多顯示卡使用。若要正常停止，請在儀表板按 `q`，或在終端機按 `Ctrl+C`。
