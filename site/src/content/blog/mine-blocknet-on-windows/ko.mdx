이 가이드는 Windows ZIP 다운로드부터 bntpool.com에서 셰어가 승인되는 단계까지 안내합니다. 파일을 추출한 뒤 지급 주소를 입력하고, CPU와 지원되는 NVIDIA 카드가 채굴하는지 확인합니다. 아래 명령은 Windows에서 직접 실행하는 PowerShell용입니다.

## Windows에서 Blocknet 채굴을 어떻게 시작하나요?

<Answer>
`seine-windows-x86_64.zip`을 다운로드하고 전체 압축을 푼 뒤 `seine.exe`를 엽니다. Blocknet 주소 또는 등록된 `@name`을 입력한 다음 풀로 `stratum+tcp://bntpool.com:3333`을 그대로 사용합니다. seine은 사용 가능한 CPU 및 NVIDIA 백엔드를 선택하고 메모리에 맞춰 스레드 수를 정한 뒤 채굴하면서 튜닝을 시작합니다.
</Answer>

채굴 프로그램을 열기 전에 공개 지급 주소를 준비하세요. [지갑 가이드](/ko/blog/blocknet-wallet-for-mining/)에서 주소를 얻는 방법을 설명합니다. 수신 주소만 입력하세요. 채굴 프로그램에는 지갑 시드 문구나 지출 키가 필요하지 않습니다. 등록된 [Blocknet ID](/ko/blog/blocknet-id-pay-by-name/)도 사용할 수 있으므로 긴 주소 대신 `@name`을 지정할 수 있습니다.

## 1단계: 알맞은 빌드 다운로드

[다운로드 섹션](/ko/#download)을 열고 Windows x86_64를 선택하세요. 압축 파일 이름은 `seine-windows-x86_64.zip`입니다.

![seine 공식 다운로드 표의 Windows ZIP](/assets/blog/setup-download.webp)

## 2단계: 압축 해제 후 실행

파일 탐색기에서 다운로드한 ZIP을 마우스 오른쪽 버튼으로 클릭하고 **모두 압축 풀기**를 선택하세요. 쓰기 권한이 있는 폴더를 선택한 뒤 압축을 푼 폴더를 엽니다. `seine.exe`와 함께 제공되는 DLL을 같은 곳에 보관하세요. Windows 압축 파일에는 채굴 프로그램이 사용하는 NVIDIA 런타임 라이브러리가 포함되어 있습니다.

압축을 푼 폴더에서 `seine.exe`를 두 번 클릭하세요. 터미널을 선호한다면 해당 폴더에서 PowerShell을 열고 다음을 실행하세요.

```powershell
.\seine.exe
```

## 3단계: 지갑 주소 입력

공개 Blocknet 수신 주소나 등록한 `@name`을 붙여 넣고 Enter를 눌러 `stratum+tcp://bntpool.com:3333`을 선택하세요. 주소를 찾는 방법은 [지갑 안내](/ko/blog/blocknet-wallet-for-mining/)에 있습니다. seine은 복구 문구나 지출 키를 요구하지 않습니다. 풀 워커 이름은 자동으로 지정됩니다.

## 4단계: 승인된 셰어 확인

<Answer>
seine 대시보드에 해시레이트와 승인된 셰어가 표시되는지 확인한 뒤 bntpool.com의 My Stats 페이지에서 같은 지급 주소를 검색하세요. 대시보드는 채굴 프로그램의 현재 작업을 보여주고, 풀은 제출된 셰어와 보상을 기록합니다. 속도를 비교하거나 설정을 바꾸기 전에 자동 튜닝이 안정될 때까지 기다리세요.
</Answer>

[대시보드 가이드](/ko/blog/seine-dashboard-explained/)는 해시레이트, 채굴 상태, 풀 패널을 설명합니다. 실행 중인 해시레이트는 로컬 해시 계산을 나타내며, 승인된 셰어는 작업이 풀에 도달했음을 확인해 줍니다. [My Stats](https://bntpool.com/stats?lang=ko)를 열고 같은 주소나 단축 이름을 입력하여 이 리그의 셰어와 잔액을 확인하세요.

## 같은 PC에서 CPU와 NVIDIA로 채굴하기

seine은 기본적으로 CPU와 지원되는 NVIDIA 카드를 함께 사용합니다. 최신 NVIDIA 드라이버를 설치하세요. Windows ZIP에 런타임 라이브러리가 이미 포함되어 있으므로 CUDA Toolkit을 별도로 설치할 필요가 없습니다. 채굴 프로그램 폴더를 옮길 때 압축을 푼 DLL을 실행 파일 옆에 그대로 두세요.

처음 실행하면 seine이 각 GPU를 튜닝하고 설정을 기억합니다. CPU 튜닝도 채굴 중에 진행됩니다. [하드웨어 가이드](/ko/blog/blocknet-mining-hardware-hashrate/)는 메모리 할당과 측정 결과를 설명하며, [NVIDIA 가이드](https://github.com/zpalmtree/seine/blob/master/docs/guides/nvidia.md)는 여러 카드 사용을 다룹니다. 정상적으로 종료하려면 대시보드에서 `q`를 누르거나 터미널에서 `Ctrl+C`를 누르세요.
