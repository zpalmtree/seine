실제로 사용하는 앱과 채굴을 함께 할 수 있도록 seine를 설정하세요. 이 가이드는 seine v0.3.1에서 데스크톱을 공유하는 방법으로 장치 선택, 여유 메모리 확보, 더 적은 CPU 스레드 수 시험, 재현 가능한 실행을 다룹니다. 작동 중인 채굴 설정에서 시작하고 주소, 풀, 작업 디렉터리는 그대로 두세요.

## 채굴 중에 컴퓨터를 사용할 수 있나요?

<Answer>
네. 데스크톱 작업에 맞춰 채굴 백엔드와 CPU 스레드 수를 선택한 뒤 평소 앱을 연 상태에서 반응성을 확인하세요. 사용 가능한 메모리, 장치 활동, 승인된 셰어를 함께 살펴보세요. 부하가 큰 게임이나 렌더링은 채굴기를 정상 종료한 뒤 진행하고, 작업이 끝나면 저장한 실행 방식으로 재개하세요.
</Answer>

## 원활하게 쓰고 싶은 작업부터 시작하세요

채굴 구성을 선택하기 전에 평소 쓰는 앱을 여세요. 브라우저 탭 전환, 문서 편집, 프로젝트 탐색 등 대표적인 동작을 해 보세요. 채굴하지 않을 때의 반응을 기록한 뒤 현재 채굴기를 실행하며 같은 동작을 반복하세요. 작업과 앱 상태를 비슷하게 유지해야 비교가 유용한 질문에 답할 수 있습니다.

이런 체감과 함께 CPU, 메모리, GPU 활동을 살펴보세요. Windows [작업 관리자](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)는 앱별 자원 사용량을 보여 주며 다른 운영체제에도 모니터링 도구가 있습니다. 사용률 하나만으로 다른 작업을 추가할 여유가 충분한지 판단할 수는 없습니다. [CPU 사용률 가이드](/ko/blog/miner-cpu-usage/)는 채굴기 쪽 비율과 장치 활동을 더 자세히 설명합니다.

## 어떤 장치로 채굴해야 하나요?

앞에서 사용하는 앱에 맞춰 장치를 고르세요. 백엔드를 자동 선택하면 seine는 CPU와 감지한 지원 NVIDIA 장치를 사용합니다. 기존 실행 명령에 `--backend cpu`를 추가하면 CPU 채굴만 선택하고 NVIDIA 채굴 백엔드는 사용하지 않습니다. 그래도 시스템 RAM과 CPU 시간은 데스크톱 작업을 수용해야 합니다. 실행 후 활성 장치 행을 확인하세요.

지원되는 NVIDIA 환경에서는 CPU 채굴을 끄고 싶을 때 대신 `--backend nvidia`를 쓸 수 있습니다. 이때 GPU 메모리와 연산 자원은 같은 카드를 쓰는 그래픽 앱과 공유합니다. 이 선택이 CPU 전체를 다른 소프트웨어에 예약하는 것은 아닙니다. 실행 환경 요구 사항과 카드 선택은 [NVIDIA 가이드](/ko/blog/mine-blocknet-nvidia-gpu/)를 따르고 비교할 원래 명령을 보관하세요.

## 자동 조정 범위나 고정 스레드 수를 선택하세요

CPU 자동 조정에는 `--cpu-profile efficiency`를 고려하세요. 이 프로필은 목표 해시레이트에 가까운 더 적은 스레드 수를 선호하며, 와트를 측정하거나 데스크톱 응답 시간 목표를 강제하지 않습니다. 검색 상한의 예로 `--cpu-autotune-max-threads 2`를 지정할 수 있습니다. 자신의 컴퓨터에 알맞은 수를 정하고 재정의 옵션을 조합하기 전에 [자동 조정 가이드](/ko/blog/seine-automatic-cpu-tuning/)를 읽으세요.

의도적으로 고정된 비교를 하려면 `--threads 2`가 CPU 백엔드마다 두 스레드를 선택하며 보통 CPU 자동 조정을 끕니다. 시험 설정이지 모든 컴퓨터에 권장하는 값은 아닙니다. 대시보드에서 `-`는 CPU 백엔드마다 한 스레드를 줄입니다. 변경은 실행 중인 CPU 스레드에 적용되며 GPU와 풀 연결은 계속 동작합니다. 자동 튜닝이 아직 스레드 수를 고르는 중이면 대시보드가 남은 시간을 보여 주고 스레드 수를 바꾸지 않습니다. 고정된 `--threads`로 시작했다면 대신 채굴을 재시작하고 세션 통계는 유지합니다. 변경이 안정된 뒤 결과를 판단하세요.

## 다른 데스크톱 작업에 쓸 메모리를 남겨 두세요

활성 CPU 채굴 스레드마다 2 GiB Argon2id 영역을 사용하며 프로세스의 추가 메모리도 필요합니다. 두 영역은 운영체제나 다른 앱을 계산하기 전부터 4 GiB를 차지합니다. 평소 작업을 연 상태의 사용 가능한 메모리로 예산을 잡으세요. 브라우저 탭, 편집기, 그래픽 프로젝트의 필요량은 하루 중에도 변하므로 설치된 RAM만으로는 충분히 계산할 수 없습니다.

자동 크기 산정은 설정한 메모리 여유분을 남기지만 명시적인 스레드 수는 그 여유분을 무시합니다. 따라서 고정 수는 직접 메모리를 확인해야 하며, 앞으로 열 모든 앱에 RAM이 충분하다는 자동 보장은 아닙니다. 산정 규칙은 [RAM 계획 가이드](/ko/blog/how-much-ram-to-mine-blocknet/)를 따르세요. 평소 작업에 더 많은 공간이 필요하면 스레드를 줄이고 같은 데스크톱 작업을 다시 비교하세요.

## 다른 작업을 위해 언제 채굴을 멈추면 좋나요?

중요한 통화, 무거운 게임, 렌더링 작업에는 대시보드의 `q`나 터미널의 `Ctrl+C`로 종료하는 명확한 방법이 있습니다. 채굴기가 종료됐는지 확인한 뒤 앞에서 쓰는 작업만 따로 평가하세요. 이후 기록한 명령을 다시 실행하면 됩니다. 계정 설정 변경, 구성 파일 삭제, 운영체제 보호 기능 수정 없이 깔끔한 비교가 가능합니다.

일상 사용 중에는 정상적인 냉각과 전원 구성을 유지하세요. 컴퓨터 자체의 온도·전력 지표를 살펴보세요. 여기서는 특정 온도나 팬 설정을 지정하지 않습니다. 절전 중인 컴퓨터는 깨어 있을 때처럼 채굴 세션을 계속하지 않습니다. 예상치 못한 종료나 절전으로 작업이 끊기면 다른 설정을 바꾸기 전에 [중단 가이드](/ko/blog/miner-keeps-stopping/)로 어떤 일이 일어났는지 확인하세요.

## 일상에 맞는 실행 방식을 저장하세요

데스크톱이 원활해지면 전체 실행 명령, 작업 디렉터리, 선택한 백엔드를 기록하세요. 대시보드 스레드 변경은 세션에만 적용되므로 반복할 수는 실행 인수로 지정하세요. [구성 가이드](/ko/blog/configure-seine-miner/)는 저장되는 연결 필드와 다른 명령줄 선택을 구분합니다. 데스크톱 사용과 무인 세션에 다른 설정을 둔다면 별도 바로가기에 알기 쉬운 이름을 붙이세요.

다음 실행이 이전 세션과 같다고 가정하지 말고 검증하세요. 장치 행, 활성 CPU 스레드, 사용 가능한 메모리, 새로 승인된 셰어를 확인하고 처음의 데스크톱 동작을 반복하세요. [풀 추적 가이드](https://bntpool.com/blog/ko/track-your-miner-on-bntpool/)는 반영된 작업을 확인하는 데 도움이 됩니다. 유용한 일상 설정은 평소 앱이 제 역할을 계속하면서도 재현할 수 있는 설정입니다.
