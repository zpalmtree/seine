ตั้งค่า seine ให้การขุดทำงานร่วมกับแอปที่คุณใช้จริงได้ คู่มือนี้อธิบายการใช้คอมพิวเตอร์ร่วมกับ seine v0.3.1 ได้แก่ การเลือกอุปกรณ์ การเผื่อหน่วยความจำ การลองลดเธรด CPU และการเก็บวิธีเริ่มที่ทำซ้ำได้ เริ่มจากการตั้งค่าขุดที่ใช้งานได้อยู่แล้ว และคงที่อยู่ พูล และไดเรกทอรีทำงานเดิมไว้

## ใช้คอมพิวเตอร์ระหว่างขุดได้ไหม?

<Answer>
ได้ เลือกแบ็กเอนด์ขุดและจำนวนเธรด CPU ให้เหมาะกับงานบนคอมพิวเตอร์ แล้วตรวจสอบการตอบสนองขณะเปิดแอปตามปกติ ดูหน่วยความจำที่ว่าง กิจกรรมอุปกรณ์ และแชร์ที่ยอมรับร่วมกัน หากจะเล่นเกมหรือเรนเดอร์ที่ใช้ทรัพยากรมาก ให้ปิดโปรแกรมขุดตามปกติ แล้วเริ่มด้วยวิธีที่บันทึกไว้เมื่องานเสร็จ
</Answer>

## เริ่มจากงานที่ต้องการให้ตอบสนองได้ดี

เปิดแอปที่ใช้ตามปกติก่อนเลือกการตั้งค่าขุด ลองการกระทำที่สะท้อนการใช้งาน เช่น สลับแท็บเบราว์เซอร์ แก้เอกสาร หรือเลื่อนไปมาในโปรเจกต์ สังเกตความรู้สึกขณะยังไม่ขุด แล้วทำซ้ำเมื่อโปรแกรมขุดปัจจุบันกำลังทำงาน คงงานและสถานะแอปให้ใกล้เคียงกันเพื่อให้การเปรียบเทียบตอบคำถามที่เป็นประโยชน์

ตรวจสอบกิจกรรม CPU หน่วยความจำ และ GPU ควบคู่กับประสบการณ์นั้น [ตัวจัดการงาน](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows) ของ Windows แสดงการใช้ทรัพยากรแยกตามแอปได้ ส่วนระบบปฏิบัติการอื่นมีเครื่องมือตรวจสอบของตนเอง เปอร์เซ็นต์การใช้งานเพียงค่าเดียวไม่ได้ยืนยันว่าคอมพิวเตอร์มีทรัพยากรเหลือพอสำหรับงานเพิ่ม [คู่มือการใช้ CPU](/th/blog/miner-cpu-usage/) อธิบายเปอร์เซ็นต์ฝั่งโปรแกรมขุดและกิจกรรมอุปกรณ์อย่างละเอียด

## ควรใช้อุปกรณ์ใดขุด?

เลือกอุปกรณ์ตามแอปที่กำลังใช้งานอยู่ เมื่อเลือกแบ็กเอนด์อัตโนมัติ seine จะใช้ CPU และอุปกรณ์ NVIDIA ที่รองรับซึ่งตรวจพบ การเพิ่ม `--backend cpu` ในคำสั่งเดิมเลือกขุดด้วย CPU อย่างเดียว และไม่ใช้แบ็กเอนด์ขุด NVIDIA ถึงอย่างนั้น RAM ระบบและเวลาของ CPU ยังต้องเพียงพอสำหรับงานเดสก์ท็อป ตรวจสอบแถวอุปกรณ์ที่ทำงานหลังเริ่มโปรแกรม

หากมีระบบ NVIDIA ที่รองรับ คุณสามารถใช้ `--backend nvidia` แทนเมื่อต้องการปิดการขุด CPU หน่วยความจำ GPU และการประมวลผล GPU จะใช้ร่วมกับแอปกราฟิกที่ใช้การ์ดนั้น การเลือกนี้ไม่ได้สงวน CPU ทั้งหมดให้ซอฟต์แวร์อื่น ทำตาม[คู่มือ NVIDIA](/th/blog/mine-blocknet-nvidia-gpu/) สำหรับข้อกำหนดรันไทม์และการเลือกการ์ด พร้อมเก็บคำสั่งเดิมไว้เปรียบเทียบ

## เลือกช่วงปรับอัตโนมัติหรือจำนวนเธรดคงที่

สำหรับการปรับ CPU อัตโนมัติ ลองพิจารณา `--cpu-profile efficiency` โปรไฟล์นี้เน้นจำนวนเธรดที่น้อยลงใกล้เป้าหมายแฮชเรต ไม่ได้วัดวัตต์หรือบังคับเป้าหมายเวลาตอบสนองของเดสก์ท็อป คุณจำกัดช่วงค้นหาได้ด้วย `--cpu-autotune-max-threads 2` ซึ่งเป็นเพียงตัวอย่างเพดาน เลือกจำนวนที่เหมาะกับเครื่องของคุณ และอ่าน[คู่มือการปรับอัตโนมัติ](/th/blog/seine-automatic-cpu-tuning/) ก่อนใช้ตัวเลือกแทนค่าร่วมกัน

หากต้องการเปรียบเทียบด้วยค่าคงที่อย่างตั้งใจ `--threads 2` จะเลือกสองเธรดต่อแบ็กเอนด์ CPU และโดยปกติจะปิดการปรับ CPU อัตโนมัติ นี่เป็นค่าทดลอง ไม่ใช่คำแนะนำสำหรับทุกเครื่อง ในแดชบอร์ด `-` ลดหนึ่งเธรดต่อแบ็กเอนด์ CPU การเปลี่ยนนี้มีผลกับเธรด CPU ที่กำลังทำงานอยู่ ขณะที่ GPU และการเชื่อมต่อพูลยังทำงานต่อ หากการปรับจูนอัตโนมัติยังเลือกจำนวนเธรดอยู่ แดชบอร์ดจะแสดงเวลาที่เหลือและไม่เปลี่ยนจำนวนนั้น หากคุณเริ่มด้วย `--threads` แบบคงที่ การเปลี่ยนจะเริ่มการขุดใหม่แทนและเก็บสถิติเซสชันไว้ รอให้ผลคงที่ก่อนตัดสิน

## เผื่อหน่วยความจำให้ส่วนอื่นของเดสก์ท็อป

เธรดขุด CPU ที่ทำงานแต่ละเธรดใช้พื้นที่ Argon2id ขนาด 2 GiB และยังมีหน่วยความจำส่วนอื่นของกระบวนการ พื้นที่สองชุดจึงใช้ 4 GiB ก่อนนับระบบปฏิบัติการและแอปอื่น คำนวณจากหน่วยความจำที่ว่างขณะเปิดงานตามปกติ แท็บเบราว์เซอร์ ตัวแก้ไข และโปรเจกต์กราฟิกอาจเปลี่ยนความต้องการระหว่างวัน ดังนั้น RAM ที่ติดตั้งเพียงอย่างเดียวจึงไม่ใช่งบประมาณที่ครบถ้วน

การกำหนดขนาดอัตโนมัติเผื่อหน่วยความจำตามที่ตั้งไว้ แต่การระบุจำนวนเธรดโดยตรงจะข้ามส่วนเผื่อนั้น จำนวนคงที่จึงต้องอาศัยการตรวจสอบหน่วยความจำของคุณเอง ไม่ใช่การรับประกันอัตโนมัติว่า RAM จะพอสำหรับทุกแอปที่จะเปิดภายหลัง ทำตาม[คู่มือวางแผน RAM](/th/blog/how-much-ram-to-mine-blocknet/) สำหรับกฎการกำหนดขนาด เลือกจำนวนน้อยลงเมื่องานปกติต้องการพื้นที่เพิ่ม แล้วเปรียบเทียบงานเดสก์ท็อปเดิมอีกครั้ง

## ควรหยุดขุดเพื่อทำงานอื่นเมื่อใด?

สำหรับสายสนทนาสำคัญ เกมที่หนัก หรือการเรนเดอร์ ทางเลือกที่ชัดเจนคือออกด้วย `q` ในแดชบอร์ดหรือ `Ctrl+C` ในเทอร์มินัล ยืนยันว่าโปรแกรมขุดออกแล้วก่อนประเมินงานหลักเพียงอย่างเดียว จากนั้นเรียกคำสั่งที่จดไว้อีกครั้ง วิธีนี้ให้การเปรียบเทียบที่ชัดเจนโดยไม่ต้องเปลี่ยนการตั้งค่าบัญชี ลบไฟล์ตั้งค่า หรือแก้การป้องกันของระบบปฏิบัติการ

คงระบบระบายความร้อนและแหล่งจ่ายไฟตามปกติระหว่างใช้งานประจำวัน สังเกตตัวชี้วัดอุณหภูมิและพลังงานของเครื่องเอง คู่มือนี้ไม่ได้กำหนดอุณหภูมิหรือค่าพัดลมเฉพาะ เครื่องที่เข้าสลีปไม่ทำเซสชันขุดต่อเหมือนขณะตื่น หากการออกโดยไม่คาดคิดหรือการสลีปขัดจังหวะงาน ใช้[คู่มือกรณีโปรแกรมหยุด](/th/blog/miner-keeps-stopping/) เพื่อระบุเหตุการณ์ก่อนเปลี่ยนค่าอื่นเพิ่ม

## บันทึกวิธีเริ่มที่เหมาะกับกิจวัตรประจำวัน

เมื่อเดสก์ท็อปตอบสนองได้ดีแล้ว จดคำสั่งเริ่มทั้งหมด ไดเรกทอรีทำงาน และแบ็กเอนด์ที่เลือก การปรับเธรดในแดชบอร์ดอยู่เฉพาะเซสชัน จึงควรใช้พารามิเตอร์เริ่มสำหรับจำนวนที่ต้องการทำซ้ำ [คู่มือการตั้งค่า](/th/blog/configure-seine-miner/) แยกช่องการเชื่อมต่อที่บันทึกได้ออกจากตัวเลือกบรรทัดคำสั่งอื่น ตั้งชื่อทางลัดแยกให้ชัดหากเก็บค่าต่างกันสำหรับการใช้งานเดสก์ท็อปและช่วงไม่มีผู้เฝ้า

ตรวจสอบการเริ่มครั้งต่อไปแทนการสมมติว่าจะเหมือนเซสชันก่อน ดูแถวอุปกรณ์ เธรด CPU ที่ทำงาน หน่วยความจำว่าง และแชร์ใหม่ที่ยอมรับ แล้วทำการกระทำเดสก์ท็อปที่เริ่มต้นไว้อีกครั้ง [คู่มือติดตามบนพูล](https://bntpool.com/blog/th/track-your-miner-on-bntpool/) ช่วยยืนยันงานที่ได้รับเครดิต การตั้งค่าประจำวันที่มีประโยชน์คือสิ่งที่ทำซ้ำได้ ขณะที่แอปปกติยังทำงานของตนต่อไป
