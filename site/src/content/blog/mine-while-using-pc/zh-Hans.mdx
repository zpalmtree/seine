让 seine 的挖矿配置配合你实际使用的应用。本指南针对 seine v0.3.1，介绍设备选择、内存余量、减少 CPU 线程和可重复启动。请从已经正常工作的挖矿配置开始，保持地址、矿池和工作目录不变。

## 挖矿时还能使用电脑吗？

<Answer>
可以。根据桌面任务选择挖矿后端和 CPU 线程数，在日常应用打开时检查响应，同时观察可用内存、设备活动和已接受份额。遇到负载较高的游戏或渲染任务，可以正常退出矿工程序，完成后再按记录的命令启动。
</Answer>

## 先确定需要保持流畅的任务

打开平时使用的应用，尝试有代表性的操作，例如切换浏览器标签、编辑文档或浏览项目。先观察不挖矿时的响应，再开启矿工程序重复操作。保持任务和应用状态相近，才能让比较回答具体问题。

同时查看 CPU、内存和 GPU 活动。Windows 的[任务管理器](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)可以显示各应用的资源使用，其他系统也有相应工具。单个占用百分比不能证明仍有足够余量运行另一项任务。[CPU 使用指南](/zh-hans/blog/miner-cpu-usage/)进一步解释矿工程序的百分比和设备活动。

## 应该让哪个设备挖矿？

根据前台应用选择。自动选择后端时，seine 会使用 CPU 和检测到的受支持 NVIDIA 设备。在现有启动参数中加入 `--backend cpu`，即可只用 CPU 挖矿，不使用 NVIDIA 挖矿后端。CPU 时间和系统内存仍与桌面共享，启动后请核对设备行。

受支持的 NVIDIA 配置可以使用 `--backend nvidia` 关闭 CPU 挖矿。同一卡上的图形应用仍共享 GPU 内存和执行资源；这并不等于把整个 CPU 专门留给其他软件。运行库要求和显卡选择见 [NVIDIA 指南](/zh-hans/blog/mine-blocknet-nvidia-gpu/)，并保留原命令供比较。

## 选择自动范围或固定线程数

自动 CPU 调优可考虑 `--cpu-profile efficiency`。它倾向于用较少线程接近自己的算力目标，不测量瓦数，也不设定桌面响应时间目标。`--cpu-autotune-max-threads 2` 是搜索上限的示例。按自己的机器选择数量，在组合覆盖选项前阅读[自动调优指南](/zh-hans/blog/seine-automatic-cpu-tuning/)。

要进行固定数量的比较，`--threads 2` 会为每个 CPU 后端选择两个线程，通常关闭 CPU 自动调优。这是测试设置，并非通用建议。面板中的 `-` 为每个 CPU 后端减少一个线程；调整作用于正在运行的 CPU 线程，GPU 和矿池连接继续运行。自动调优仍在选择线程数时，仪表盘会显示剩余时间，并保持线程数不变。如果启动时用了固定的 `--threads`，调整会改为重启挖矿，同时保留会话统计。等结果稳定后再判断效果。

## 为其余桌面应用保留内存

每个活跃 CPU 挖矿线程使用一个 2 GiB 的 Argon2id 内存区域，另有进程开销。两个区域就是 4 GiB，尚未计入操作系统和其他应用。应根据正常工作打开时的可用内存规划。标签页、编辑器和图形项目的需求会随使用变化，仅看已安装 RAM 并不完整。

自动确定规模时会留下配置好的内存余量，但显式线程数会覆盖这项预留。固定数量需要自行检查内存，不保证今后打开的每个应用都有足够空间。[RAM 规划指南](/zh-hans/blog/how-much-ram-to-mine-blocknet/)说明具体规则。如果工作需要更多余量，就减少线程，再重复相同的桌面任务。

## 什么时候应为其他任务停止挖矿？

遇到重要通话、负载较高的游戏或渲染，可在面板按 `q`，或在终端按 `Ctrl+C` 退出。确认矿工进程已结束，再单独判断前台任务的表现，之后运行记录的命令恢复。这样无需更改账户、删除配置文件或修改系统防护。

日常使用时保持正常散热和供电，观察电脑自身的温度与电源指标。本指南不规定特定温度或风扇设置。电脑睡眠后不会像清醒时一样继续挖矿。遇到意外退出或睡眠，应先用[停止运行指南](/zh-hans/blog/miner-keeps-stopping/)识别事件，再考虑更多设置改动。

## 保存适合日常使用的启动方式

桌面响应合适后，记录完整命令、工作目录和所选后端。面板线程调整仅对当前会话有效；需要重复的数量应写入启动参数。[配置指南](/zh-hans/blog/configure-seine-miner/)区分保存的连接字段和其他命令行选项。如果分别保留桌面使用和无人值守设置，请给快捷方式清楚命名。

验证下一次启动，而不是假设它与之前相同。检查设备行、活跃 CPU 线程、可用内存和新接受的份额，再重复最初的桌面操作。[矿池跟踪指南](https://bntpool.com/blog/zh-hans/track-your-miner-on-bntpool/)帮助确认工作已计入。实用的日常配置应能重复使用，同时让常用应用继续完成任务。
