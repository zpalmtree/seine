設定 seine，讓挖礦配合你實際使用的應用程式。本指南說明 seine v0.3.1 共用桌面電腦的方法，包括選擇裝置、保留可用記憶體、嘗試較少的 CPU 執行緒，以及保留可重現的啟動方式。請從能正常挖礦的設定開始，保持原本的地址、礦池與工作目錄不變。

## 挖礦時可以使用電腦嗎？

<Answer>
可以。按照日常工作選擇挖礦後端與 CPU 執行緒數，再開啟平常的應用程式檢查反應。同時觀察可用記憶體、裝置活動和已接受的份額。進行高負載遊戲或算圖時，請正常關閉礦工程式，工作結束後再用已儲存的方式啟動。
</Answer>

## 從需要保持順暢的工作開始

選擇挖礦設定前，先開啟平常使用的應用程式。試做代表性的操作，例如切換瀏覽器分頁、編輯文件或在專案中移動。記錄未挖礦時的感受，再於目前的礦工程式運作時重做。保持工作與應用程式狀態相近，才能讓比較回答有用的問題。

除了操作感受，也檢查 CPU、記憶體與 GPU 活動。Windows [工作管理員](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)可顯示各應用程式的資源用量，其他作業系統也有自己的監控工具。單一使用率不能證明桌面還有足夠空間容納另一項工作。[CPU 使用率指南](/zh-hant/blog/miner-cpu-usage/)更詳細地說明礦工端的百分比與裝置活動。

## 應該讓哪個裝置挖礦？

根據前景應用程式選擇裝置。自動選擇後端時，seine 會使用 CPU 與偵測到的支援 NVIDIA 裝置。在原有啟動指令加入 `--backend cpu` 會只選 CPU 挖礦，不使用 NVIDIA 挖礦後端。系統 RAM 與 CPU 時間仍須容納桌面工作。啟動後請確認正在運作的裝置列。

支援的 NVIDIA 環境也可改用 `--backend nvidia`，讓 CPU 挖礦停用。這時 GPU 記憶體與 GPU 執行資源會與同卡的圖形應用程式共用；這個選擇並不是把整個 CPU 保留給其他軟體。請依照 [NVIDIA 指南](/zh-hant/blog/mine-blocknet-nvidia-gpu/)確認執行環境需求與顯示卡選擇，並保留原指令作比較。

## 選擇自動調校範圍或固定執行緒數

需要自動調校 CPU 時，可考慮 `--cpu-profile efficiency`。這個設定檔偏好接近目標算力的較少執行緒數，不會量測瓦數或強制達成桌面回應時間目標。你可以用 `--cpu-autotune-max-threads 2` 作為搜尋上限的例子。請選擇適合自身電腦的數量，在搭配覆寫選項前閱讀[自動調校指南](/zh-hant/blog/seine-automatic-cpu-tuning/)。

若要刻意用固定值比較，`--threads 2` 會為每個 CPU 後端選擇兩個執行緒，通常也會停用 CPU 自動調校。這是測試設定，不是適合所有人的建議。儀表板中的 `-` 會讓每個 CPU 後端減少一個執行緒；調整會套用到正在執行的 CPU 執行緒，GPU 和礦池連線會繼續運作。自動調校仍在選擇執行緒數時，儀表板會顯示剩餘時間，並保持執行緒數不變。如果啟動時使用固定的 `--threads`，調整會改為重新啟動挖礦，同時保留本次工作階段統計。請等結果穩定後再評估。

## 為桌面其他工作保留記憶體

每個運作中的 CPU 挖礦執行緒使用 2 GiB 的 Argon2id 記憶體區域，程序另有額外開銷。兩個這類區域就占 4 GiB，還沒計算作業系統與其他應用程式。請以平常工作開啟時的可用記憶體做預算。瀏覽器分頁、編輯器與圖形專案的需求可能在一天中改變，因此只看已安裝 RAM 並不完整。

自動配置會留下設定的記憶體保留量，但明確指定的執行緒數會覆寫這項保留。因此固定數量需要你自行檢查記憶體，不代表自動保證未來每個應用程式都有足夠 RAM。配置規則請參閱 [RAM 規劃指南](/zh-hant/blog/how-much-ram-to-mine-blocknet/)。當平常工作需要更多空間時，優先選較少執行緒，再比較同一項桌面操作。

## 何時應為其他工作停止挖礦？

重要通話、高負載遊戲或算圖工作前，可以在儀表板按 `q`，或在終端機按 `Ctrl+C` 離開。先確認礦工程式已結束，再單獨評估前景工作。之後重新執行記錄的指令即可。這樣能進行清楚的比較，不必更動帳戶設定、刪除設定檔或修改作業系統防護。

日常使用時，請維持正常的散熱與供電安排。觀察電腦自身的溫度與電力指標；本指南不指定特定溫度或風扇設定。睡眠中的電腦不會像清醒時一樣持續挖礦。如果意外結束或睡眠中斷工作，請先用[停止挖礦指南](/zh-hant/blog/miner-keeps-stopping/)辨識事件，再修改更多設定。

## 儲存符合日常習慣的啟動方式

當桌面反應合適後，記錄完整啟動指令、工作目錄與所選後端。儀表板執行緒調整只限本次工作階段，想重複使用的數量應寫入啟動參數。[設定指南](/zh-hant/blog/configure-seine-miner/)區分可儲存的連線欄位與其他命令列選項。如果為桌面使用與無人操作保留不同設定，請替各捷徑取清楚的名稱。

確認下次啟動，而非假設它與前次工作階段相同。檢查裝置列、運作中的 CPU 執行緒、可用記憶體與新接受的份額，再重做最初的桌面操作。[礦池追蹤指南](https://bntpool.com/blog/zh-hant/track-your-miner-on-bntpool/)可協助確認已計入的工作。實用的日常設定應能重現，同時讓平常的應用程式繼續完成工作。
