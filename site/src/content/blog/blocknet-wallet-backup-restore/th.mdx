สำรอง Blocknet ก่อนเปลี่ยนคอมพิวเตอร์ แล้วกู้ที่อยู่เดิมด้วยไฟล์หรือ seed คู่มือนี้ตาม CLI ทางการ v1.2.0 และ core v0.22.0 ที่ตรวจเมื่อ 27 ตุลาคม 2026 แยกการสำรอง การเปิดที่อื่น และการตรวจว่ากู้คืนครบ

## สำรองและกู้กระเป๋า Blocknet อย่างไร?

<Answer>
เก็บ seed ออฟไลน์และสำเนาไฟล์เต็มแยกกัน บนปลายทางโหลดไฟล์ด้วยรหัสหรือนำเข้า seed เดิมเป็นไฟล์ใหม่ เทียบที่อยู่รับเต็ม รอให้โหนดและสแกนตามทัน ตรวจบันทึกก่อนเลิกใช้สำเนาเก่า
</Answer>

## เลือกวิธีกู้ที่คุณมีจริง

ไฟล์สำรองกับ seed มีหน้าที่ต่างกัน ไฟล์ `.wallet.dat` เก็บกุญแจและสถานะกระเป๋า การเปิดสำเนาที่มีรหัสต้องใช้รหัสนั้น Seed สร้างกุญแจของกระเป๋าที่อิง seed ใหม่ในไฟล์ใหม่พร้อมรหัสใหม่ เก็บทั้งคู่ถ้ามี และเก็บบันทึกชำระส่วนตัวแยกเพื่อเทียบหลังกู้

ขั้นตอนนี้สำหรับกระเป๋าเต็มเดิม สร้างครั้งแรกตาม [คู่มือตั้งค่ากระเป๋า](/th/blog/blocknet-wallet-for-mining/) หากดูเงินบนเครื่องที่สองโดยไม่จ่าย ใช้ [คู่มือดูอย่างเดียว](/th/blog/blocknet-view-only-wallet/) ที่อยู่รับสาธารณะอย่างเดียวกู้กระเป๋าไม่ได้ ตรวจว่ามีไฟล์เต็ม รหัส และ seed เดิมก่อนเลือกขั้นตอน

## เตรียมกระเป๋าเดิมและบันทึกกู้คืน

เชื่อม mainnet core ที่ทำงานจากเทอร์มินัล:

```sh
blocknet attach mainnet
```

ในเชลล์โหลดกระเป๋าที่ต้องการและจดที่อยู่สาธารณะเต็ม:

```text
load
address
```

เลือกเมนูกระเป๋าที่มีอยู่ หากโหลดอันอื่นให้ใช้ `unload` ก่อน เก็บที่อยู่ เครือข่าย และชื่อไฟล์ในบันทึกย้ายส่วนตัว

กระเป๋าที่ใช้ seed ให้เรียก `seed` ยืนยันคำถามและใส่รหัส จดคำที่ได้ตามลำดับตรงตัวและเก็บออฟไลน์ ไม่ทำระหว่างแชร์หรือบันทึกหน้าจอ [คู่มือ seed](/th/blog/seed-phrase-explained/) อธิบายการป้องกัน หากระบบแจ้งไม่มี seed ให้เก็บไฟล์เต็มกับรหัสและใช้ทางคัดลอก อย่าคิดว่าทุกกระเป๋าเก่าหรือนำเข้ากุญแจมี seed

## ทำสำเนาไฟล์แยก

หาไฟล์ที่ core ใช้จริง โฟลเดอร์เริ่มต้นคือ `~/.config/bnt/wallets/` บน Windows คือ `C:\Users\<you>\.config\bnt\wallets\` โฟลเดอร์ที่เก็บ `wallet_file` ตามการตั้งค่าอาจต่าง ใช้พาธที่ไคลเอนต์แสดงและ [เอกสารจัดการกระเป๋า](https://github.com/blocknetprivacy/blocknet/blob/948af4de8b7a3e3cddc86a329c7d2d003cb3fd6b/docs/reference-wallet.md) โดยเฉพาะชื่อคล้ายกัน ตรวจไฟล์ก่อนคัดลอก

หลังจดที่อยู่ เรียก `unload` และรอสำเร็จก่อนคัดลอก คงต้นฉบับไว้และเก็บสำเนาลงวันที่บนสื่อแยกที่ควบคุม คงนามสกุล `.wallet.dat` และป้องกันสำรองกับรหัส ไคลเอนต์อาจสำรองในเครื่องเมื่อโหลดจากโฟลเดอร์อื่น แต่ไม่เขียนทับสำรองชื่อเดิมที่มีอยู่ ตรวจสำเนาที่เก็บเองแทนการคิดว่าสำเนาในเครื่องล่าสุด

## ย้ายไปคอมพิวเตอร์ใหม่อย่างไร?

ติดตั้ง [ไคลเอนต์ทางการ](https://github.com/blocknetprivacy/blocknet/releases/latest) และเตรียม mainnet core ตาม [คู่มือโหนด](/th/blog/run-blocknet-node/) ย้ายสำเนาไฟล์เต็มผ่านสื่อที่ควบคุมไปโฟลเดอร์กระเป๋าของ core ปลายทาง รักษาไฟล์อื่นที่มีอยู่ เลือกชื่อต่างถ้าจำเป็น ในไคลเอนต์ที่ตรวจสอบ `load` อ่านจากโฟลเดอร์นั้นแม้ใส่พาธกำหนดเอง

เชื่อม attach ที่ปลายทางและเรียก `load` เลือกสำเนาแล้วใส่รหัสเดิม หากไม่ปรากฏในเมนู ตรวจโฟลเดอร์ที่ core ใช้และจุดที่คัดลอก เลือกไฟล์เดิม ไม่ใช่สร้างกระเป๋าใหม่ คัดลอกไฟล์เดียวกันคืนสิทธิ์กุญแจเดิม ไม่ส่งเหรียญหรือสร้างยอดที่สอง

## กู้ด้วย seed ต้นฉบับ

หากไฟล์หายหรือลืมรหัส ใช้ seed ที่เก็บในไคลเอนต์ทางการบนเครื่องปลายทางที่ไว้ใจ เชื่อม mainnet core ที่ต้องการและเลิกโหลดกระเป๋าอื่นก่อน เริ่มกู้ในเชลล์:

```text
import
```

เลือกข้อ 1 สำหรับ seed 12 คำ ใส่คำเดิมของคุณตามลำดับ ห้ามใช้คำตัวอย่างหรือวาง seed ในเว็บไซต์

เลือกชื่อใหม่ที่ยังไม่ใช้ ตั้งและยืนยันรหัสใหม่ [การนำเข้าที่ตรวจสอบ](https://github.com/blocknetprivacy/blocknet/blob/948af4de8b7a3e3cddc86a329c7d2d003cb3fd6b/attach_wallet.go) สร้างกระเป๋าจากข้อมูลกู้และรายงานที่อยู่ ไฟล์เข้ารหัสต้นฉบับยังใช้รหัสเก่า เก็บไฟล์เก่ากับสำรองไว้ระหว่างตรวจ และถือไฟล์ใหม่เป็นอีกสำเนาที่ต้องป้องกัน

## ตรวจที่อยู่ เชน และการสแกน

หลังโหลดหรือนำเข้า ตรวจปลายทาง:

```text
address
status
balance
history
```

เทียบที่อยู่ทั้งหมดกับบันทึกเดิม การตรวจนี้ระบุกระเป๋าก่อนเชื่อยอด หากต่าง หยุดย้ายและตรวจไฟล์ คำกู้ และเครือข่าย เก็บสำรองเดิมสมบูรณ์ระหว่างแก้ความต่าง

ให้ทั้งดาวน์โหลดเชนและสแกนเอาต์พุตตามทัน กระเป๋าเพิ่งนำเข้าต้องหาเอาต์พุตบนเชน ยอดช่วงแรกไม่ใช่ตรวจสุดท้าย หลังสแกนเทียบยอดพร้อมใช้และรายการรับ เก็บโน้ตชำระแยกและไฟล์เดิมสำหรับประวัติ [คู่มือซิงก์](/th/blog/blocknet-wallet-not-syncing/) อธิบายค่าคืบหน้าที่ดูและเมื่อไรควรสแกนใหม่

## จบการย้ายหลังตรวจยืนยัน

เก็บสำรองที่ป้องกันของปลายทางที่ตรวจแล้วและ seed ออฟไลน์ จดว่าเครื่องไหนถือกระเป๋าเต็มใช้งานและสำเนาไหนสำรอง สำเนาเก่ายังเข้าถึงกุญแจเดียวกัน การย้ายไม่เพิกถอน เมื่อเลิกใช้เครื่อง ให้ยืนยันสำรองทำงานแล้วจัดการสื่อตามขั้นตอนกำจัดปลอดภัยปกติ

หากที่อยู่กู้ตรง ปลายทางรับเงินขุดเดิมคงได้ เทียบ [บันทึกจ่ายพูล](https://bntpool.com/blog/th/track-your-miner-on-bntpool/) กับประวัติรับเมื่อเช็กรายได้ หากจงใจสร้างกระเป๋าอื่น นั่นคือเปลี่ยนที่อยู่ไม่ใช่กู้คืน ตรวจกระเป๋าที่กู้ให้เสร็จก่อนเปลี่ยนการตั้งค่าตัวขุดแยกต่างหาก
