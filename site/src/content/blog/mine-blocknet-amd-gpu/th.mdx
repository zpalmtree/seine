seine ขุด Blocknet บนการ์ดจอ AMD Radeon พร้อมกับ CPU ของคุณ คู่มือนี้อธิบายสิ่งที่ต้องติดตั้งบน Windows และ Linux วิธีเลือกการ์ด วิธียืนยันว่า GPU แต่ละตัวกำลังแฮช และสิ่งที่ควรตรวจหากการ์ดไม่ปรากฏ เนื้อหานี้อ้างอิง seine v0.3.1

## seine รองรับการ์ด AMD รุ่นใด?

<Answer>
seine ขุดบนการ์ด AMD Radeon RX 6000, RX 7000 และ RX 9000 และการ์ด Radeon PRO ที่ใช้ชิป RDNA2, RDNA3 และ RDNA4 เดียวกัน ทำงานบน Windows x86_64 และ Linux x86_64 การ์ด AMD แยกทุกใบถูกเลือกเองและขุดพร้อม CPU โดยไม่ต้องเปลี่ยนการตั้งค่าใด
</Answer>

การ์ดแต่ละใบขุดด้วยหลาย lane โดยแต่ละ lane คำนวณแฮชหนึ่งครั้ง lane หนึ่งต้องใช้หน่วยความจำวิดีโอประมาณ 2 GB น้อยกว่านั้นเล็กน้อยบน RDNA2, RDNA3 และ RDNA4 การ์ดที่มีหน่วยความจำมากกว่าจึงรัน lane พร้อมกันได้มากกว่า การ์ด 16 GB รันได้ประมาณ 9 lane seine คำนวณจากหน่วยความจำที่ว่างตอนเริ่ม คุณจึงไม่ต้องคำนวณเอง

กราฟิก Radeon ในตัวของโปรเซสเซอร์ Ryzen ปิดไว้เป็นค่าเริ่มต้น หากต้องการก็เพิ่มได้ด้วย `--backend amd`

## ตั้งค่าการขุดด้วย GPU AMD บน Windows อย่างไร?

ติดตั้งไดรเวอร์กราฟิก AMD ล่าสุดสำหรับการ์ดของคุณ Adrenalin สำหรับการ์ด Radeon RX หรือไดรเวอร์ Radeon PRO สำหรับการ์ด PRO จาก[หน้าไดรเวอร์ของ AMD](https://www.amd.com/en/support/download/drivers.html) ไดรเวอร์มี HIP runtime ที่ seine ใช้ และไฟล์รุ่นเผยแพร่มีเคอร์เนล GPU สำเร็จรูปสำหรับการ์ด RX 6000, RX 7000 และ RX 9000 ไม่ต้องใช้อย่างอื่นอีก

ดาวน์โหลด `seine-windows-x86_64.zip` จาก[ส่วนดาวน์โหลด](/th/#download) แตกไฟล์ทั้งหมดลงในโฟลเดอร์ที่เขียนได้ แล้วเริ่มโปรแกรม:

```powershell
.\seine.exe
```

ในการเปิดครั้งแรก วางที่อยู่รับเงินแล้วกด Enter เพื่อยอมรับ bntpool.com [คู่มือตั้งค่าบน Windows](/th/blog/mine-blocknet-on-windows/) อธิบายการดาวน์โหลดและแตกไฟล์ทีละขั้น

## ตั้งค่าการขุดด้วย GPU AMD บน Linux อย่างไร?

<Answer>
ติดตั้งไดรเวอร์เคอร์เนล amdgpu ซึ่งดิสทริบิวชันปัจจุบันมีอยู่แล้ว และ ROCm HIP runtime ของ AMD จะเป็นแพ็กเกจ hip-runtime-amd หรือติดตั้ง ROCm เต็มก็ได้ เพิ่มผู้ใช้ของคุณเข้ากลุ่ม render และ video เพื่อให้ seine เปิด GPU ได้ ล็อกอินใหม่ แล้วเริ่มไฟล์ seine สำหรับ Linux x86_64 seine จะค้นหาการ์ด AMD ของคุณเอง
</Answer>

1. **ติดตั้ง runtime** เพิ่มคลัง ROCm ของ AMD สำหรับดิสทริบิวชันของคุณแล้วติดตั้ง `hip-runtime-amd` หรือติดตั้ง ROCm เต็มหากใช้อยู่แล้ว [คู่มือติดตั้ง ROCm](https://rocm.docs.amd.com/projects/install-on-linux/en/latest/) ของ AMD แสดงดิสทริบิวชันที่รองรับ
2. **ให้ผู้ใช้ของคุณเข้าถึง GPU** seine เปิด `/dev/kfd` และ `/dev/dri/renderD*`:

   ```bash
   sudo usermod -aG render,video $USER
   ```

   ออกจากระบบแล้วเข้าใหม่เพื่อให้กลุ่มใหม่มีผล
3. **เริ่ม seine** ดาวน์โหลด `seine-linux-x86_64.tar.gz` จาก[ส่วนดาวน์โหลด](/th/#download) แตกไฟล์แล้วรัน:

   ```bash
   ./seine
   ```

เมื่อมี hipRTC ติดตั้งอยู่ seine จะคอมไพล์เคอร์เนลให้ตรงกับการ์ดของคุณตอนเริ่ม การ์ด RX 6000, RX 7000 และ RX 9000 ยังทำงานได้โดยไม่มี hipRTC โดยใช้เคอร์เนลที่มาในรุ่นเผยแพร่ [คู่มือขุดบน Linux](/th/blog/mine-blocknet-on-linux/) อธิบายไฟล์และความต้องการของระบบ

บนการ์ด RX 7000 และ Radeon PRO W7000 เมื่อรันด้วยสิทธิ์ root seine จะตั้งระดับพลังงานของการ์ดเป็น `high` ระหว่างขุด และคืนค่าระดับเดิมเมื่อปิด หากไม่มีสิทธิ์ root โปรแกรมจะแสดงคำสั่งบรรทัดเดียวที่ทำแบบเดียวกัน ให้คุณสั่งเองได้

## เลือกการ์ดที่จะขุดอย่างไร?

ไม่ต้องตั้งตัวเลือก backend เพื่อขุดบน CPU และการ์ด AMD แยกทุกใบ หากต้องการให้ GPU ขุดต่อและเว้น CPU ไว้ ให้เลือก `amd`:

```bash
./seine --backend amd
```

หากต้องการขุดบนการ์ดใบเดียวและยังขุดด้วย CPU ให้เลือกทั้งสอง backend และหมายเลขการ์ด:

```bash
./seine --backend cpu,amd --amd-devices 0
```

`--amd-devices 0,1` เลือกการ์ดสองใบ ในเครื่องที่มีทั้งการ์ด NVIDIA และ AMD `--backend nvidia,amd` จะขุดบนทุกใบโดยไม่ใช้ CPU หากต้องการเหลือหน่วยความจำวิดีโอให้เกมหรือแอปอื่นบนการ์ดเดียวกัน ให้จำกัด lane ด้วย `--amd-max-lanes 2` [คู่มือการตั้งค่า](/th/blog/configure-seine-miner/) แสดงวิธีเก็บตัวเลือกเหล่านี้ไว้ทุกครั้งที่เริ่ม

## ยืนยันว่า GPU AMD กำลังขุดอย่างไร?

การ์ด AMD เริ่มทำงานเบื้องหลังขณะที่ CPU ขุดอยู่แล้ว การ์ดแต่ละใบมีแถวของตัวเองในแผง Devices คือ `amd#1`, `amd#2` และต่อไป และบันทึกจะรายงานเมื่อการ์ดออนไลน์พร้อมจำนวน lane เช่น `amd#1: online (initialized in background, 9 lanes)` จากนั้นแถวจะแสดง hashrate ปัจจุบันและค่าเฉลี่ยของการ์ด

share ที่ได้รับการยอมรับในแผง Mining ยืนยันว่าพูลนับงานของคุณ [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายทุกแผง และคุณติดตามเครื่องขุดบน bntpool.com ได้ด้วย[คู่มือติดตามเครื่องขุด](https://bntpool.com/blog/th/track-your-miner-on-bntpool/)

## ควรตรวจอะไรหากการ์ด AMD ไม่ปรากฏ?

- **ตรวจไดรเวอร์และ runtime** บน Windows ให้ติดตั้งหรืออัปเดตไดรเวอร์ AMD บน Linux ให้ติดตั้ง `hip-runtime-amd` และตรวจว่าผู้ใช้ของคุณอยู่ในกลุ่ม `render` และ `video` หากไม่มี runtime seine จะขุดบน CPU และเมื่อใช้ `--backend amd` จะระบุชื่อ runtime ที่ขาดตอนเริ่ม
- **ตรวจคำสั่งของคุณ** `--backend cpu` ขุดบนโปรเซสเซอร์เท่านั้น ใช้คำสั่งเริ่มต้นหรือใส่ `amd` ในรายการ backend หากตั้ง `--amd-devices` ไว้ ให้ตรวจว่าหมายเลขนั้นมีอยู่จริง
- **ระบุ amd เองหลังอัปเดตไดรเวอร์** หาก AMD runtime ทำให้ seine ปิดสองครั้งติดกัน seine จะหยุดเลือกการ์ด AMD เองและขุดต่อบนส่วนที่เหลือ แล้วลองการ์ดอีกครั้งหลังการอัปเดตครั้งถัดไป เริ่มหนึ่งครั้งด้วย `--backend cpu,amd` เพื่อลองการ์ดอีกครั้งทันที

[คู่มือ AMD ของ seine](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md) มีความต้องการทั้งหมด และผู้ใช้ระบบปฏิบัติการสำหรับขุดติดตั้งแพ็กเกจ [HiveOS](https://github.com/zpalmtree/seine/blob/master/docs/guides/hiveos.md) หรือ [mmpOS](https://github.com/zpalmtree/seine/blob/master/docs/guides/mmpos.md) จากทุกรุ่นเผยแพร่ได้
