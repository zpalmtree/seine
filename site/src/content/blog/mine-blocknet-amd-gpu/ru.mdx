Seine майнит Blocknet на видеокартах AMD Radeon вместе с вашим CPU. Это руководство объясняет, что установить в Windows и Linux, как выбрать карты, как убедиться, что каждый GPU вычисляет хеши, и что проверить, если карта не видна. Описана версия seine v0.3.1.

## Какие карты AMD поддерживает seine?

<Answer>
Seine майнит на картах AMD Radeon RX 6000, RX 7000 и RX 9000 и на картах Radeon PRO на тех же чипах RDNA2, RDNA3 и RDNA4. Он работает в Windows x86_64 и Linux x86_64. Каждая дискретная карта AMD выбирается автоматически и майнит вместе с CPU, ничего менять в настройках не нужно.
</Answer>

Каждая карта майнит несколькими линиями, по одному хешу в работе на линию. Линии нужно около 2 GB видеопамяти, на RDNA2, RDNA3 и RDNA4 немного меньше, поэтому карты с большим объёмом памяти запускают больше линий одновременно. Карта на 16 GB запускает около 9 линий. Seine рассчитывает это по свободной памяти при запуске, так что считать самому не нужно.

Встроенная графика Radeon в процессорах Ryzen по умолчанию выключена. При желании её можно добавить с `--backend amd`.

## Как настроить майнинг на GPU AMD в Windows?

Установите актуальный графический драйвер AMD для своей карты, Adrenalin для Radeon RX или драйвер Radeon PRO для карт PRO, со [страницы драйверов AMD](https://www.amd.com/en/support/download/drivers.html). Драйвер включает среду выполнения HIP, которую использует seine, а релизный файл содержит готовые вычислительные ядра GPU для карт RX 6000, RX 7000 и RX 9000. Больше ничего не нужно.

Скачайте `seine-windows-x86_64.zip` из [раздела загрузки](/ru/#download), распакуйте весь архив в папку с правом записи и запустите:

```powershell
.\seine.exe
```

При первом запуске вставьте адрес для выплат и нажмите Enter, чтобы принять bntpool.com. [Руководство по настройке в Windows](/ru/blog/mine-blocknet-on-windows/) пошагово описывает загрузку и распаковку.

## Как настроить майнинг на GPU AMD в Linux?

<Answer>
Установите драйвер ядра amdgpu, который есть в современных дистрибутивах, и среду выполнения ROCm HIP от AMD: пакет hip-runtime-amd или полную установку ROCm. Добавьте пользователя в группы render и video, чтобы seine мог открыть GPU, войдите в систему заново и запустите архив seine для Linux x86_64. Seine сам найдёт ваши карты AMD.
</Answer>

1. **Установите среду выполнения.** Подключите репозиторий ROCm от AMD для своего дистрибутива и установите `hip-runtime-amd` или полную установку ROCm, если вы её уже используете. [Руководство по установке ROCm](https://rocm.docs.amd.com/projects/install-on-linux/en/latest/) от AMD перечисляет поддерживаемые дистрибутивы.
2. **Дайте пользователю доступ к GPU.** Seine открывает `/dev/kfd` и `/dev/dri/renderD*`:

   ```bash
   sudo usermod -aG render,video $USER
   ```

   Выйдите и войдите снова, чтобы новые группы вступили в силу.
3. **Запустите seine.** Скачайте `seine-linux-x86_64.tar.gz` из [раздела загрузки](/ru/#download), распакуйте и выполните:

   ```bash
   ./seine
   ```

Если установлен hipRTC, seine при запуске компилирует вычислительное ядро именно под вашу карту. Карты RX 6000, RX 7000 и RX 9000 работают и без него, используя ядра, встроенные в релиз. [Руководство по майнингу в Linux](/ru/blog/mine-blocknet-on-linux/) описывает архив и системные требования.

На картах RX 7000 и Radeon PRO W7000 seine, запущенный от root, на время майнинга ставит уровень питания карты `high` и возвращает прежний уровень при выходе. Без root он выводит однострочную команду, которая делает то же самое, чтобы вы могли применить её сами.

## Как выбрать карты для майнинга?

Не задавайте параметр backend, чтобы майнить на CPU и на каждой дискретной карте AMD. Чтобы майнить на GPU и оставить CPU свободным, выберите `amd`:

```bash
./seine --backend amd
```

Чтобы майнить на одной карте и сохранить майнинг на CPU, выберите оба бэкенда и индекс карты:

```bash
./seine --backend cpu,amd --amd-devices 0
```

`--amd-devices 0,1` выбирает две карты. В компьютере с картами NVIDIA и AMD `--backend nvidia,amd` майнит на всех без CPU. Чтобы оставить видеопамять для игры или других программ на той же карте, ограничьте число линий с `--amd-max-lanes 2`. [Руководство по настройкам](/ru/blog/configure-seine-miner/) показывает, как сохранить эти параметры для каждого запуска.

## Как убедиться, что GPU AMD майнит?

Карты AMD запускаются в фоне, пока CPU уже майнит. Каждая карта получает свою строку на панели Devices, `amd#1`, `amd#2` и так далее, а лог сообщает о её подключении с числом линий, например `amd#1: online (initialized in background, 9 lanes)`. Затем в строке видны текущий и средний хешрейт карты.

Принятые шары на панели Mining подтверждают, что пул засчитывает вашу работу. [Руководство по панели](/ru/blog/seine-dashboard-explained/) объясняет каждую панель, а следить за ригами на bntpool.com помогает [руководство по наблюдению за майнером](https://bntpool.com/blog/ru/track-your-miner-on-bntpool/).

## Что проверить, если карта AMD не видна?

- **Проверьте драйвер и среду выполнения.** В Windows установите или обновите драйвер AMD. В Linux установите `hip-runtime-amd` и проверьте, что пользователь состоит в группах `render` и `video`. Без среды выполнения seine майнит на CPU, а с `--backend amd` называет недостающую среду при запуске.
- **Проверьте команду.** `--backend cpu` майнит только на процессоре. Используйте команду по умолчанию или включите `amd` в список бэкендов. Если вы задали `--amd-devices`, проверьте, что такой индекс существует.
- **Укажите amd вручную после обновления драйвера.** Если среда выполнения AMD дважды подряд закрывает seine, он перестаёт сам выбирать карты AMD и продолжает майнить на остальном оборудовании, а после следующего обновления пробует их снова. Запустите его один раз с `--backend cpu,amd`, чтобы сразу снова попробовать карты.

[Руководство seine по AMD](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md) содержит полные требования, а пользователи майнинговых ОС могут установить пакет для [HiveOS](https://github.com/zpalmtree/seine/blob/master/docs/guides/hiveos.md) или [mmpOS](https://github.com/zpalmtree/seine/blob/master/docs/guides/mmpos.md) из каждого релиза.
