ทำความเข้าใจว่า seine ทำอะไรเมื่อจำนวนเธรด CPU เปลี่ยนระหว่างขุด คู่มือนี้อ้างอิงรุ่นเผยแพร่สาธารณะ v0.3.1 และอธิบายว่า seine หาการตั้งค่าที่เร็วที่สุดสำหรับ CPU ของคุณอย่างไร ทำไมจึงใช้จำนวนเธรดต่ำสุดที่ได้ความเร็วนั้น และจะตรวจอีกครั้งเมื่อใด สำหรับการติดตั้ง ให้เริ่มที่[คู่มือการขุด](/th/blog/how-to-mine-blocknet/) และสำหรับความหมายของแต่ละแผง ดู[คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/)

## การปรับแต่ง CPU อัตโนมัติทำงานอย่างไร?

<Answer>
seine เริ่มขุดทันทีและปรับแต่งด้วยงานขุดจริง โปรแกรมเปรียบเทียบเคอร์เนล CPU ที่โปรเซสเซอร์ของคุณรันได้ แล้วจึงเปรียบเทียบจำนวนเธรด โดยวัดค่าปัจจุบัน ค่าทดลอง แล้ววัดค่าปัจจุบันอีกครั้ง โปรแกรมใช้จำนวนเธรดต่ำสุดที่แฮชได้เร็วเท่าค่าที่ดีที่สุด แล้วหยุดทดสอบจนกว่าจะมีสิ่งใดเปลี่ยน
</Answer>

<img src="/assets/blog/cpu-autotuning.svg" alt="การเปรียบเทียบค่าฐาน–ผู้สมัคร–ค่าฐานซ้ำจะนำไปสู่ค่าที่บันทึก โดยตรวจหน่วยความจำที่มีตลอดกระบวนการ" width="1200" height="675" loading="lazy" />

ไม่ต้องตั้ง `--threads` เพื่อใช้การปรับแต่งอัตโนมัติ ไม่มีอะไรต้องกำหนดค่า seine เริ่มจากสิ่งที่ดีที่สุดที่รู้ ได้แก่ ผลที่บันทึกไว้ของเครื่องนี้ จุดเริ่มต้นสำหรับรุ่น CPU ของคุณ และค่าประมาณจากจำนวนคอร์และ RAM ที่ว่าง จากนั้นค้นหาด้วยก้าวที่ใหญ่ขึ้นเรื่อยๆ จนเพิ่มเธรดแล้วไม่ช่วย แล้วจึงค่อยๆ แคบลง

การรันค่าปัจจุบันทั้งก่อนและหลังค่าทดลองแต่ละค่า ทำให้การเปลี่ยนแปลงของภาระงาน เช่น แท็บเบราว์เซอร์หรือการอัปเดตเบื้องหลัง ไม่นับเป็นผลดีหรือผลเสียของค่าทดลอง ค่าทดลองที่ช้ากว่าอย่างชัดเจนจะถูกตัดจบก่อน เครื่องส่วนใหญ่จึงเสร็จภายในไม่กี่นาที

## แถว Tuning บนแดชบอร์ดหมายถึงอะไร?

แถว `Tuning:` บนแดชบอร์ดบอกสถานะของการปรับแต่ง:

| แถว | ความหมาย |
|---|---|
| `trying kernels, about 4 min left` | กำลังเปรียบเทียบเคอร์เนล CPU ขณะขุด |
| `12 vs 16 threads, about 3 min left` | กำลังเปรียบเทียบสองจำนวนเธรด จำนวนจะสลับระหว่างสองค่านี้ขณะ seine วัดผล |
| `update: 12 vs 14 threads, ~2 min` | รุ่นใหม่เปลี่ยนบางอย่างสำหรับ CPU ของคุณและทดสอบเฉพาะส่วนนั้น |
| `done` | ปรับแต่งเสร็จแล้ว จำนวนเธรดคงที่จนกว่าจะมีสิ่งใดเปลี่ยน |
| `low on RAM, best is 12 threads` | รันเธรดน้อยลงจนกว่า RAM จะว่างอีกครั้ง |

บันทึกมีหนึ่งบรรทัดเมื่อเริ่มปรับแต่ง พร้อมเหตุผล และหนึ่งบรรทัดเมื่อเสร็จ เช่น `tuned to 12 threads` [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/) อธิบายแผงอื่น

## ทำไม seine จึงใช้เธรดน้อยกว่าที่ใช้ได้?

เธรด CPU แต่ละเธรดถือพื้นที่หน่วยความจำขนาดใหญ่ และทุกเธรดใช้แบนด์วิดท์หน่วยความจำของเครื่องร่วมกัน เมื่อเกินจำนวนหนึ่ง การเพิ่มเธรดไม่เพิ่ม hashrate และยังกิน RAM ที่โปรแกรมอื่นใช้ได้ seine จึงถือว่าทุกจำนวนที่เร็วเท่าค่าที่เร็วที่สุดดีพอกัน และใช้จำนวนต่ำสุดในนั้น คุณได้ hashrate เท่าเดิมโดยเหลือหน่วยความจำว่างมากขึ้น

นี่คือเหตุที่จำนวนที่ดีที่สุดมักต่ำกว่าจำนวนคอร์หรือเธรดทั้งหมดของคุณ และต่างกันระหว่างเครื่องที่ดูเหมือนกัน จำนวนเธรด ช่องหน่วยความจำ และชนิดเพจหน่วยความจำล้วนมีผล ผลจากเครื่องอื่นจึงเป็นเพียงข้อมูลอ้างอิง ไม่ใช่ค่าที่ควรคัดลอก [คู่มือ RAM](/th/blog/how-much-ram-to-mine-blocknet/) อธิบายงบหน่วยความจำต่อเธรด

หากคุณอยากประหยัดไฟและหน่วยความจำมากกว่าได้แฮชเพิ่มอีกเล็กน้อย `--cpu-profile efficiency` จะใช้จำนวนที่ต่ำกว่าซึ่งใกล้กับค่าที่เร็วที่สุด

## seine ปรับแต่งเคอร์เนล CPU ด้วยไหม?

ใช่ เคอร์เนลในที่นี้คือซอฟต์แวร์ที่คำนวณแฮชสำหรับชุดคำสั่งโปรเซสเซอร์หนึ่งชุด seine ตรวจว่า CPU ของคุณรองรับคำสั่งใด ไม่ลองเคอร์เนลที่รันไม่ได้ และข้ามเคอร์เนลที่ไม่ได้ผลดีกว่าบน CPU ของคุณ แล้วเปรียบเทียบส่วนที่เหลือขณะขุด ก่อนกำหนดจำนวนเธรด การสลับเคอร์เนลเกิดขึ้นระหว่างแฮชที่เสร็จสมบูรณ์ การขุดจึงดำเนินต่อและการเชื่อมต่อพูลไม่หลุด

## seine จะปรับแต่งอีกเมื่อใด?

เมื่อแถวแสดง `done` แล้ว seine จะไม่รันการทดสอบตามกำหนดเวลา โปรแกรมจะตรวจอีกครั้งเมื่อมีสิ่งใดเปลี่ยนเท่านั้น:

- **รุ่นใหม่เปลี่ยนบางอย่างสำหรับ CPU ของคุณ** รุ่นใหม่เริ่มจากผลที่บันทึกไว้และทดสอบเฉพาะส่วนที่เปลี่ยน เช่น เคอร์เนลใหม่หรือที่ปรับปรุงแล้ว รุ่นที่ไม่เปลี่ยนอะไรเกี่ยวกับการแฮชจะไม่รันการทดสอบเลย
- **hashrate เปลี่ยนเป็นเวลานาน** เช่น เมื่อโปรแกรมอื่นเริ่มหรือหยุดใช้ CPU หนัก
- **RAM ว่างมากขึ้น** หลังจาก RAM เคยเป็นสิ่งที่จำกัดจำนวนเธรด
- **ฮาร์ดแวร์ ระบบปฏิบัติการ หรือขีดจำกัด CPU เปลี่ยน** เช่น ขีดจำกัด CPU ของคอนเทนเนอร์

แต่ละกรณีจะเขียนบรรทัดบันทึกที่บอกเหตุผลที่เริ่มปรับแต่ง การอัปเดตอัตโนมัติเก็บผลการปรับแต่งไว้ การอัปเดต seine จึงไม่ทำให้ต้องเริ่มใหม่ตั้งแต่ต้น [คู่มือการอัปเดต](/th/blog/update-seine-miner/) อธิบายการทำงานของการอัปเดต

## จะเกิดอะไรขึ้นเมื่อโปรแกรมอื่นต้องใช้ RAM?

seine ตรวจ RAM ที่ว่างทุกวินาที เมื่อโปรแกรมอื่นต้องใช้หน่วยความจำ เธรด CPU จะทำแฮชปัจจุบันให้เสร็จ พักไว้ และคืนพื้นที่หน่วยความจำ และแถวจะแสดง `low on RAM` เมื่อหน่วยความจำว่างอีกครั้ง เธรดจะกลับมา จำนวนที่ดีที่สุดที่เรียนรู้แล้วยังคงบันทึกไว้ การขาด RAM ช่วงสั้นจึงไม่ลบค่านั้น

บน Linux พื้นที่ HugeTLB แบบระบุชัดที่คืนแล้วจะกลับไปยังพูล huge page ที่จองไว้ seine ไม่เปลี่ยนขนาดพูลนั้น [คู่มือ huge pages](/th/blog/huge-pages-blocknet-mining/) อธิบายการจอง huge page

## ผลการปรับแต่งที่บันทึกไว้ถูกใช้ซ้ำอย่างไร?

ผลถูกบันทึกใน `seine.cpu-autotune.json` ในไดเรกทอรีข้อมูล ค่าเริ่มต้นคือ `seine-data` เมื่อเริ่มครั้งถัดไป seine จะกลับไปใช้ผลที่บันทึกไว้ทันทีและแถวจะแสดง `done` หาก hashrate ต่างจากครั้งก่อนอย่างชัดเจน โปรแกรมจะปรับแต่งอีกครั้งและบันทึกจะบอกเหตุผล ใช้ไดเรกทอรีข้อมูลเดิมระหว่างการรันเพื่อให้ seine หาไฟล์เจอ และให้เครื่องขุดแต่ละเครื่องสร้างไฟล์ของตัวเอง การคัดลอกไฟล์จากเครื่องอื่นไม่ช่วย เพราะผลขึ้นกับฮาร์ดแวร์และการตั้งค่าที่ตรงกันพอดี

## เปลี่ยนจำนวนเธรดเองได้ไหม?

ได้ กด `-` หรือ `+` บนแดชบอร์ดเพื่อลดหรือเพิ่มเธรด CPU หนึ่งเธรด เมื่อการปรับแต่งแสดง `done` แล้ว การเปลี่ยนจะมีผลกับเธรดที่รันอยู่ทันที โดย GPU และการเชื่อมต่อพูลยังทำงานต่อ ขณะที่การปรับแต่งยังเลือกจำนวนอยู่ ปุ่มจะรอและแดชบอร์ดจะแสดงเวลาที่การปรับแต่งเหลือ การกดปุ่มมีผลเฉพาะการรันครั้งนั้น การเริ่มครั้งถัดไปจะใช้ผลที่บันทึกไว้อีกครั้ง

หากต้องการกำหนดจำนวนตั้งแต่เริ่ม ให้ใช้ `--threads` เช่น `--threads 4` seine จะใช้จำนวนนั้นและยังเลือกเคอร์เนลที่ดีที่สุดให้ `--disable-cpu-autotune-threads` ปิดการปรับแต่งเธรดและเคอร์เนลทั้งหมด [เอกสารแฟล็ก](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/MINER_FLAGS.md) อธิบายตัวเลือกเหล่านี้ และ[การขุดขณะใช้คอมพิวเตอร์](/th/blog/mine-while-using-pc/) แสดงวิธีใช้เดสก์ท็อปร่วมกับการขุด

สำหรับการขุดทุกวัน ให้เริ่มด้วยค่าเริ่มต้นและปล่อยให้การปรับแต่งถึง `done` ใช้แถวอุปกรณ์ CPU เพื่อติดตามการทดลองปรับแต่ง และ[สถิติของพูล](https://bntpool.com/blog/th/track-your-miner-on-bntpool/) เพื่อติดตามงานขุดที่นับแล้ว
