本指南介绍如何用一个 seine 矿场代理运行 Blocknet 矿场。你在网络中的一台机器上启动代理，让每台矿机都连接到它，代理就会为整个矿场连接 bntpool.com。你可以在一处设置矿池、收款地址和备用矿池，并在矿池上保留每台矿机的统计。内容基于 seine v0.3.1。

## 矿场代理有什么作用？

<Answer>
矿场代理是作为矿机本地矿池运行的 seine。它为整个矿场只连接一次 bntpool.com，并把各自那份工作分给每台矿机。矿池只看到一个连接，每台矿机仍然各自挖矿、各自计入收益，你可以在一处为所有矿机更改矿池或备用矿池。
</Answer>

矿场代理适合运行不止几台矿机的任何人：

- **一处设置。** 在代理上设置矿池、备用矿池和默认收款地址，每台矿机都会使用这些设置。
- **一个对外连接。** 矿机通过本地网络与代理通信，代理只打开矿场需要的矿池连接，通常是一个或几个。
- **矿池上按矿机统计。** bntpool.com 按矿机记录份额，所以每台矿机仍会以自己的矿工名显示在[统计页面](https://bntpool.com/stats?lang=zh-hans)上。

代理本身不挖矿。它几乎不占用 CPU 和内存，所以可以运行在矿机能访问的任何机器上，包括其中一台矿机。

## 如何启动代理？

<Answer>
用 --proxy-listen 指定矿机要连接的地址和端口，再加上常用的矿池、收款地址和矿机名称选项来启动 seine。例如：./seine --proxy-listen 0.0.0.0:3333 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_ADDRESS --pool-worker farm-1。代理随后会在 3333 端口等待矿机连接。
</Answer>

在要运行代理的机器上执行：

```bash
./seine --proxy-listen 0.0.0.0:3333 \
        --pool-url stratum+tcp://bntpool.com:3333 \
        --address YOUR_ADDRESS --pool-worker farm-1
```

`--proxy-listen` 设置代理接受矿机连接的位置；`0.0.0.0:3333` 表示在所有网络接口的 3333 端口上监听。`--address` 是默认收款地址，用于没有用有效地址登录的矿机。所有矿池选项都可以在代理上使用，包括备用矿池：按顺序列出，用逗号分隔，代理会在第一个矿池恢复后切回。[seine 配置指南](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/guides/configuration.md)介绍了矿池选项。

请把代理绑定到你的本地网络。任何能访问其端口的人都能通过它挖矿，所以请在 `--proxy-listen` 中使用局域网地址，或用防火墙保护该端口，而不要把它暴露到互联网上。

## 如何让矿机连接到代理？

在每台矿机上，把代理的本地地址用作矿池，并给矿机取一个自己的名称：

```bash
./seine --pool-url 192.168.1.10:3333 --address YOUR_ADDRESS --pool-worker rig-07
```

把 `192.168.1.10` 换成代理机器在你网络中的地址。挖矿系统上的矿机也一样：按照 [HiveOS 和 mmpOS 指南](/zh-hans/blog/mine-blocknet-hiveos-mmpos/)所示，把代理地址填入 HiveOS flight sheet 或 mmpOS 配置文件的矿池 URL 字段。seine 会把矿池与矿机的设置一起保存，所以之后的启动会自动连接到代理。

## 代理后面的矿机如何获得支付？

每台矿机都支付到它登录时使用的完整 Blocknet 地址。挖到不同钱包的矿机可以共用一个代理，同时最多 16 个地址。没有地址或使用无效地址登录的矿机，会支付到代理的 `--address`。

当 16 个地址都在使用时，使用第 17 个地址的矿机会等待，直到其他某个地址连续 10 分钟没有矿机。如果矿池拒绝了某台矿机的地址，代理会转达矿池给出的原因，方便你在那台矿机上修正。

代理后面的矿机也可以在 bntpool.com 上单独挖矿：在矿机的地址前加上 `solo:`，矿池就会把该矿机找到的每个区块的全部奖励支付给它。[在 bntpool.com 上单独挖矿](https://bntpool.com/blog/zh-hans/solo-mine-blocknet-on-bntpool/)介绍了单独挖矿的收益。支付到交易所需要充值备注，而代理不传递备注，所以请让挖到交易所的矿机直接连接矿池。

## 如何跟踪矿场状况？

在 bntpool.com 的[统计页面](https://bntpool.com/stats?lang=zh-hans)上查询每个收款地址。代理后面的每台矿机都会出现在 Workers 表中，显示自己的矿机名称、算力、份额和最后一个份额的时间，和直接连接时完全一样。[矿机追踪指南](https://bntpool.com/blog/zh-hans/track-your-miner-on-bntpool/)介绍了该页面。

代理也会每分钟在日志中记录自己的摘要：已连接的矿机、被接受和被拒绝的份额、估算算力以及矿池连接。每台矿机连接和断开时它都会记录，所以有矿机掉线时你一眼就能看到。每台矿机自己的 seine 仪表盘仍会显示本地算力和份额，详见[仪表盘指南](/zh-hans/blog/seine-dashboard-explained/)。

## 还需要了解什么？

- **矿池连接数随矿场规模增长。** 代理会打开足够的矿池连接，让每台矿机在每个新区块都能拿到工作。大多数矿场只需要一个或几个，超大型矿场每个收款地址最多 64 个。
- **每台矿机保留自己的设置。** 线程数、GPU 选择和调优都保留在矿机上。[设置指南](/zh-hans/blog/configure-seine-miner/)介绍了这些设置，[服务器挖矿指南](/zh-hans/blog/mine-blocknet-on-servers/)介绍了大型 CPU 服务器。
- **网络升级。** 在 Faraday 网络升级时，代理会像矿池一样，要求运行不支持该升级的 seine 版本的矿机进行更新。
