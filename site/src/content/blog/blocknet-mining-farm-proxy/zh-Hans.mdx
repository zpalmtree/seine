当每台矿机各自连接矿池时，每次更换矿池都要在每台矿机上操作一遍。使用 seine 矿场代理后，你的矿机连接到网络中的一台机器，再由这台机器为整个矿场连接 bntpool.com。你只需更改一次矿池、备用矿池或默认收款地址，每台矿机都会跟着变。每台矿机在 bntpool.com 上仍以自己的名称显示。内容基于 seine v0.3.1。

## 矿场代理能为你做什么？

<Answer>
矿场代理是作为矿机本地矿池运行的 seine。它为整个矿场连接 bntpool.com，并把各自那份工作分给每台矿机。你在一处管理矿池、备用矿池和默认收款地址，而每台矿机仍然各自挖矿、各自计入收益。
</Answer>

矿场通过代理运行后，会有这些变化：

- **重启一次即可为整个矿场切换矿池。** 矿池和备用矿池都在代理上，所以你只需修改一条命令行，而不是每台矿机、每个 flight sheet 或配置文件。
- **所有矿机同时故障切换。** 在代理上列出备用矿池，整个矿场会一起切换到下一个矿池，并在第一个矿池恢复响应后切回。
- **一行命令添加矿机。** 新矿机只需把代理地址设为矿池，矿场的其他部分都不用改。
- **只有一台机器连接互联网。** 矿机通过本地网络与代理通信，只有代理需要访问矿池。一条防火墙规则就能覆盖整个矿场；对于屏蔽挖矿端口的网络，SOCKS5 代理也只需设置在代理上。
- **每台矿机仍有自己的统计。** bntpool.com 按矿机记录份额，所以每台矿机都会以自己的矿工名、算力和份额显示在[统计页面](https://bntpool.com/stats?lang=zh-hans)上。
- **一个代理支持多个钱包。** 每台矿机都支付到它登录时使用的地址，所以一个代理可以服务最多 16 个不同钱包的矿机，例如你为朋友或合作伙伴运行的矿机。

代理本身不挖矿。它几乎不占用 CPU 和内存，所以可以运行在一台小型服务器上，也可以运行在某台矿机上，与该矿机自己的矿工程序并行。

## 如何设置矿场代理？

<Answer>
用 --proxy-listen 指定矿机要连接的地址和端口，再加上常用的矿池、收款地址和矿机名称选项来启动 seine。例如：./seine --proxy-listen 0.0.0.0:3333 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_ADDRESS --pool-worker farm-1。然后把每台矿机的矿池 URL 指向代理。
</Answer>

设置分两步：启动代理，再让矿机连接到它。

**1. 启动代理。** 在要运行代理的机器上执行：

```bash
./seine --proxy-listen 0.0.0.0:3333 \
        --pool-url stratum+tcp://bntpool.com:3333 \
        --address YOUR_ADDRESS --pool-worker farm-1
```

`--proxy-listen` 设置代理接受矿机连接的位置；`0.0.0.0:3333` 表示在所有网络接口的 3333 端口上监听。`--address` 是默认收款地址，用于没有用有效地址登录的矿机。所有矿池选项都可以在代理上使用。备用矿池按顺序列出，用逗号分隔；如果你的网络需要通过 SOCKS5 代理才能访问矿池，再加上 `--pool-proxy socks5://host:port`。[seine 配置指南](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/guides/configuration.md)介绍了矿池选项。

请把代理留在你的本地网络中：在 `--proxy-listen` 中使用局域网地址，或用防火墙保护该端口，这样只有你自己的矿机能通过它挖矿并支付到你的地址。

**2. 让每台矿机连接到代理。** 把代理的本地地址用作矿池，并给矿机取一个自己的名称：

```bash
./seine --pool-url 192.168.1.10:3333 --address YOUR_ADDRESS --pool-worker rig-07
```

把 `192.168.1.10` 换成代理机器在你网络中的地址。在挖矿系统上，按照 [HiveOS 和 mmpOS 指南](/zh-hans/blog/mine-blocknet-hiveos-mmpos/)所示，把代理地址填入 HiveOS flight sheet 或 mmpOS 配置文件的矿池 URL 字段。seine 会把矿池与矿机的设置一起保存，所以之后的启动会自动连接到代理，此后你就在代理上管理矿池。

## 代理后面的矿机如何获得支付？

每台矿机都支付到它登录时使用的完整 Blocknet 地址，和直接连接时完全一样。挖到不同钱包的矿机可以共用一个代理，同时最多 16 个地址。没有地址或使用无效地址登录的矿机，会支付到代理的 `--address`，所以它的算力仍然归你。

当 16 个地址都在使用时，使用第 17 个地址的矿机会等待，直到其他某个地址连续 10 分钟没有矿机。如果矿池拒绝了某台矿机的地址，代理会转达矿池给出的原因，方便你在那台矿机上修正。

代理后面的矿机也可以在 bntpool.com 上单独挖矿：在矿机的地址前加上 `solo:`，矿池就会把该矿机找到的每个区块的全部奖励支付给它。[在 bntpool.com 上单独挖矿](https://bntpool.com/blog/zh-hans/solo-mine-blocknet-on-bntpool/)介绍了单独挖矿的收益。支付到交易所使用充值备注，而代理不传递备注，所以请让支付到交易所的矿机直接连接矿池。

## 如何跟踪矿场状况？

在 bntpool.com 的[统计页面](https://bntpool.com/stats?lang=zh-hans)上查询每个收款地址。代理后面的每台矿机都会出现在 Workers 表中，显示自己的矿机名称、算力、份额和最后一个份额的时间，和直接连接时完全一样。[矿机追踪指南](https://bntpool.com/blog/zh-hans/track-your-miner-on-bntpool/)介绍了该页面。

代理还会提供自己的全矿场视图。它每分钟在日志中记录一次摘要：已连接的矿机、被接受和被拒绝的份额、整个矿场的估算算力以及矿池连接。每台矿机连接和断开时它也会记录，所以一份日志就能看出矿机何时掉线。每台矿机自己的 seine 仪表盘仍会显示本地算力和份额，详见[仪表盘指南](/zh-hans/blog/seine-dashboard-explained/)。

## 矿场扩大后代理还能跟上吗？

能。代理会打开足够的矿池连接，让每台矿机在每个新区块都能拿到工作。大多数矿场只需要一个或几个，超大型矿场每个收款地址最多 64 个。你不需要设置这一点；矿机加入时代理会自动增加连接。

还有几点和直接挖矿时一样保持不变：

- **每台矿机保留自己的调优。** 线程数、GPU 选择和调优都保留在矿机上。[设置指南](/zh-hans/blog/configure-seine-miner/)介绍了这些设置，[服务器挖矿指南](/zh-hans/blog/mine-blocknet-on-servers/)介绍了大型 CPU 服务器。
- **网络升级。** 在 Faraday 网络升级时，代理会像矿池一样，要求运行不支持该升级的 seine 版本的矿机进行更新。
