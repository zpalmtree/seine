當每台礦機各自連線到礦池時，每次更換礦池都要在每台礦機上操作一遍。使用 seine 礦場代理後，你的礦機連線到網路中的一台機器，再由這台機器為整個礦場連線到 bntpool.com。你只需變更一次礦池、備用礦池或預設收款地址，每台礦機都會跟著變。每台礦機在 bntpool.com 上仍以自己的名稱顯示。內容依據 seine v0.3.1。

## 礦場代理能為你做什麼？

<Answer>
礦場代理是作為礦機本地礦池執行的 seine。它為整個礦場連線到 bntpool.com，並把各自那份工作分給每台礦機。你在一處管理礦池、備用礦池與預設收款地址，而每台礦機仍然各自挖礦、各自計入收益。
</Answer>

礦場透過代理執行後，會有這些變化：

- **重新啟動一次即可為整個礦場切換礦池。** 礦池與備用礦池都在代理上，所以你只需修改一條命令列，而不是每台礦機、每個 flight sheet 或設定檔。
- **所有礦機同時容錯移轉。** 在代理上列出備用礦池，整個礦場會一起切換到下一個礦池，並在第一個礦池恢復回應後切回。
- **一行指令新增礦機。** 新礦機只需把代理位址設為礦池，礦場的其他部分都不用改。
- **只有一台機器連線到網際網路。** 礦機透過本地網路與代理通訊，只有代理需要存取礦池。一條防火牆規則就能涵蓋整個礦場；對於封鎖挖礦連接埠的網路，SOCKS5 代理也只需設定在代理上。
- **每台礦機仍有自己的統計。** bntpool.com 依礦機記錄份額，所以每台礦機都會以自己的礦工名稱、算力與份額顯示在[統計頁面](https://bntpool.com/stats?lang=zh-hant)上。
- **一個代理支援多個錢包。** 每台礦機都支付到它登入時使用的地址，所以一個代理可以服務最多 16 個不同錢包的礦機，例如你為朋友或合作夥伴執行的礦機。

代理本身不挖礦。它幾乎不佔用 CPU 與記憶體，所以可以執行在一台小型伺服器上，也可以執行在某台礦機上，與該礦機自己的挖礦程式並行。

## 如何設定礦場代理？

<Answer>
用 --proxy-listen 指定礦機要連線的位址與連接埠，再加上常用的礦池、收款地址與礦機名稱選項來啟動 seine。例如：./seine --proxy-listen 0.0.0.0:3333 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_ADDRESS --pool-worker farm-1。然後把每台礦機的礦池 URL 指向代理。
</Answer>

設定分兩步：啟動代理，再讓礦機連線到它。

**1. 啟動代理。** 在要執行代理的機器上執行：

```bash
./seine --proxy-listen 0.0.0.0:3333 \
        --pool-url stratum+tcp://bntpool.com:3333 \
        --address YOUR_ADDRESS --pool-worker farm-1
```

`--proxy-listen` 設定代理接受礦機連線的位置；`0.0.0.0:3333` 表示在所有網路介面的 3333 連接埠上監聽。`--address` 是預設收款地址，用於沒有用有效地址登入的礦機。所有礦池選項都可以在代理上使用。備用礦池依序列出，用逗號分隔；如果你的網路需要透過 SOCKS5 代理才能存取礦池，再加上 `--pool-proxy socks5://host:port`。[seine 設定指南](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/guides/configuration.md)說明了礦池選項。

請把代理留在你的本地網路中：在 `--proxy-listen` 中使用區域網路位址，或用防火牆保護該連接埠，這樣只有你自己的礦機能透過它挖礦並支付到你的地址。

**2. 讓每台礦機連線到代理。** 把代理的本地位址用作礦池，並為礦機取一個自己的名稱：

```bash
./seine --pool-url 192.168.1.10:3333 --address YOUR_ADDRESS --pool-worker rig-07
```

把 `192.168.1.10` 換成代理機器在你網路中的位址。在挖礦系統上，依照 [HiveOS 與 mmpOS 指南](/zh-hant/blog/mine-blocknet-hiveos-mmpos/)所示，把代理位址填入 HiveOS flight sheet 或 mmpOS 設定檔的礦池 URL 欄位。seine 會把礦池與礦機的設定一起儲存，所以之後的啟動會自動連線到代理，此後你就在代理上管理礦池。

## 代理後面的礦機如何獲得支付？

每台礦機都支付到它登入時使用的完整 Blocknet 地址，和直接連線時完全一樣。挖到不同錢包的礦機可以共用一個代理，同時最多 16 個地址。沒有地址或使用無效地址登入的礦機，會支付到代理的 `--address`，所以它的算力仍然歸你。

當 16 個地址都在使用時，使用第 17 個地址的礦機會等待，直到其他某個地址連續 10 分鐘沒有礦機。如果礦池拒絕了某台礦機的地址，代理會轉達礦池給出的原因，方便你在那台礦機上修正。

代理後面的礦機也可以在 bntpool.com 上單獨挖礦：在礦機的地址前加上 `solo:`，礦池就會把該礦機找到的每個區塊的全部獎勵支付給它。[在 bntpool.com 上單獨挖礦](https://bntpool.com/blog/zh-hant/solo-mine-blocknet-on-bntpool/)說明了單獨挖礦的收益。支付到交易所使用儲值備註，而代理不傳遞備註，所以請讓支付到交易所的礦機直接連線到礦池。

## 如何追蹤礦場狀況？

在 bntpool.com 的[統計頁面](https://bntpool.com/stats?lang=zh-hant)上查詢每個收款地址。代理後面的每台礦機都會出現在 Workers 表中，顯示自己的礦機名稱、算力、份額與最後一個份額的時間，和直接連線時完全一樣。[礦機追蹤指南](https://bntpool.com/blog/zh-hant/track-your-miner-on-bntpool/)說明了該頁面。

代理還會提供自己的全礦場檢視。它每分鐘在日誌中記錄一次摘要：已連線的礦機、被接受與被拒絕的份額、整個礦場的估算算力以及礦池連線。每台礦機連線與中斷時它也會記錄，所以一份日誌就能看出礦機何時掉線。每台礦機自己的 seine 儀表板仍會顯示本地算力與份額，詳見[儀表板指南](/zh-hant/blog/seine-dashboard-explained/)。

## 礦場擴大後代理還能跟上嗎？

能。代理會開啟足夠的礦池連線，讓每台礦機在每個新區塊都能拿到工作。大多數礦場只需要一個或幾個，超大型礦場每個收款地址最多 64 個。你不需要設定這一點；礦機加入時代理會自動增加連線。

還有幾點和直接挖礦時一樣維持不變：

- **每台礦機保留自己的調校。** 執行緒數、GPU 選擇與調校都保留在礦機上。[設定指南](/zh-hant/blog/configure-seine-miner/)說明了這些設定，[伺服器挖礦指南](/zh-hant/blog/mine-blocknet-on-servers/)說明了大型 CPU 伺服器。
- **網路升級。** 在 Faraday 網路升級時，代理會像礦池一樣，要求執行不支援該升級的 seine 版本的礦機進行更新。
