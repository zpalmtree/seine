本指南說明如何用一個 seine 礦場代理執行 Blocknet 礦場。你在網路中的一台機器上啟動代理，讓每台礦機都連線到它，代理就會為整個礦場連線到 bntpool.com。你可以在一處設定礦池、收款地址與備用礦池，並在礦池上保留每台礦機的統計。內容依據 seine v0.3.1。

## 礦場代理有什麼作用？

<Answer>
礦場代理是作為礦機本地礦池執行的 seine。它為整個礦場只連線一次 bntpool.com，並把各自那份工作分給每台礦機。礦池只看到一個連線，每台礦機仍然各自挖礦、各自計入收益，你可以在一處為所有礦機變更礦池或備用礦池。
</Answer>

礦場代理適合執行不只幾台礦機的任何人：

- **一處設定。** 在代理上設定礦池、備用礦池與預設收款地址，每台礦機都會使用這些設定。
- **一個對外連線。** 礦機透過本地網路與代理通訊，代理只開啟礦場需要的礦池連線，通常是一個或幾個。
- **礦池上依礦機統計。** bntpool.com 依礦機記錄份額，所以每台礦機仍會以自己的礦工名稱顯示在[統計頁面](https://bntpool.com/stats?lang=zh-hant)上。

代理本身不挖礦。它幾乎不佔用 CPU 與記憶體，所以可以執行在礦機能存取的任何機器上，包括其中一台礦機。

## 如何啟動代理？

<Answer>
用 --proxy-listen 指定礦機要連線的位址與連接埠，再加上常用的礦池、收款地址與礦機名稱選項來啟動 seine。例如：./seine --proxy-listen 0.0.0.0:3333 --pool-url stratum+tcp://bntpool.com:3333 --address YOUR_ADDRESS --pool-worker farm-1。代理隨後會在 3333 連接埠等待礦機連線。
</Answer>

在要執行代理的機器上執行：

```bash
./seine --proxy-listen 0.0.0.0:3333 \
        --pool-url stratum+tcp://bntpool.com:3333 \
        --address YOUR_ADDRESS --pool-worker farm-1
```

`--proxy-listen` 設定代理接受礦機連線的位置；`0.0.0.0:3333` 表示在所有網路介面的 3333 連接埠上監聽。`--address` 是預設收款地址，用於沒有用有效地址登入的礦機。所有礦池選項都可以在代理上使用，包括備用礦池：依序列出，用逗號分隔，代理會在第一個礦池恢復後切回。[seine 設定指南](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/guides/configuration.md)說明了礦池選項。

請把代理繫結到你的本地網路。任何能存取其連接埠的人都能透過它挖礦，所以請在 `--proxy-listen` 中使用區域網路位址，或用防火牆保護該連接埠，而不要把它暴露到網際網路上。

## 如何讓礦機連線到代理？

在每台礦機上，把代理的本地位址用作礦池，並為礦機取一個自己的名稱：

```bash
./seine --pool-url 192.168.1.10:3333 --address YOUR_ADDRESS --pool-worker rig-07
```

把 `192.168.1.10` 換成代理機器在你網路中的位址。挖礦系統上的礦機也一樣：依照 [HiveOS 與 mmpOS 指南](/zh-hant/blog/mine-blocknet-hiveos-mmpos/)所示，把代理位址填入 HiveOS flight sheet 或 mmpOS 設定檔的礦池 URL 欄位。seine 會把礦池與礦機的設定一起儲存，所以之後的啟動會自動連線到代理。

## 代理後面的礦機如何獲得支付？

每台礦機都支付到它登入時使用的完整 Blocknet 地址。挖到不同錢包的礦機可以共用一個代理，同時最多 16 個地址。沒有地址或使用無效地址登入的礦機，會支付到代理的 `--address`。

當 16 個地址都在使用時，使用第 17 個地址的礦機會等待，直到其他某個地址連續 10 分鐘沒有礦機。如果礦池拒絕了某台礦機的地址，代理會轉達礦池給出的原因，方便你在那台礦機上修正。

代理後面的礦機也可以在 bntpool.com 上單獨挖礦：在礦機的地址前加上 `solo:`，礦池就會把該礦機找到的每個區塊的全部獎勵支付給它。[在 bntpool.com 上單獨挖礦](https://bntpool.com/blog/zh-hant/solo-mine-blocknet-on-bntpool/)說明了單獨挖礦的收益。支付到交易所需要儲值備註，而代理不傳遞備註，所以請讓挖到交易所的礦機直接連線到礦池。

## 如何追蹤礦場狀況？

在 bntpool.com 的[統計頁面](https://bntpool.com/stats?lang=zh-hant)上查詢每個收款地址。代理後面的每台礦機都會出現在 Workers 表中，顯示自己的礦機名稱、算力、份額與最後一個份額的時間，和直接連線時完全一樣。[礦機追蹤指南](https://bntpool.com/blog/zh-hant/track-your-miner-on-bntpool/)說明了該頁面。

代理也會每分鐘在日誌中記錄自己的摘要：已連線的礦機、被接受與被拒絕的份額、估算算力以及礦池連線。每台礦機連線與中斷時它都會記錄，所以有礦機掉線時你一眼就能看到。每台礦機自己的 seine 儀表板仍會顯示本地算力與份額，詳見[儀表板指南](/zh-hant/blog/seine-dashboard-explained/)。

## 還需要了解什麼？

- **礦池連線數隨礦場規模增長。** 代理會開啟足夠的礦池連線，讓每台礦機在每個新區塊都能拿到工作。大多數礦場只需要一個或幾個，超大型礦場每個收款地址最多 64 個。
- **每台礦機保留自己的設定。** 執行緒數、GPU 選擇與調校都保留在礦機上。[設定指南](/zh-hant/blog/configure-seine-miner/)說明了這些設定，[伺服器挖礦指南](/zh-hant/blog/mine-blocknet-on-servers/)說明了大型 CPU 伺服器。
- **網路升級。** 在 Faraday 網路升級時，代理會像礦池一樣，要求執行不支援該升級的 seine 版本的礦機進行更新。
