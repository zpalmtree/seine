Blocknet をマイニングするには報酬を受け取るアドレスが必要で、公式ウォレットを使えば数分で用意できます。このガイドでは、コマンドライン版またはデスクトップ版のウォレットでウォレットを作り、リカバリーシードをバックアップし、seine に貼り付けるアドレスを確認し、bntpool.com から支払いを受けたときに残高を確認する方法を説明します。

## マイニングにはどの Blocknet ウォレットを使えばよいですか？

<Answer>
Blocknet Privacy の 2 つの公式ウォレットのどちらかを使います。Windows、macOS、Linux で動くコマンドライン版ウォレットと、同じシステム向けのデスクトップ版ウォレットです。どちらもコンピューター上で Blocknet のフルノードを動かし、seine で bntpool.com にマイニングするための受け取りアドレスを用意できます。
</Answer>

- **コマンドライン版ウォレット。** `blocknet` プログラムは、ノード、ウォレット、ネットワークを動かすバックグラウンドプロセスである Blocknet コアのインストール、起動、更新を行います。ウォレットは対話型シェルで管理します。Windows、macOS、Linux 向けのビルドがある[コマンドライン版のリリース](https://github.com/blocknetprivacy/blocknet/releases/latest)からダウンロードできます。
- **デスクトップ版ウォレット。** Blocknet デーモンを同梱したグラフィカルなウォレットです。[デスクトップ版のリリース](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)からダウンロードできます。

どちらでも好きなほうを選んでください。以下では、すべてのコマンドがドキュメント化されているコマンドライン版ウォレットの手順を説明し、その後でデスクトップ版のインストールを説明します。

## コマンドライン版ウォレットでウォレットを作る方法

1. **コアをインストールして起動する。** リリースを展開し、セットアップウィザードを実行します。

   ```sh
   blocknet setup
   ```

   ウィザードは、ノードを自動で更新するかどうかを尋ね、最新のコアをダウンロードし、起動するかどうかを提案します。Windows ではプログラム名が `blocknet.exe` なので、`blocknet.exe setup` を実行します。ウィザードを使わない場合は、`blocknet install latest` を実行してから `blocknet start` を実行します。

2. **シェルを開く。** 実行中のコアに接続します。

   ```sh
   blocknet attach mainnet
   ```

   `>` プロンプトが表示されます。`quit` でシェルを閉じてもコアは動き続けるので、いつでも再接続できます。

3. **ウォレットを作る。** `load` と入力します。ウォレットは見つかったウォレットファイルを一覧表示し、「Create a new wallet」を提示します。その項目を選んで名前とパスワードを入力すると、コアが新しいリカバリーシード付きの新しいウォレットを作ります。

   ```
   > load
     ...
     4) Create a new wallet

     Choose: 4
     Wallet name (without extension):
   > mining
     Password: ********

     Wallet created
     Address:  9PNo...
     Filename: mining.wallet.dat
   ```

ウォレットは1つの `.wallet.dat` ファイルで、パスワードがその支出鍵を暗号化します。コアはウォレットのパスを記憶しますが、`blocknet start` の後もシェルに接続し、パスワードで `load` を使う必要があります。ウォレットファイルのコピーを別にバックアップとして保管してください。

## リカバリーシードはどうやってバックアップしますか？

リカバリーシードは最も重要なバックアップです。12 単語からなり、ウォレットファイルを失ったりパスワードを忘れたりしても、これがあればどのコンピューターでもウォレットを復元できます。Blocknet はパスワードを保存しないので、パスワードを忘れたときもシードで復旧します。

`seed` コマンドで表示します。ウォレットは警告を表示し、確認とパスワードの入力を求めてから単語を表示します。

```
> seed

# Seed
  WARNING: Your recovery seed controls all funds.
  Anyone with this seed can steal your coins.
  Never share it. Never enter it online.

  Show recovery seed? [y/N]: y
  Password: ********
```

12 単語を紙に書き、オフラインの安全な場所に保管してください。ウォレットのガイドでは、単語を知っている人は誰でも資金を動かせるため、テキストファイル、メモアプリ、クラウドストレージに保存しないよう求めています。12 単語がどのように鍵になるのか、どう保管すればよいのかは[シードフレーズのガイド](/ja/blog/seed-phrase-explained/)で説明しています。

後で復元するには、`import` を実行して `1) 12-word recovery seed` を選び、単語を入力して、新しいウォレットに名前とパスワードを付けます。その後、コアがチェーンをスキャンしてあなたのアウトプットを探します。

## Blocknet アドレスはどうやって確認しますか？

<Answer>
コマンドライン版ウォレットでは、シェルのプロンプトで address（または addr）と入力します。ウォレットは 92 文字または 93 文字の受け取りアドレスを表示し、続いてショートネームを取得できる blocknet.id への案内を表示します。アドレス全体をコピーし、seine が受け取りアドレスを尋ねたときに貼り付けてください。
</Answer>

```
> addr

# Address

  9PNoFCqUa7K8e5JfV2Hs3TBt7kMzRGkPxJ4xVmn5cFb...

  Get a short name like @name or $name at https://blocknet.id
```

これが seine に渡すアドレスです。[seine](/ja/#download) を初めて起動すると、受け取りアドレス、続いてプールを尋ねられます。アドレスを貼り付け、Enter キーを押して bntpool.com を選びます。直接指定することもできます。

```sh
./seine --address <your-address>
```

seine がマイニングを始めると、[ダッシュボード](/ja/blog/seine-dashboard-explained/)のプール残高パネルにマイニング先アドレスの最初と最後の 6 文字が表示されるので、ウォレットと一致しているか確認できます。

もっと短いものを使いたい場合は、`@yourname` のような [Blocknet ID のショートネーム](/ja/blog/blocknet-id-pay-by-name/)がこのアドレスを指し、seine と bntpool.com で使えます。

## デスクトップ版ウォレットの設定

デスクトップ版ウォレットの最新リリース（v0.22.0、2026 年 10 月 15 日公開）には、次のダウンロードがあります。

| システム | ファイル |
|---|---|
| Windows x86_64 | `.exe` インストーラー |
| macOS Apple シリコン | `.dmg` |
| macOS Intel | `.app.zip` |
| Linux x86_64 | `.AppImage`、`.deb`、`.rpm`、`.flatpak` |

すべてのリリースに `SHA256SUMS.txt` が含まれているので、インストール前にダウンロードを確認できます。

```sh
sha256sum -c SHA256SUMS.txt
```

Linux では `.deb` をインストールするか、`.AppImage` を直接実行します。macOS では、アプリを「アプリケーション」に移動し、README の指示どおり初回起動の前にターミナルで次を一度実行します。

```sh
xattr -cr /Applications/blocknet.app
```

Windows では、インストーラーに対して Defender の確認画面が表示された場合、「詳細情報」をクリックしてから「実行」をクリックします。

アプリは同梱の Blocknet デーモンをコンピューター上で動かして `127.0.0.1` 経由で通信し、外部のサービスにはリクエストを送りません。アプリでウォレットを作り、リカバリーシードを書き留め、受け取りアドレスを seine にコピーします。デスクトップ版ウォレットは `blocknet://` の[支払いリンク](/ja/blog/blocknet-payment-links/)も開き、送金フォームに入力した状態で確認画面を表示します。

## 鍵は自分のコンピューターに置いておく

マイニングマシンに必要なのはアドレスだけです。seine はアドレスかショートネームさえあればマイニングできるので、ウォレットファイルとリカバリーシードは信頼できるコンピューターに置いたままにできます。これは、レンタルサーバー、共用リグ、ほかの人がアクセスできるマシンで特に重要です。

- **ウォレットは自宅で、マイニングはどこでも。** seine を動かすすべてのマシンに同じアドレスを設定します。bntpool.com はそれらのシェアを 1 つの残高にまとめます。
- **鍵なしで進捗を確認する。** [bntpool.com](https://bntpool.com) で自分のアドレスを検索すれば、どのブラウザーからでもハッシュレート、シェア、残高を確認できます。
- **閲覧専用アクセス。** 別のコンピューターで入金を確認したい場合は、`viewkeys` で閲覧専用の鍵をエクスポートできます。閲覧専用ウォレットは入金を表示でき、送金や署名はできません。
- **離れるときはロックする。** `lock` を使うと、パスワードで `unlock` するまで送金ができなくなります。

## マイニングの支払いはウォレットにどう表示されますか？

bntpool.com は、ブロックが成熟した時点で報酬を支払います。プールのブロックには 60 承認が必要で、Blocknet の 5 分のブロック時間で約 5 時間です。承認済みの残高が最低額の 1 BNT に達すると、プールが通常の Blocknet トランザクションとしてあなたのアドレスへ送金します。

ウォレットでは `balance`（または `bal`）で確認します。

```
> bal

# Balance
  spendable:  12.5 BNT
  confirming: 1 BNT
  total:      13.5 BNT
```

新しい支払いは、まず `confirming` に表示されます。通常のトランザクションは 10 承認（約 50 分）後に使えるようになり、`spendable` に移ります。`history` コマンドは受け取ったトランザクションを古い順に一覧表示し、それぞれのブロック、金額、種類を示します。プールからの支払いは `regular` と表示され、ソロモードで自分で見つけたブロックは `coinbase` と表示されます。後者は使えるようになるまで 60 承認が必要です。

ウォレットに支払いが表示されるのは、ノードがチェーンに追いついてからです。追いつくと `status` に `Syncing: false` と表示され、`sync` はダウンロード済みのブロックを再スキャンしてあなたのアウトプットを探します。

マイニングが初めての方は、[Blocknet のマイニングガイド](/ja/blog/how-to-mine-blocknet/)で seine のダウンロード、スレッドの選び方、bntpool.com での流れをご覧ください。
