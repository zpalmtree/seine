การขุด Blocknet ต้องมีที่อยู่สำหรับรางวัล กระเป๋าเงินทางการสร้างให้ได้ในไม่กี่นาที คู่มือนี้แสดงการสร้างกระเป๋าเงินด้วยรุ่นบรรทัดคำสั่งหรือเดสก์ท็อป สำรองวลีกู้คืน หาที่อยู่ไปวางใน seine และตรวจยอดเมื่อ bntpool.com จ่ายให้คุณ

## ควรใช้กระเป๋าเงิน Blocknet ใดสำหรับขุด?

<Answer>
ใช้หนึ่งในสองกระเป๋าเงินทางการจาก Blocknet Privacy: รุ่นบรรทัดคำสั่งที่ทำงานบน Windows, macOS และ Linux หรือรุ่นเดสก์ท็อปสำหรับระบบเดียวกัน ทั้งสองเปิดโหนด Blocknet เต็มบนคอมพิวเตอร์และให้ที่อยู่รับเงินเพื่อขุดบน bntpool.com ด้วย seine
</Answer>

- **กระเป๋าเงินแบบบรรทัดคำสั่ง** โปรแกรม `blocknet` ติดตั้ง เริ่มและอัปเดต Blocknet core ซึ่งเป็นกระบวนการเบื้องหลังที่ดูแลโหนด กระเป๋าเงินและเครือข่าย คุณจัดการผ่านเชลล์แบบโต้ตอบ ดาวน์โหลดจาก[รีลีสบรรทัดคำสั่ง](https://github.com/blocknetprivacy/blocknet/releases/latest) ที่มีรุ่น Windows, macOS และ Linux
- **กระเป๋าเงินเดสก์ท็อป** กระเป๋าเงินแบบกราฟิกที่รวม Blocknet daemon ดาวน์โหลดจาก[รีลีสเดสก์ท็อป](https://github.com/blocknetprivacy/blocknet-gui/releases/latest)
- **Gyroid** วอลเล็ตจากชุมชนที่รวมหน้าจอกราฟิกและเครื่องมือบรรทัดคำสั่งไว้ในโปรแกรมเดียว พัฒนาโดย obselate ผู้ร่วมพัฒนาแกนของ Blocknet ดู[การเปรียบเทียบวอลเล็ต](/th/blog/blocknet-wallets/) สำหรับทั้งสามแบบ

เลือกแบบที่ชอบ ขั้นตอนต่อไปใช้รุ่นบรรทัดคำสั่งเพราะมีเอกสารทุกคำสั่ง แล้วจึงอธิบายการติดตั้งเดสก์ท็อป

## สร้างกระเป๋าเงินด้วยรุ่นบรรทัดคำสั่งอย่างไร

1. **ติดตั้งและเริ่ม core** แตกไฟล์รีลีสแล้วเรียกตัวช่วยตั้งค่า:

   ```sh
   blocknet setup
   ```

   ตัวช่วยถามว่าจะอัปเดตโหนดอัตโนมัติไหม ดาวน์โหลด core ล่าสุด และเสนอให้เริ่ม บน Windows โปรแกรมชื่อ `blocknet.exe` จึงใช้ `blocknet.exe setup` หากข้ามตัวช่วย ให้ใช้ `blocknet install latest` แล้ว `blocknet start`

2. **เปิดเชลล์** เชื่อมต่อกับ core ที่ทำงานอยู่:

   ```sh
   blocknet attach mainnet
   ```

   คุณจะเห็นพรอมป์ต์ `>` การปิดเชลล์ด้วย `quit` ไม่หยุด core จึงเชื่อมต่อกลับได้ทุกเวลา

3. **สร้างกระเป๋าเงิน** พิมพ์ `load` กระเป๋าเงินแสดงไฟล์ที่พบและตัวเลือก “Create a new wallet” เลือกตัวเลือกนั้น ใส่ชื่อและรหัสผ่าน แล้ว core สร้างกระเป๋าเงินใหม่พร้อมวลีกู้คืนใหม่:

   ```
   > load
     ...
     4) Create a new wallet

     Choose: 4
     Wallet name (without extension):
   > mining
     Password: ********

     Wallet created
     Address:  9PNo...
     Filename: mining.wallet.dat
   ```

กระเป๋าเป็นไฟล์ `.wallet.dat` ไฟล์เดียว และรหัสผ่านของคุณเข้ารหัสคีย์ใช้จ่ายของมัน คอร์จำพาธกระเป๋าไว้ แต่หลัง `blocknet start` คุณยังต้องเชื่อมต่อเชลล์และใช้ `load` พร้อมรหัสผ่าน เก็บสำเนาไฟล์กระเป๋าแยกไว้เป็นข้อมูลสำรอง

## สำรองวลีกู้คืนอย่างไร?

วลีกู้คืนเป็นข้อมูลสำรองที่สำคัญที่สุด มี 12 คำที่ใช้สร้างกระเป๋าเงินกลับบนคอมพิวเตอร์ใดก็ได้ แม้ไฟล์หายหรือลืมรหัสผ่าน Blocknet ไม่เก็บรหัสผ่านของคุณ วลีนี้จึงใช้กู้คืนเมื่อลืมรหัสผ่านด้วย

แสดงด้วยคำสั่ง `seed` กระเป๋าเงินแสดงคำเตือน ขอคำยืนยันและรหัสผ่าน แล้วแสดงคำ:

```
> seed

# Seed
  WARNING: Your recovery seed controls all funds.
  Anyone with this seed can steal your coins.
  Never share it. Never enter it online.

  Show recovery seed? [y/N]: y
  Password: ********
```

เขียน 12 คำลงกระดาษและเก็บในที่ปลอดภัยออฟไลน์ คู่มือกระเป๋าเงินระบุว่าไม่ควรเก็บในไฟล์ข้อความ แอปจดโน้ต หรือคลาวด์ เพราะใครมีคำก็มีสิทธิ์ควบคุมเงิน คู่มือ[วลีกู้คืน](/th/blog/seed-phrase-explained/) อธิบายว่า 12 คำกลายเป็นคีย์อย่างไรและควรเก็บอย่างไร

หากต้องการกู้คืนภายหลัง ใช้ `import` เลือก `1) 12-word recovery seed` พิมพ์คำ แล้วตั้งชื่อและรหัสผ่านกระเป๋าเงินใหม่ จากนั้น core สแกนเชนหาเอาต์พุตของคุณ

## หาที่อยู่ Blocknet อย่างไร?

<Answer>
ในกระเป๋าเงินแบบบรรทัดคำสั่ง พิมพ์ address หรือ addr ที่พรอมป์ต์ กระเป๋าเงินแสดงที่อยู่รับเงินยาว 92 หรือ 93 ตัวอักษร ตามด้วยข้อมูล blocknet.id สำหรับชื่อสั้น คัดลอกที่อยู่ทั้งหมดแล้ววางใน seine เมื่อถามที่อยู่รับเงิน
</Answer>

```
> addr

# Address

  9PNoFCqUa7K8e5JfV2Hs3TBt7kMzRGkPxJ4xVmn5cFb...

  Get a short name like @name or $name at https://blocknet.id
```

นี่คือที่อยู่ที่ให้ seine เมื่อเปิด [seine](/th/#download) ครั้งแรก โปรแกรมถามที่อยู่รับเงินแล้วถามพูล ให้วางที่อยู่และกด Enter เพื่อใช้ bntpool.com หรือส่งโดยตรงได้:

```sh
./seine --address <your-address>
```

เมื่อ seine ขุดแล้ว แผงยอดพูลบน[แดชบอร์ด](/th/blog/seine-dashboard-explained/) แสดงหกตัวแรกและหกตัวท้ายของที่อยู่ที่ขุดไป คุณจึงตรวจว่าตรงกับกระเป๋าเงิน

หากอยากขุดไปยังชื่อสั้นกว่า [ชื่อสั้น Blocknet ID](/th/blog/blocknet-id-pay-by-name/) เช่น `@yourname` ชี้ไปที่อยู่นี้และใช้กับ seine และ bntpool.com ได้

## ตั้งค่ากระเป๋าเงินเดสก์ท็อป

รีลีสล่าสุดของกระเป๋าเงินเดสก์ท็อป (v0.22.0 เผยแพร่ 15 ตุลาคม 2026) มีไฟล์ดังนี้:

| ระบบ | ไฟล์ |
|---|---|
| Windows x86_64 | ตัวติดตั้ง `.exe` |
| macOS Apple Silicon | `.dmg` |
| macOS Intel | `.app.zip` |
| Linux x86_64 | `.AppImage`, `.deb`, `.rpm`, `.flatpak` |

ทุกรีลีสมี `SHA256SUMS.txt` ให้ตรวจไฟล์ก่อนติดตั้ง:

```sh
sha256sum -c SHA256SUMS.txt
```

บน Linux ติดตั้ง `.deb` หรือเปิด `.AppImage` โดยตรง บน macOS ย้ายแอปไป Applications แล้วใช้คำสั่งนี้ครั้งเดียวใน Terminal ก่อนเปิดครั้งแรกตาม README:

```sh
xattr -cr /Applications/blocknet.app
```

บน Windows หาก Defender แสดงข้อความกับตัวติดตั้ง ให้กด “More info” แล้ว “Run anyway”

แอปเปิด Blocknet daemon ที่รวมมาบนเครื่องและสื่อสารผ่าน `127.0.0.1` โดยไม่ส่งคำขอไปบริการภายนอก สร้างกระเป๋าเงินในแอป จดวลีกู้คืน แล้วคัดลอกที่อยู่รับเงินไป seine กระเป๋าเงินเดสก์ท็อปยังเปิด[ลิงก์ชำระเงิน](/th/blog/blocknet-payment-links/) `blocknet://` และกรอกแบบฟอร์มส่งให้ตรวจได้

## เก็บคีย์บนคอมพิวเตอร์ของคุณ

เครื่องขุดต้องมีเพียงที่อยู่ seine ใช้เพียงที่อยู่หรือชื่อสั้นในการขุด ไฟล์กระเป๋าเงินและวลีกู้คืนจึงอยู่บนเครื่องที่คุณไว้ใจได้ เรื่องนี้สำคัญเป็นพิเศษกับเซิร์ฟเวอร์เช่า ริกที่แชร์ และเครื่องที่ผู้อื่นเข้าถึงได้

- **เปิดกระเป๋าเงินที่บ้าน ขุดที่ไหนก็ได้** ใส่ที่อยู่เดียวกันในทุกเครื่องที่ใช้ seine แล้ว bntpool.com รวมแชร์เป็นยอดเดียว
- **ดูความคืบหน้าโดยไม่ใช้คีย์** ค้นหาที่อยู่บน [bntpool.com](https://bntpool.com) เพื่อดูแฮชเรต แชร์และยอดจากเบราว์เซอร์ใดก็ได้
- **สิทธิ์ดูอย่างเดียว** หากต้องการดูเงินเข้าบนเครื่องที่สอง `viewkeys` ส่งออกคีย์แบบดูอย่างเดียว กระเป๋าเงินชนิดนี้แสดงเงินเข้าและส่งหรือลงลายเซ็นไม่ได้
- **ล็อกเมื่อไม่อยู่** `lock` ปิดการใช้จ่ายจนกว่าจะ `unlock` ด้วยรหัสผ่าน

## เงินจากการขุดแสดงในกระเป๋าเงินอย่างไร?

bntpool.com จ่ายรางวัลเมื่อบล็อกครบกำหนด บล็อกพูลต้องยืนยัน 60 ครั้ง ประมาณห้าชั่วโมงตามเวลาบล็อกห้านาทีของ Blocknet เมื่อยอดที่ยืนยันแล้วถึงขั้นต่ำ 1 BNT พูลส่งไปที่อยู่คุณเป็นธุรกรรม Blocknet ปกติ

ในกระเป๋าเงิน ตรวจด้วย `balance` หรือ `bal`:

```
> bal

# Balance
  spendable:  12.5 BNT
  confirming: 1 BNT
  total:      13.5 BNT
```

ยอดจ่ายใหม่ปรากฏใน `confirming` ก่อน ธุรกรรมปกติใช้จ่ายได้หลังยืนยัน 10 ครั้ง ประมาณ 50 นาที แล้วจึงย้ายไป `spendable` คำสั่ง `history` แสดงธุรกรรมขาเข้าจากเก่าไปใหม่ พร้อมบล็อก จำนวนเงินและประเภท: ยอดจ่ายพูลเป็น `regular` ส่วนบล็อกที่คุณพบเองในโหมดเดี่ยวเป็น `coinbase` ซึ่งต้องยืนยัน 60 ครั้งก่อนใช้จ่าย

กระเป๋าเงินแสดงยอดจ่ายเมื่อโหนดตามเชนทันแล้ว `status` แสดง `Syncing: false` เมื่อทัน และ `sync` สแกนบล็อกที่ดาวน์โหลดแล้วใหม่เพื่อหาเอาต์พุตของคุณ
