이 가이드에서는 2026년 CPU 채굴의 현주소, 메모리 하드 작업 증명을 쓰는 코인이 일반 컴퓨터의 경쟁력을 지켜 주는 이유, 프로세서로 채굴할 코인을 고를 때 살펴볼 점, 그리고 seine로 몇 분 만에 Blocknet 채굴을 시작하는 방법을 설명합니다.

## 2026년에도 CPU로 암호화폐를 채굴할 수 있습니까?

<Answer>
네, 작업 증명이 범용 프로세서를 위해 설계된 코인이라면 가능합니다. Bitcoin은 전용 ASIC 칩으로 채굴하고 Ethereum은 2022년에 채굴을 끝냈지만, Monero의 RandomX와 Blocknet의 Argon2id 같은 메모리 하드 알고리즘에서는 CPU가 여전히 제 몫을 합니다. 모든 해시에 연산뿐 아니라 수 기가바이트의 빠른 메모리가 필요하기 때문입니다.
</Answer>

채굴은 CPU에서 시작되었습니다. Bitcoin 백서는 작업 증명을 "본질적으로 CPU 하나당 한 표"라고 설명합니다. Bitcoin이 성장하면서 채굴자들은 그래픽 카드로, 이어서 FPGA로, 그다음에는 Bitcoin의 SHA-256 해시 계산만 하는 칩인 ASIC으로 옮겨 갔습니다. 지금은 Bitcoin 채굴이 주로 Bitcoin 전용 ASIC으로 이루어집니다.

Ethereum은 2022년 9월 15일 머지(Merge)로 작업 증명에서 지분 증명으로의 전환을 마쳤습니다. 그 이후로 Ethereum은 채굴로 블록을 만들지 않습니다. 두 설계의 차이는 [작업 증명과 지분 증명](/ko/blog/proof-of-work-vs-proof-of-stake/) 가이드에서 설명합니다.

따라서 2026년의 CPU 채굴은 한 가지 선택으로 귀결됩니다. 일반 컴퓨터가 이미 갖춘 프로세서와 메모리를 위해 만들어진 알고리즘을 쓰는 코인을 고르는 것입니다.

## 메모리 하드 코인은 왜 일반 컴퓨터에 유리합니까?

<Answer>
메모리 하드 작업 증명은 해시마다 큰 메모리 블록을 채우고 다시 읽게 합니다. 해시 계산 전용 칩도 코어마다 옆에 수 기가바이트의 빠른 RAM이 필요하지만, 데스크톱, 노트북, 서버는 이미 그런 메모리와 이를 공급하는 컨트롤러를 갖추고 있습니다.
</Answer>

Bitcoin의 SHA-256은 메모리가 거의 필요 없습니다. 해시 하나는 짧은 연산 한 묶음으로 끝나므로, 맞춤형 칩은 작은 해시 회로를 나란히 잔뜩 넣을 수 있습니다. 범용 프로세서는 SHA-256이 전혀 쓰지 않는 캐시, 분기 예측, 명령어 디코딩까지 갖추고 있습니다.

메모리 하드 알고리즘은 작업이 일어나는 곳을 바꿉니다. Blocknet의 작업 증명은 2 GiB 메모리, 패스 1회, 레인 하나를 쓰는 [Argon2id](/ko/blog/argon2id-proof-of-work-explained/)입니다. 해시마다 약 2 GiB의 메모리를 쓰고 약 2 GiB를 다시 읽습니다. 패스의 후반부에서는 새 블록마다 채굴기가 미리 예측할 수 없는 데이터로 고른 이전 블록을 읽습니다. 2 GiB 블록 전체가 만들어져야 해시가 끝나므로, 속도는 메모리 시스템이 데이터를 얼마나 빨리 옮기는지, 그리고 RAM에 2 GiB 블록이 한 번에 몇 개 들어가는지에 달려 있습니다.

바로 이 부분이 일반 컴퓨터가 이미 잘하는 일입니다. Blocknet의 데몬 코드는 의도를 직접 밝힙니다. "ASIC에 저항하고 공정한 채굴을 보장하기 위한 메모리 하드 PoW"이며, 2 GB 크기가 "전용 하드웨어를 비실용적으로" 만든다는 것입니다. Argon2id는 ASIC에 저항하도록 설계되었고, 2 GiB 설정은 그 설계가 사람들이 이미 가진 컴퓨터에 유리하게 작동하도록 합니다.

## CPU로는 무엇을 채굴해야 합니까?

목록을 쫓기보다 다음 몇 가지 질문으로 코인을 확인해 보세요.

- **알고리즘이 CPU를 위해 설계되었습니까?** Monero의 RandomX는 "범용 CPU에 최적화된 작업 증명(PoW) 알고리즘"이며, Monero는 2019년 11월 30일에 이를 활성화했습니다. Blocknet의 Argon2id는 해시마다 2 GiB 메모리를 쓰므로 RAM과 메모리 대역폭이 결정적인 자원이 됩니다.
- **공정하게 출시되었습니까?** Blocknet의 제네시스 블록에는 트랜잭션이 없고, 모든 블록의 보상은 그 블록을 찾은 채굴자에게 지급되는 출력 하나뿐입니다. 합의 규칙에 프리마인, 트레저리, 개발자 펀드가 없으므로 유통 중인 모든 코인은 채굴된 것입니다.
- **내 프로세서를 잘 아는 채굴기가 있습니까?** 좋은 채굴기는 CPU 제품군마다 별도의 코드 경로를 제공하고 내 컴퓨터에서 가장 빠른 것을 고릅니다.
- **지급이 꾸준한 풀이 있습니까?** 풀 채굴은 많은 소규모 채굴자를 모아 블록 단위가 아니라 정기적으로 보상이 들어오게 합니다. 풀과 셰어는 [암호화폐 채굴의 원리](/ko/blog/how-crypto-mining-works/) 가이드에서 설명합니다.

Blocknet은 네 가지 모두를 충족합니다. [기본 프라이버시](/ko/blog/blocknet-privacy-features/), 5분 블록, 이름으로 결제하는 기능을 갖춘 프라이버시 코인이며, 2026년 2월에 출시되었습니다. 채굴기 seine는 무료 오픈 소스이고, 기본 풀인 bntpool.com은 6시간 구간의 PPLNS 방식으로 지급합니다. 코인 자체는 [Blocknet 개요](/ko/blog/what-is-blocknet/)에서 다룹니다.

## 메모리 하드 채굴에서 CPU를 빠르게 만드는 것은 무엇입니까?

프로세서가 Blocknet에서 초당 몇 개의 해시(H/s)를 내는지는 세 가지가 결정합니다.

**RAM 용량.** 채굴 스레드마다 해시 하나에 전용 2 GiB 블록이 필요하므로, RAM 용량을 2로 나누면 들어가는 최대 스레드 수가 나옵니다. 32 GB 컴퓨터에는 이론상 블록 16개가 들어갑니다. seine는 RAM의 5% (기본 최대 1 GiB)를 예비로 남기고 운영 체제용 공간도 남기므로, 이 컴퓨터는 약 14개의 스레드를 돌립니다. 코어 수보다 RAM이 먼저 스레드 수를 제한하는 경우가 많습니다. 4-16 GB 컴퓨터는 [오래된 PC나 노트북으로 채굴하기](/ko/blog/mine-crypto-on-old-pc-or-laptop/) 가이드에서 다룹니다.

**메모리 대역폭.** 해시마다 수 기가바이트가 메모리 시스템을 오갑니다. seine로 측정한 가장 빠른 컴퓨터는 97.1 H/s에서 매초 약 194.2 GiB의 새 메모리 블록을 씁니다(97.1 × 2 GiB). 메모리 채널이 더 많고 메모리가 더 빠른 프로세서가 앞서 나갑니다.

**알맞은 커널.** seine은 채굴 중 사용 가능한 CPU 커널을 비교하고 해당 컴퓨터에 맞는 커널을 선택합니다.

측정된 하드웨어 구성:

| 하드웨어 | 정확한 칩 | 스레드 | 해시레이트 |
|---|---|---|---|
| AMD EPYC · Zen 5 | EPYC 9355P 서버 | 64 | 97.1 H/s |
| Arm 서버 | AWS Graviton4 | 32 | 39.3 H/s |
| AMD EPYC · Zen 4 | EPYC 9R14 서버 | 32 | 45.3 H/s |
| Apple M4 Max | 48 GB MacBook Pro | 16 | 30.9 H/s |
| Intel Xeon | Sapphire Rapids 8488C | 32 | 26.0 H/s |

이 측정에서 가장 빠른 구성은 97.1 H/s를 기록한 AMD EPYC 9355P입니다. Linux에서 seine의 기본 설정으로 채굴 스레드 64개와 RAM 192 GiB를 사용했습니다. Blocknet 채굴은 메모리 대역폭과 스레드당 2 GiB를 제공할 만큼 충분한 RAM의 이점을 얻습니다. NVIDIA 카드는 CPU와 함께 해시레이트를 더할 수 있습니다.

EPYC 9R45 및 9R14 클라우드 결과는 32개 스레드와 transparent huge pages를 사용합니다. 시작 시간을 제외한 해싱 시간을 측정합니다. 다른 행은 각자의 측정 조건을 유지합니다.

## Blocknet CPU 채굴은 어떻게 시작합니까?

seine는 설정이 필요 없습니다. 컴퓨터에 맞게 스스로 조정하고 바로 해시 계산을 시작합니다.

1. **주소를 준비합니다.** 공식 Blocknet 지갑을 설치하고 주소를 복사하거나, [Blocknet ID 짧은 이름](/ko/blog/blocknet-id-pay-by-name/)을 받아 `@name`으로 채굴하세요. [지갑 가이드](/ko/blog/blocknet-wallet-for-mining/)에서 안내합니다.
2. **seine를 다운로드합니다.** [다운로드 섹션](/ko/#download)에서 Windows, macOS, Linux용을 받아 압축을 푸세요.
3. **실행하고** 묻는 화면에서 주소를 붙여 넣습니다.

```sh
./seine
```

4. **기본 풀인** `stratum+tcp://bntpool.com:3333`을 선택하면 채굴이 시작됩니다.

채굴하는 동안 seine는 실제 채굴 작업으로 스레드 수와 CPU 커널을 비교하고, 메모리가 빠듯해지면 사용량을 줄이며, 효과가 있었던 설정을 기억해 다음 실행 때 사용합니다. Windows와 Linux에서는 컴퓨터의 NVIDIA 그래픽 카드로도 동시에 채굴하며, 해시레이트가 합산됩니다. 지급은 [단계별 채굴 가이드](/ko/blog/how-to-mine-blocknet/)에서 다루며, Linux에서는 [휴즈 페이지 가이드](/ko/blog/huge-pages-blocknet-mining/)를 따르면 2 MiB 페이지로 약 4-6%, 1 GiB 페이지로 2%를 더 얻을 수 있습니다.

## 내 CPU는 얼마나 채굴합니까?

먼저 해시레이트를 측정하세요. seine의 오프라인 벤치마크는 풀이나 노드가 필요 없습니다.

```sh
./seine --bench --bench-kind backend --backend cpu --bench-secs 20 --bench-rounds 3
```

그다음 실시간 수치로 계산하세요. Blocknet은 5분마다 블록 하나, 즉 하루 288개 블록을 목표로 합니다. 예상 몫은 다음과 같습니다.

- **하루 블록 수** = 288 × (내 H/s ÷ 네트워크 H/s)
- **하루 BNT** = 하루 블록 수 × 현재 블록 보상

네트워크 해시레이트와 블록 보상은 시간에 따라 바뀌므로, 계산하기 전에 [bntpool.com](https://bntpool.com)에서 최신 값을 확인하세요. 풀에서는 블록을 통째로 직접 찾을 때까지 기다리는 대신, 잔액이 1 BNT에 도달하면 정기적인 PPLNS 지급을 받습니다. 그 BNT의 가치는 코인 가격과 전기 요금에 따라 달라집니다.

<Note>
위 내용은 모두 Blocknet의 현재 Argon2id 작업 증명 기준입니다. [blocknetcrypto.com](https://blocknetcrypto.com/#faraday)에 따르면 Blocknet은 2027년 2월 16일 무렵 Faraday라는 네트워크 업그레이드를 계획하고 있으며, 이 업그레이드로 "더 가벼운 작업 증명"이 도입될 예정입니다. seine는 시작할 때와 12시간마다 새 릴리스를 확인합니다.
</Note>
