## 如何開始在 Linux 上挖掘 Blocknet？

<Answer>
下載並解壓縮 seine，輸入 Blocknet 地址，然後在 bntpool.com 確認份額已被接受。先使用自動設定；效能調校建議放在設定步驟之後。
</Answer>

## 第 1 步：下載適合的版本

開啟[下載區](/zh-hant/#download)。執行 `uname -m`：結果為 `x86_64` 時選擇 `seine-linux-x86_64.tar.gz`，為 `aarch64` 時選擇 `seine-linux-aarch64.tar.gz`。Linux 版本需要 glibc 2.31 或更新版本。x86_64 版本支援 CPU 和 NVIDIA，ARM64 版本支援 CPU 挖礦。

## 第 2 步：解壓縮並啟動

開啟終端機。以下指令假設壓縮檔位於 Downloads 資料夾；如果位置不同，請使用實際路徑。在 ARM64 上，將 `seine-linux-x86_64.tar.gz` 替換為 `seine-linux-aarch64.tar.gz`。指令會將 seine 解壓縮到個人專屬檔案夾中並啟動：

```sh
mkdir -p "$HOME/seine"
tar -xzf "$HOME/Downloads/seine-linux-x86_64.tar.gz" -C "$HOME/seine"
cd "$HOME/seine"
./seine
```

## 第 3 步：輸入錢包地址

貼上你的公開 Blocknet 收款地址或已註冊的 `@name`，然後按 Enter 接受 `stratum+tcp://bntpool.com:3333`。[錢包指南](/zh-hant/blog/blocknet-wallet-for-mining/)說明了在哪裡找到地址。seine 不需要復原詞組或支出金鑰，並會自動分配礦池礦機名稱。

## 第 4 步：查看已接受的份額

在[儀表板](/zh-hant/blog/seine-dashboard-explained/)中查看雜湊率和持續增加的 **Accepted** 計數。份額被接受表示礦池收到了你的工作，並不表示已經付款。按 `q` 或 `Ctrl+C` 停止。

開啟[我的統計](https://bntpool.com/stats?lang=zh-hant)，輸入相同的地址或已註冊名稱，即可查看礦機、份額和餘額。

## 在 Linux 上用 GPU 挖礦需要什麼？

NVIDIA 顯示卡只需要 NVIDIA 驅動程式。AMD 顯示卡需要 amdgpu 驅動程式和 ROCm HIP 執行環境，詳見 [AMD 指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md)。seine 會自動找到你的顯示卡，並在 x86_64 版本中與 CPU 一起用它們挖礦。[NVIDIA 指南](/zh-hant/blog/mine-blocknet-nvidia-gpu/)說明如何選擇顯示卡和檢查 GPU 份額。

## 如何解決 Linux 啟動錯誤？

根據第一則錯誤訊息選擇下一項檢查：

| 訊息或症狀 | 檢查項目 |
|---|---|
| `Exec format error` | 架構不符：將 `uname -m` 與壓縮檔檔名比較。 |
| `GLIBC_... not found` | 二進位程式需要更新的 glibc。請使用相容系統或從原始碼建置；系統 C 程式庫應繼續由發行版管理。 |
| `Permission denied` | 檢查使用者執行權限，並使用允許執行程式之檔案系統上的資料夾。 |

份額開始獲接受後，可參閱[巨型記憶體分頁指南](/zh-hant/blog/huge-pages-blocknet-mining/)進行選用的 Linux 分頁設定。[伺服器指南](/zh-hant/blog/mine-blocknet-on-servers/)介紹無頭執行與 NUMA 配置。這兩項準備都不是完成本首次執行教學的必要條件；請分別進行每項變更，以便判斷電腦上具體改變了什麼。
