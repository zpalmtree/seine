## 如何开始在 Linux 上挖掘 Blocknet？

<Answer>
下载并解压 seine，输入 Blocknet 地址，然后在 bntpool.com 确认份额已被接受。先使用自动设置；性能调优建议放在设置步骤之后。
</Answer>

## 第 1 步：下载适合的版本

打开[下载区](/zh-hans/#download)。运行 `uname -m`：结果为 `x86_64` 时选择 `seine-linux-x86_64.tar.gz`，为 `aarch64` 时选择 `seine-linux-aarch64.tar.gz`。Linux 版本需要 glibc 2.31 或更新版本。x86_64 版本支持 CPU 和 NVIDIA，ARM64 版本支持 CPU 挖矿。

<img src="/assets/blog/setup-download.webp" alt="列出 Linux 与 Linux ARM64 压缩包的官方下载表" loading="lazy" />

## 第 2 步：解压并启动

打开终端。以下命令假设压缩包位于 Downloads 文件夹；如果位置不同，请使用实际路径。在 ARM64 上，将 `seine-linux-x86_64.tar.gz` 替换为 `seine-linux-aarch64.tar.gz`。命令会将 seine 解压到主文件夹中并启动：

```sh
mkdir -p "$HOME/seine"
tar -xzf "$HOME/Downloads/seine-linux-x86_64.tar.gz" -C "$HOME/seine"
cd "$HOME/seine"
./seine
```

## 第 3 步：输入钱包地址

粘贴你的公开 Blocknet 收款地址或已注册的 `@name`，然后按 Enter 接受 `stratum+tcp://bntpool.com:3333`。[钱包指南](/zh-hans/blog/blocknet-wallet-for-mining/)说明了在哪里找到地址。seine 不需要恢复短语或支出密钥，并会自动分配矿池矿机名称。

## 第 4 步：查看已接受的份额

在[控制台](/zh-hans/blog/seine-dashboard-explained/)中查看算力和不断增加的 **Accepted** 计数。份额被接受表示矿池收到了你的工作，并不表示已经付款。按 `q` 或 `Ctrl+C` 停止。

## 在 Linux 上用 GPU 挖矿需要什么？

NVIDIA 显卡只需要 NVIDIA 驱动。AMD 显卡需要 amdgpu 驱动和 ROCm HIP 运行时，详见 [AMD 指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md)。seine 会自动找到你的显卡，并在 x86_64 版本中与 CPU 一起用它们挖矿。[NVIDIA 指南](/zh-hans/blog/mine-blocknet-nvidia-gpu/)介绍了如何选择显卡和检查 GPU 份额。

## 如何解决 Linux 启动错误？

根据第一条错误消息选择下一项检查：

| 消息或现象 | 检查内容 |
|---|---|
| `Exec format error` | 架构不匹配：将 `uname -m` 与压缩包文件名进行比较。 |
| `GLIBC_... not found` | 二进制程序需要更新的 glibc。请使用兼容系统或从源码构建；系统 C 库应继续由发行版管理。 |
| `Permission denied` | 检查用户执行权限，并使用允许执行程序的文件系统上的文件夹。 |

份额开始被接受后，可以参阅[大页内存指南](/zh-hans/blog/huge-pages-blocknet-mining/)进行可选的 Linux 内存页设置。[服务器指南](/zh-hans/blog/mine-blocknet-on-servers/)介绍无头运行与 NUMA 分配。这两项准备都不是完成本首次运行教程的必要条件；请分别进行每项更改，以便判断机器上具体发生了什么变化。
