## 可以在 Mac 上挖 Blocknet 吗？

<Answer>
下载并解压 seine，输入 Blocknet 地址，然后在 bntpool.com 确认份额已被接受。先使用自动设置；性能调优建议放在设置步骤之后。
</Answer>

## 第 1 步：下载适合的版本

在 Apple 菜单 → 关于本机中查看芯片或处理器。在[下载区](/zh-hans/#download)为 Apple Silicon 选择 `seine-macos-aarch64.tar.gz`，为 Intel 选择 `seine-macos-x86_64.tar.gz`。

## 第 2 步：解压并启动

打开终端。以下命令假设压缩包位于 Downloads 文件夹；如果位置不同，请使用实际路径。在 Intel Mac 上，将 `seine-macos-aarch64.tar.gz` 替换为 `seine-macos-x86_64.tar.gz`。命令会将 seine 解压到主文件夹中并启动：

```sh
mkdir -p "$HOME/seine"
tar -xzf "$HOME/Downloads/seine-macos-aarch64.tar.gz" -C "$HOME/seine"
cd "$HOME/seine"
./seine
```

## 第 3 步：输入钱包地址

粘贴你的公开 Blocknet 收款地址或已注册的 `@name`，然后按 Enter 接受 `stratum+tcp://bntpool.com:3333`。[钱包指南](/zh-hans/blog/blocknet-wallet-for-mining/)说明了在哪里找到地址。seine 不需要恢复短语或支出密钥，并会自动分配矿池矿机名称。

在[控制台](/zh-hans/blog/seine-dashboard-explained/)中查看算力和不断增加的 **Accepted** 计数。份额被接受表示矿池收到了你的工作，并不表示已经付款。按 `q` 或 `Ctrl+C` 停止。

## 如果 macOS 阻止首次启动

macOS 版本采用临时（ad-hoc）签名。如果 macOS 阻止了首次启动，请打开“系统设置”，进入“隐私与安全性”，允许 `seine` 运行。你也可以在终端中清除下载标记，然后再次运行：

```sh
xattr -d com.apple.quarantine ./seine
./seine
```

## 为什么 Apple 芯片 Mac 挖 Blocknet 表现出色？

Blocknet 的工作量证明是 [Argon2id](/zh-hans/blog/argon2id-proof-of-work-explained/)，每次哈希使用 2 GiB 内存。每次哈希都会填满一块 2 GiB 的内存，并在过程中回读其中较早的部分，所以挖矿线程的速度主要取决于芯片与内存之间传输数据的速度。这就是 seine 每个线程都需要约 2 GB 独立内存的原因。

Apple 芯片围绕统一内存构建，[Apple 的描述](https://www.apple.com/newsroom/2020/11/apple-unleashes-m1/)是把高带宽、低延迟的内存整合到单一的内存池中。这为每个挖矿线程提供了充足的带宽，而这正是内存密集型哈希所需要的。结果就是一台笔记本电脑挖 Blocknet 的速度可以与服务器处理器处于同一水平。

## M4 Max 挖 Blocknet 有多快？

<Answer>
一台搭载 M4 Max 芯片的 48 GB MacBook Pro 仅用 CPU、以 16 个线程挖 Blocknet，达到 30.94 H/s。以性能核心优先调度运行 14 个线程时（这是 seine 在这台机器上默认运行的均衡设置），它达到 29.26 H/s，并为其他应用留出了更多内存。
</Answer>

这些结果来自 seine 于 2026-07-10 在一台 48 GB M4 Max（12 个性能核心和 4 个能效核心）上进行的验证测试：

| 设置 | 线程数 | 算力 |
|---|---|---|
| 最大吞吐量 | 16，`auto` 调度 | 30.94 H/s |
| 均衡（seine 在这台 Mac 上的默认上限） | 14，`pcore-only` 调度 | 29.26 H/s |

## 你的 Mac 能运行多少个线程？

每个线程都需要独立的 2 GiB 内存，所以内存决定了上限。seine 在确定线程数时还会保留 Mac 内存的 5% (默认最多 1 GiB) 作为余量。由此得出以下上限：

| Mac 内存 | 内存可容纳的线程数 |
|---|---|
| 16 GB | 最多 7 个 |
| 24 GB | 最多 11 个 |
| 32 GB | 最多 15 个 |
| 36 GB | 最多 17 个 |
| 48 GB | 最多 23 个 |
| 64 GB | 最多 31 个 |

有两点会让最终的线程数恰好适合你的 Mac：

- **空闲内存。** seine 在启动时计算实际空闲的内存，所以你打开的应用会让线程数略微减少。如果运行中内存变得紧张，seine 会暂停部分线程并释放它们占用的内存。
- **核心数。** 在 Mac 上，seine 默认使用全部性能核心加上一半的能效核心。在 12+4 核的 M4 Max 上，就是 14 个线程，即上表中的均衡设置。

这些都无需你自己计算。seine 会在启动时选好线程数，并在挖矿过程中持续测试相近的线程数。

## 为什么 seine 在 Mac 上只用 CPU 挖矿？

在 Apple 芯片上，CPU 和图形核心共用同一个统一内存池。Argon2id 取决于内存带宽，所以 CPU 和图形核心会争用同一份带宽。在 seine 对 M4 Max 的测试中，只用 CPU 挖矿得到的算力最高，因此 seine 会在每台 Apple 芯片 Mac 上自动选择这种方式。你无需设置任何参数，就能得到最快的配置。

## 如何让 Mac 发挥最大算力？

- **让 seine 自动调优。** 它用真实的挖矿任务比较不同的线程数和 CPU 计算内核，只有在确认有提升后才会切换，并记住结果供下次启动使用。
- **让 Mac 保持唤醒。** macOS 会让闲置的 Mac 进入睡眠，这会暂停挖矿。用系统自带的 `caffeinate` 命令启动 seine，就能在 seine 运行期间让 Mac 保持唤醒：

  ```sh
  caffeinate -i ./seine
  ```

- **在专用 Mac 上追求最大吞吐量。** 如果这台 Mac 只用来挖矿，在 M4 Max 上实测达到 30.94 H/s 的设置会使用全部 16 个核心，占用的内存也比默认的均衡设置更多：

  ```sh
  ./seine --backend cpu --threads 16 --cpu-affinity auto
  ```

所有选项见[配置指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/configuration.md)。[挖矿主指南](/zh-hans/blog/how-to-mine-blocknet/)介绍了收益发放和其他平台。

<Note>
以上结果针对 Blocknet 当前的 Argon2id 工作量证明。根据 [blocknetcrypto.com](https://blocknetcrypto.com/#faraday)，Blocknet 计划在 2027-02-16 前后进行名为 Faraday 的网络升级，届时工作量证明算法预计会改变。seine 会在启动时以及每 12 小时检查一次新版本，请保持它为最新版本。
</Note>
