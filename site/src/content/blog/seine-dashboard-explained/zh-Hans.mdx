启动 seine 后，它会立即打开一个实时仪表盘：你的哈希速度、矿池接受了多少份额、应得多少收益、调优进展如何，以及它所做操作的日志。本文逐个面板介绍 seine v0.3.1，说明每个标签的含义及其数字的来源，并介绍挖矿时可以使用的按键。

这张图是用 seine v0.3.1 自身的仪表盘代码，以 120 × 26 字符和演示数值渲染而成：一台 Ryzen 9 9950X 以实测的 16.63 H/s、21 个线程在 bntpool.com 上运行了两小时。地址经过缩写，是虚构的。本文其余部分都以这张图为参照。

## seine 的仪表盘显示什么？

<Answer>
seine 的仪表盘显示你的实时算力和平均算力、已完成的哈希数、区块链高度和全网算力、矿工状态、份额难度以及被拒和被接受的份额、每个设备的算力、矿池、线程数和调优状态、你的 bntpool.com 余额，以及可以向回滚动查看的日志。它大约每秒刷新一次。
</Answer>

从上到下依次是标题栏、一排三个统计面板（`HASHRATE`、`NETWORK`、`MINING`）、`DEVICES`、`CONFIG`、`POOL BALANCE` 和 `LOG`。在较宽的终端中，`CONFIG` 和余额面板会左右并排。

仪表盘在开始挖矿之前就会打开。首次运行时，seine 会在仪表盘中询问你的收款地址和矿池，然后在屏幕上显示硬件检查和启动进度，让你可以跟进每一步。

## 标题栏：版本、波浪和更新

标题栏的标题显示 seine 版本，这里是 `seine v0.3.1`。有新版本发布时，它会显示 `update vX.Y.Z available`，然后开始自动安装倒计时：`updating to vX.Y.Z in 42s`，旁边显示 `u now  s skip`。按 `u` 立即安装，按 `s` 跳过该版本。倒计时期间挖矿不会中断，之后的过程见[更新指南](/zh-hans/blog/update-seine-miner/)。

标题下方有两行波浪，每秒移动一步。每当矿池接受你的一个份额，或你的矿机找到一个区块，就会有一个金色菱形出现在上面一行的最右侧，并每秒向左移动一列。在宽约 120 列的终端中，你能看到的菱形就是最近两分钟左右被接受的工作。`uptime` 位于下面一行的末尾。

## seine 如何测量算力？

`HASHRATE` 面板有三行：

- **Current** 是最近五秒滚动窗口内的算力。这里的一个哈希是一次完整的 2 GiB Argon2id 计算，所以 H/s 统计的是每秒完成的哈希数。NVIDIA 显卡是成批完成工作的，所以它们的当前算力使用 30 秒窗口，读数更稳定。
- **Average** 是本次会话的全部哈希除以挖矿时间。等待的时间（例如等待节点同步，或地址无效之后）不计入。
- **Total** 是自启动 seine 以来完成的哈希总数。

图中 Current 为 16.63 H/s，Average 为 16.41 H/s。Average 起步较低，是因为它包含最初几分钟：这段时间里每个线程还在完成第一个哈希，调优也还在选择线程数。seine 运行得越久，两者越接近。

## 网络、状态和份额

`NETWORK` 面板显示你正在挖的区块链 `Height`（高度）和 `Global` 全网算力；在矿池模式下，seine 从 bntpool.com 的公开统计中读取全网算力。

`State` 告诉你矿工程序正在做什么。绿色的 `working` 是你希望看到的状态。在矿池模式下，启动和重新连接时还会看到以下状态：

| State | 含义 |
|---|---|
| `pool-connecting` | 正在建立 Stratum 连接 |
| `pool-connected` | 已连接，正在登录 |
| `pool-authenticated` | 登录已接受，等待第一个任务 |
| `working` | 正在计算当前任务的哈希 |
| `pool-disconnected` | 连接已断开；seine 会自动重新连接 |
| `pool-login-rejected` | 矿池拒绝了登录；日志会给出原因 |

对接自己节点单独挖矿时，还会出现 `daemon-syncing` 和 `stale-tip` 等状态。seine 在等待某件事时，Current 会降为零，因此它绝不会显示并未产生的算力。

`MINING` 面板统计本次会话的份额：

- **Difficulty：** 矿池为这台矿机设置的份额难度。
- **Rejected：** 矿池没有接受的份额。
- **Accepted：** 矿池记入你名下的份额。

bntpool.com 会调整每台矿机的份额难度，使它无论算力高低都能稳定地发送份额，因此越快的矿机难度越高。你的支付取决于被接受的份额。在 daemon 模式下，这个面板改为显示 `Submitted`、`Stale` 和 `Accepted`，统计发送到你自己节点的解。

## 设备、配置和矿池余额

`DEVICES` 列出每个挖矿后端及其当前算力和平均算力：CPU 为 `cpu#1`，每块 GPU 依次为 `nvidia#1`、`amd#1` 等。GPU 会在 CPU 已经开始挖矿时在后台启动，仍在启动的显卡会显示进度，直到上线。

`CONFIG` 显示本次运行的设置：

- **Pool** 是矿池地址，默认为 `bntpool.com:3333`；在 daemon 模式下显示 `Daemon` 和节点的 API 地址。
- **Threads** 是 CPU 挖矿线程数。按键可用时，旁边会显示 `[+] [-]`。**Worker** 是这台机器登录矿池时使用的矿机名称。
- **Tuning** 显示 CPU 自动调优：正在比较什么、还剩多少时间，完成后显示 `done`。[CPU 调优指南](/zh-hans/blog/seine-automatic-cpu-tuning/)解释了每种状态。

要让矿机在矿池上显示一个易于识别的名称，在启动时传入：

```sh
./seine --pool-worker rig-01
```

`POOL BALANCE` 每隔几秒从 bntpool.com 读取你的余额。`Pending` 是你已经赚到但尚未支付的金额，包括仍在成熟中的区块的预估收益；`Paid` 是矿池已发送到你地址的金额；右侧的 `Miner` 是你的地址，缩写为前六个和后六个字符。在地址前加上 `solo:` 在矿池单独挖矿时，这个标签显示为 `Solo`。`Min payout` 显示矿池的最低支付额，在 bntpool.com 上为 1 BNT。在 daemon 模式下这个面板变为 `WALLET`，显示节点钱包的 `Pending` 和 `Unlocked` 余额。

## 阅读日志

`LOG` 列出 seine 正在做的事，最新的在最下面，每一行都有标签和发生在多久之前。重复的行会合并为一行并附上次数，例如 `share accepted ×104`，所以即使长时间运行，日志也易于阅读。在矿池上最常见的标签有：

- `CONN`：矿池连接，例如 `connected to pool`
- `SHARE`：`share accepted`，或附带原因的拒绝
- `CPU`：调优结果，例如 `tuned to 21 threads`
- `BACKEND`：设备启动，例如 `cpu: starting 21 threads (~42.0 GiB RAM)`

日志默认显示你需要的内容。加上 `--verbose` 可以查看内部设置以及每个新任务等常规活动。

## 仪表盘中可以用哪些按键？

<Answer>
Tuning 行显示 done 后，按 + 或 = 增加一个 CPU 线程，按 - 减少一个。用方向键、PgUp、PgDn 和 Home 向回滚动日志，按 End 重新跟随新行。更新倒计时期间，按 u 立即安装，按 s 跳过该版本。按 q 或 Ctrl+C 退出。
</Answer>

线程数的更改会立即作用于正在运行的 CPU 线程，GPU 和矿池连接继续运行。调优仍在选择线程数时，按键会等待，仪表盘会显示调优还剩多少时间。按键调整只对本次运行有效；下次启动会再次使用你保存的调优结果。要从一开始就固定线程数，使用 `--threads`。

向回滚动时，日志标题会显示 `LOG  paused, End to follow`，画面保持不动，直到你按 `End`。

## 小终端和普通输出

在宽度不足 80 列的终端中，三个统计面板会纵向堆叠。在较矮的窗口中，seine 会切换到紧凑视图，在日志上方保留 Threads、State、Current 和 Average。默认的 `--ui auto` 只在交互式终端中显示仪表盘；`--ui plain` 为服务器、日志文件和进程管理器提供普通的滚动日志。
