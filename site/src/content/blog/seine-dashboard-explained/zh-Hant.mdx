啟動 seine 後，它會立即開啟一個即時儀表板：你的雜湊速度、礦池接受了多少份額、應得多少收益、調校進展如何，以及它所做操作的日誌。本文逐一介紹 seine v0.3.1 的面板，說明每個標籤的含義及其數字的來源，並介紹挖礦時可以使用的按鍵。

這張圖是用 seine v0.3.1 本身的儀表板程式碼，以 120 × 26 字元與示範數值繪製而成：一台 Ryzen 9 9950X 以實測的 16.63 H/s、21 個執行緒在 bntpool.com 上執行了兩小時。地址經過縮寫，是虛構的。本文其餘部分都以這張圖為參照。

## seine 的儀表板顯示什麼？

<Answer>
seine 的儀表板顯示你的即時算力與平均算力、已完成的雜湊數、區塊鏈高度與全網算力、礦工狀態、份額難度以及被拒與被接受的份額、每個裝置的算力、礦池、執行緒數與調校狀態、你的 bntpool.com 餘額，以及可以往回捲動查看的日誌。它大約每秒更新一次。
</Answer>

由上到下依序是標題列、一排三個統計面板（`HASHRATE`、`NETWORK`、`MINING`）、`DEVICES`、`CONFIG`、`POOL BALANCE` 與 `LOG`。在較寬的終端機中，`CONFIG` 與餘額面板會左右並排。

儀表板在開始挖礦之前就會開啟。首次執行時，seine 會在儀表板中詢問你的收款地址與礦池，然後在畫面上顯示硬體檢查與啟動進度，讓你可以跟進每一步。

## 標題列：版本、波浪與更新

標題列的標題顯示 seine 版本，這裡是 `seine v0.3.1`。有新版本發布時，它會顯示 `update vX.Y.Z available`，然後開始自動安裝倒數：`updating to vX.Y.Z in 42s`，旁邊顯示 `u now  s skip`。按 `u` 立即安裝，按 `s` 略過該版本。倒數期間挖礦不會中斷，之後的過程見[更新指南](/zh-hant/blog/update-seine-miner/)。

標題下方有兩行波浪，每秒移動一步。每當礦池接受你的一個份額，或你的礦機找到一個區塊，就會有一個金色菱形出現在上面一行的最右側，並每秒向左移動一欄。在寬約 120 欄的終端機中，你能看到的菱形就是最近兩分鐘左右被接受的工作。`uptime` 位於下面一行的末尾。

## seine 如何測量算力？

`HASHRATE` 面板有三行：

- **Current** 是最近五秒滾動視窗內的算力。這裡的一個雜湊是一次完整的 2 GiB Argon2id 計算，所以 H/s 統計的是每秒完成的雜湊數。NVIDIA 顯示卡是成批完成工作的，所以它們的目前算力使用 30 秒視窗，讀數更穩定。
- **Average** 是本次工作階段的全部雜湊除以挖礦時間。等待的時間（例如等待節點同步，或地址無效之後）不計入。
- **Total** 是自啟動 seine 以來完成的雜湊總數。

圖中 Current 為 16.63 H/s，Average 為 16.41 H/s。Average 起步較低，是因為它包含最初幾分鐘：這段時間裡每個執行緒還在完成第一個雜湊，調校也還在選擇執行緒數。seine 執行得越久，兩者越接近。

## 網路、狀態與份額

`NETWORK` 面板顯示你正在挖的區塊鏈 `Height`（高度）與 `Global` 全網算力；在礦池模式下，seine 從 bntpool.com 的公開統計中讀取全網算力。

`State` 告訴你礦工程式正在做什麼。綠色的 `working` 是你希望看到的狀態。在礦池模式下，啟動與重新連線時還會看到以下狀態：

| State | 含義 |
|---|---|
| `pool-connecting` | 正在建立 Stratum 連線 |
| `pool-connected` | 已連線，正在登入 |
| `pool-authenticated` | 登入已接受，等待第一個工作 |
| `working` | 正在計算目前工作的雜湊 |
| `pool-disconnected` | 連線已中斷；seine 會自動重新連線 |
| `pool-login-rejected` | 礦池拒絕了登入；日誌會說明原因 |

連接自己的節點單獨挖礦時，還會出現 `daemon-syncing` 與 `stale-tip` 等狀態。seine 在等待某件事時，Current 會降為零，因此它絕不會顯示並未產生的算力。

`MINING` 面板統計本次工作階段的份額：

- **Difficulty：** 礦池為這台礦機設定的份額難度。
- **Rejected：** 礦池沒有接受的份額。
- **Accepted：** 礦池記入你名下的份額。

bntpool.com 會調整每台礦機的份額難度，使它無論算力高低都能穩定地傳送份額，因此越快的礦機難度越高。你的支付取決於被接受的份額。在 daemon 模式下，這個面板改為顯示 `Submitted`、`Stale` 與 `Accepted`，統計傳送到你自己節點的解。

## 裝置、設定與礦池餘額

`DEVICES` 列出每個挖礦後端及其目前算力與平均算力：CPU 為 `cpu#1`，每張 GPU 依序為 `nvidia#1`、`amd#1` 等。GPU 會在 CPU 已經開始挖礦時於背景啟動，仍在啟動的顯示卡會顯示進度，直到上線。

`CONFIG` 顯示本次執行的設定：

- **Pool** 是礦池位址，預設為 `bntpool.com:3333`；在 daemon 模式下顯示 `Daemon` 與節點的 API 位址。
- **Threads** 是 CPU 挖礦執行緒數。按鍵可用時，旁邊會顯示 `[+] [-]`。**Worker** 是這台機器登入礦池時使用的礦機名稱。
- **Tuning** 顯示 CPU 自動調校：正在比較什麼、還剩多少時間，完成後顯示 `done`。[CPU 調校指南](/zh-hant/blog/seine-automatic-cpu-tuning/)說明了每種狀態。

要讓礦機在礦池上顯示一個容易辨識的名稱，在啟動時傳入：

```sh
./seine --pool-worker rig-01
```

`POOL BALANCE` 每隔幾秒從 bntpool.com 讀取你的餘額。`Pending` 是你已經賺到但尚未支付的金額，包括仍在成熟中的區塊的預估收益；`Paid` 是礦池已傳送到你地址的金額；右側的 `Miner` 是你的地址，縮寫為前六個與後六個字元。在地址前加上 `solo:` 在礦池單獨挖礦時，這個標籤顯示為 `Solo`。`Min payout` 顯示礦池的最低支付額，在 bntpool.com 上為 1 BNT。在 daemon 模式下這個面板變為 `WALLET`，顯示節點錢包的 `Pending` 與 `Unlocked` 餘額。

## 閱讀日誌

`LOG` 列出 seine 正在做的事，最新的在最下面，每一行都有標籤與發生在多久之前。重複的行會合併為一行並附上次數，例如 `share accepted ×104`，所以即使長時間執行，日誌也容易閱讀。在礦池上最常見的標籤有：

- `CONN`：礦池連線，例如 `connected to pool`
- `SHARE`：`share accepted`，或附帶原因的拒絕
- `CPU`：調校結果，例如 `tuned to 21 threads`
- `BACKEND`：裝置啟動，例如 `cpu: starting 21 threads (~42.0 GiB RAM)`

日誌預設顯示你需要的內容。加上 `--verbose` 可以查看內部設定以及每個新工作等例行活動。

## 儀表板中可以用哪些按鍵？

<Answer>
Tuning 列顯示 done 後，按 + 或 = 增加一個 CPU 執行緒，按 - 減少一個。用方向鍵、PgUp、PgDn 與 Home 往回捲動日誌，按 End 重新跟隨新行。更新倒數期間，按 u 立即安裝，按 s 略過該版本。按 q 或 Ctrl+C 結束。
</Answer>

執行緒數的變更會立即作用於正在執行的 CPU 執行緒，GPU 與礦池連線繼續運作。調校仍在選擇執行緒數時，按鍵會等待，儀表板會顯示調校還剩多少時間。按鍵調整只對本次執行有效；下次啟動會再次使用你儲存的調校結果。要從一開始就固定執行緒數，使用 `--threads`。

往回捲動時，日誌標題會顯示 `LOG  paused, End to follow`，畫面保持不動，直到你按 `End`。

## 小型終端機與一般輸出

在寬度不足 80 欄的終端機中，三個統計面板會縱向堆疊。在較矮的視窗中，seine 會切換到精簡檢視，在日誌上方保留 Threads、State、Current 與 Average。預設的 `--ui auto` 只在互動式終端機中顯示儀表板；`--ui plain` 為伺服器、日誌檔案與程序管理器提供一般的捲動日誌。

如果你還沒有設定 seine，[Blocknet 挖礦指南](/zh-hant/blog/how-to-mine-blocknet/)介紹了從下載到第一個被接受份額的全過程。
