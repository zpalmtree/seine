ให้ seine อยู่ในรุ่นล่าสุดโดยรักษาการเชื่อมต่อพูลและตัวเลือกเริ่มต้นที่ใช้งานได้บนเครื่องของคุณ คู่มือนี้อ้างอิงรุ่นสาธารณะ v0.3.1: การอัปเดตอัตโนมัติทำงานอย่างไร สิ่งที่ต้องทำครั้งเดียวเมื่อมาจากรุ่นเก่า และวิธีอัปเดตเอง หากติดตั้งครั้งแรกให้ใช้คู่มือ [Windows](/th/blog/mine-blocknet-on-windows/), [Linux](/th/blog/mine-blocknet-on-linux/) หรือ [Mac](/th/blog/mine-blocknet-on-mac/)

## อัปเดต seine อย่างไร?

<Answer>
ปล่อยให้ seine ทำงานต่อไป โปรแกรมตรวจรุ่นใหม่เมื่อเริ่มและทุก 12 ชั่วโมง นับถอยหลัง 60 วินาทีที่ส่วนหัวแดชบอร์ดขณะยังขุดอยู่ แล้วติดตั้งรุ่นที่ลงนามและเริ่มใหม่ด้วยอาร์กิวเมนต์และการตั้งค่าเดิม หากต้องการอัปเดตเอง ให้หยุด seine เปลี่ยนไฟล์จากแพ็กเกจทางการ แล้วเริ่มด้วยวิธีเดิม
</Answer>

## การอัปเดตอัตโนมัติทำงานอย่างไร?

เมื่อมีรุ่นใหม่กว่า ส่วนหัวจะแสดง `update vX.Y.Z available` บันทึกจะลิงก์ไปยังรุ่นนั้น แล้วส่วนหัวจะนับถอยหลัง: `updating to vX.Y.Z in 42s` การขุดดำเนินต่อระหว่างนับถอยหลัง กด `u` เพื่ออัปเดตทันที หรือ `s` เพื่อข้ามรุ่นนั้น seine จำการข้ามไว้ในไดเรกทอรีข้อมูลและเสนอรุ่นถัดไปตามปกติ

หลังนับถอยหลัง seine ตรวจลายเซ็นของรุ่น ตรวจว่าไฟล์โปรแกรมใหม่เริ่มทำงานได้ แล้วจึงแทนที่ไฟล์เก่า โปรแกรมหยุดขุดอย่างเรียบร้อยและเริ่มใหม่ด้วยอาร์กิวเมนต์เดิม และแดชบอร์ดใหม่จะบันทึก `updated to seine vX.Y.Z` รุ่นใหม่เริ่มจากผลการปรับแต่งที่บันทึกไว้และทดสอบเฉพาะสิ่งที่รุ่นนั้นเปลี่ยน จึงกลับสู่ความเร็วเต็มได้เร็ว

หากพูลส่งงานที่ต้องใช้รุ่นใหม่กว่า เช่นในการอัปเกรดเครือข่าย seine จะหยุดขุดชั่วคราวและติดตั้งอัปเดตทันที แม้เป็นรุ่นที่คุณข้ามไว้ ใช้ `--no-auto-update` เพื่อให้แสดงเพียงการแจ้งเตือน หรือ `--disable-update-check` เพื่อปิดการตรวจ รุ่นที่คุณคอมไพล์เองจะแสดงการแจ้งเตือนและให้คุณอัปเดตเอง

## ต้องทำอะไรครั้งเดียวเมื่อมาจากรุ่นเก่า?

เครื่องขุดส่วนใหญ่ไม่ต้องทำอะไร การตั้งค่าบางแบบต้องทำหนึ่งขั้นตอนในการอัปเดตอัตโนมัติครั้งแรกเป็น v0.3.1:

- **Linux จาก v0.2.45:** v0.2.45 ติดตั้งรุ่นใหม่แล้วปิดตัว ให้เริ่ม seine อีกครั้ง การตั้งค่าที่เริ่ม seine ใหม่เอง เช่นบริการ systemd ไม่ต้องทำอะไร
- **Windows จาก v0.2.45 หรือ v0.3.0:** รุ่นเก่าจะเริ่มรุ่นใหม่แล้วปิดตัว หากสคริปต์หรือบริการเริ่ม seine ใหม่เมื่อปิดตัวด้วย ให้หยุดสคริปต์หรือบริการนั้นหนึ่งครั้งหลังอัปเดต เพื่อให้มี seine ทำงานอยู่เพียงตัวเดียว
- **HiveOS และ mmpOS จากแพ็กเกจ v0.3.0:** เปลี่ยน flight sheet หรือ profile เป็นแพ็กเกจ v0.3.1 จาก[หน้ารุ่นเผยแพร่](https://github.com/zpalmtree/seine/releases) ตั้งแต่ v0.3.1 เป็นต้นไป แพ็กเกจจะอัปเกรดผ่านระบบปฏิบัติการสำหรับขุด: เปลี่ยนรุ่นใน URL ตามที่[คู่มือ HiveOS และ mmpOS](/th/blog/mine-blocknet-hiveos-mmpos/)แสดง

## ตรวจสอบเวอร์ชันปัจจุบันอย่างไร?

ส่วนหัวแดชบอร์ดแสดงรุ่นที่คุณใช้อยู่ คุณยังใช้คำสั่งเวอร์ชันกับไฟล์ที่ใช้งานจริงได้ สำเนาเก่าอาจต่างจากโปรแกรมที่ทางลัดหรือบริการเรียกใช้ จดพาธ ไดเรกทอรีทำงาน และอาร์กิวเมนต์ไว้ด้วยกันเพื่อทำซ้ำได้ ใน Windows เปิด PowerShell ที่โฟลเดอร์โปรแกรมปัจจุบัน:

```powershell
.\seine.exe --version
```

ใน Linux หรือ macOS เปิดเทอร์มินัลในโฟลเดอร์นั้น:

```sh
./seine --version
```

เปรียบเทียบกับ[รุ่นทางการ](https://github.com/zpalmtree/seine/releases) และอ่านบันทึกรุ่นสำหรับการเปลี่ยนแปลงที่มีผลต่อแพลตฟอร์ม รันไทม์ หรือตัวเลือกเริ่มต้นของคุณ

## ต้องเก็บการตั้งค่าใด?

seine อ่าน `./seine-data/seine.config.json` ตามค่าเริ่มต้น `./` หมายถึงไดเรกทอรีทำงาน การย้ายโปรแกรมแล้วเปิดจากที่อื่นอาจเปลี่ยนตำแหน่งค้นหา หากใช้ `--data-dir` ให้ชี้ที่เดิม พาธแบบเต็มระบุตำแหน่งชัดเจนเมื่อทางลัด สคริปต์ หรือบริการเลือกไดเรกทอรีทำงาน

การตั้งค่าเก็บโหมดขุด ที่อยู่รับเงิน URL พูล และชื่อเครื่อง เก็บไดเรกทอรีข้อมูลทั้งหมดรวมไฟล์ปรับแต่ง เก็บคำสั่ง สคริปต์ หรือนิยามบริการด้วย เพราะ `--backend` และ `--threads` แยกจากช่องข้อมูลเชื่อมต่อ การเก็บทั้งสองส่วนรักษารูปแบบที่ต้องการหลังเริ่มใหม่

## อัปเดต seine เองอย่างไร?

หากคุณใช้ `--no-auto-update` หรืออยากเลือกเวลาเอง ให้อัปเดตเอง ใช้[หน้าดาวน์โหลด](/th/#download)หรือรุ่นทางการ เลือกไฟล์ตามระบบและสถาปัตยกรรม CPU ดาวน์โหลด `SHA256SUMS.txt` ที่แยกไว้ของรุ่นเดียวกัน เปรียบเทียบ checksum ก่อนแตกไฟล์ในโฟลเดอร์อื่น [คู่มือตรวจสอบ](/th/blog/antivirus-flags-crypto-miner/)อธิบายขั้นตอน Windows และคำเตือนการดาวน์โหลด

เก็บไฟล์ในแพ็กเกจไว้ด้วยกัน รุ่น Windows มีไลบรารี NVIDIA ข้าง `seine.exe` การคัดลอกเฉพาะโปรแกรมอาจปะปนเวอร์ชัน [คู่มือ NVIDIA](/th/blog/mine-blocknet-nvidia-gpu/)อธิบายรันไทม์ [เอกสารการตั้งค่า v0.3.1](https://github.com/zpalmtree/seine/blob/v0.3.1/docs/guides/configuration.md)ระบุการบันทึกค่า การอัปเดตอัตโนมัติ และพฤติกรรมเริ่มต้นที่ใช้ในบทความนี้

## หยุด สำรอง และเปลี่ยนไฟล์

ออกด้วย `q` หรือ `Ctrl+C` แล้วรอจนโปรเซสจบ ถ้าเป็นบริการให้ใช้ตัวจัดการและคำนึงถึงการเริ่มอัตโนมัติก่อนเปลี่ยนไฟล์ เมื่อหยุดแล้วสำรองแอปและข้อมูลไว้ในเครื่อง แยกสำเนาจากโฟลเดอร์ที่แตกใหม่เพื่อให้ระบุสองเวอร์ชันได้

วางไฟล์ใหม่ในตำแหน่งติดตั้งพร้อมเก็บข้อมูลเดิม หากแยกโฟลเดอร์ตามเวอร์ชัน ให้เปลี่ยนพาธโปรแกรมในทางลัดหรือบริการและรักษาไดเรกทอรีทำงานกับพาธข้อมูลอย่างชัดเจน เปิดหนึ่งอินสแตนซ์ด้วยตัวเลือกเดิม ถ้ามีหลายเครื่องให้ตรวจสอบหนึ่งเครื่องให้ครบก่อน

## ยืนยันว่าอัปเดตสำเร็จอย่างไร?

ตรวจสอบเวอร์ชันของไฟล์ที่ติดตั้งอีกครั้งเทียบกับที่ดาวน์โหลด เริ่มโปรแกรมแล้วเช็กปลายทางรับเงิน พูล ชื่อเครื่อง และ backend CPU/GPU ที่ต้องการ ข้อมูลปรับแต่งที่เข้ากันได้อาจนำกลับมาใช้ รอการปรับแต่งเริ่มต้นจบก่อนประเมิน hashrate [คู่มือแดชบอร์ด](/th/blog/seine-dashboard-explained/)อธิบายแต่ละส่วน

ดูแชร์ที่ยอมรับแล้วเปิด [My Stats](https://bntpool.com/stats) ของที่อยู่เดียวกัน ค่าประมาณพูลต้องมีแชร์และเวลาเพื่อให้เสถียร ความต่างทันทีของ hashrate ยังไม่พอระบุปัญหาอัปเดต โปรเซสใหม่เริ่มเซสชันในเครื่องใหม่ด้วย เปรียบเทียบที่อยู่ เครื่อง และกิจกรรมก่อนเทียบตัวนับระยะสั้น

## ถ้าคำถามตั้งค่าเริ่มต้นกลับมา?

ตรวจสอบไดเรกทอรีทำงานและ `--data-dir` ก่อน โฟลเดอร์ใหม่มักไม่มีการตั้งค่าในพาธสัมพัทธ์เริ่มต้น หยุดอินสแตนซ์และชี้ข้อมูลเดิม หากข้อผิดพลาดระบุไฟล์ตั้งค่า ให้เก็บไฟล์และข้อความตรงตัวไว้ตรวจสอบ อย่าใส่วลีกู้คืน คีย์ส่วนตัว หรือโทเคน API ควบคุมในภาพหรือรายงานสาธารณะ

ถ้าเริ่มไม่ได้ให้บันทึกเวอร์ชัน ระบบ พาธ และข้อผิดพลาดตรงตัว แล้วใช้คู่มือแพลตฟอร์ม สำเนาเก็บแอปเก่าและการตั้งค่าด้วยกัน ก่อนย้อนกลับให้ตรวจข้อกำหนดความเข้ากันได้ในบันทึกรุ่นใหม่ ใช้การตั้งค่าที่ทราบแล้วตรวจแชร์อีกครั้ง การเปลี่ยนโปรแกรมขุดไม่ต้องสร้างกระเป๋าใหม่
