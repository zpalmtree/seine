Το seine δουλεύει καλά και χωρίς ρυθμίσεις. Αυτός ο οδηγός καλύπτει τις αλλαγές που είναι πιο πιθανό να θελήσετε: απενεργοποίηση της εξόρυξης με CPU ή GPU, χρήση λιγότερων νημάτων, επιλογή κάρτας γραφικών και αλλαγή της διεύθυνσης ή του pool σας.

## Πώς αλλάζετε μια ρύθμιση του seine;

<Answer>
Κλείστε το seine, ανοίξτε ένα τερματικό στον φάκελό του και ξεκινήστε το ξανά με τη ρύθμιση προστιθέμενη στην εντολή, για παράδειγμα `./seine --threads 4`. Στα Windows χρησιμοποιήστε το PowerShell και `.\seine.exe --threads 4`. Το seine κρατά την αποθηκευμένη διεύθυνση και το pool σας, οπότε πληκτρολογείτε μόνο ό,τι θέλετε να αλλάξετε.
</Answer>

- **Windows:** ανοίξτε τον φάκελο του seine στην Εξερεύνηση αρχείων, πληκτρολογήστε `powershell` στη γραμμή διευθύνσεων και πατήστε Enter.
- **macOS και Linux:** ανοίξτε το Terminal και πηγαίνετε στον φάκελο του seine με `cd`.

Τα παραδείγματα παρακάτω χρησιμοποιούν `./seine`. Στα Windows πληκτρολογήστε αντί γι' αυτό `.\seine.exe`.

## Πώς απενεργοποιείτε την εξόρυξη με CPU ή GPU;

Από προεπιλογή, το seine εξορύσσει με τον επεξεργαστή και με κάθε υποστηριζόμενη κάρτα γραφικών. Η ρύθμιση `--backend` επιλέγει ποια θα χρησιμοποιηθούν:

| Τι θέλετε | Προσθέστε |
|---|---|
| Μόνο CPU, χωρίς GPU | `--backend cpu` |
| Μόνο GPU NVIDIA, χωρίς CPU | `--backend nvidia` |
| Μόνο GPU AMD, χωρίς CPU | `--backend amd` |
| GPU NVIDIA και AMD, χωρίς CPU | `--backend nvidia,amd` |

Για παράδειγμα, για να εξορύσσετε με κάρτα NVIDIA και να αφήσετε τον επεξεργαστή ελεύθερο:

```sh
./seine --backend nvidia
```

Ο πίνακας Devices στο [dashboard](/el/blog/seine-dashboard-explained/) δείχνει μια γραμμή για κάθε συσκευή που εξορύσσει.

## Πώς χρησιμοποιείτε λιγότερα νήματα CPU;

Προσθέστε `--threads` με τον αριθμό που θέλετε:

```sh
./seine --threads 4
```

Κάθε νήμα χρησιμοποιεί περίπου 2 GB RAM, άρα 4 νήματα χρησιμοποιούν περίπου 8 GB. Το seine μένει σε αυτόν τον αριθμό μέχρι να αφαιρέσετε τη ρύθμιση.

Για να βρείτε έναν καλό αριθμό, ξεκινήστε το seine κανονικά και πατήστε `-` στον πίνακα για να αφαιρέσετε ένα νήμα ή `+` για να προσθέσετε ένα. Η αλλαγή θέλει λίγο χρόνο και ο πίνακας δείχνει τον νέο αριθμό. Σταματήστε όταν ο υπολογιστής σας λειτουργεί σωστά και μετά χρησιμοποιήστε αυτόν τον αριθμό με το `--threads`, γιατί τα πλήκτρα ισχύουν μόνο μέχρι να κλείσετε το seine.

Για να διαλέξει το ίδιο το seine έναν ελαφρύτερο αριθμό νημάτων, χρησιμοποιήστε αυτό:

```sh
./seine --cpu-profile efficiency
```

Ο [οδηγός για επιτραπέζιο υπολογιστή](/el/blog/mine-while-using-pc/) έχει περισσότερα για την εξόρυξη ενώ χρησιμοποιείτε τον υπολογιστή σας.

## Πώς διαλέγετε μία κάρτα γραφικών;

Προσθέστε τον αριθμό της κάρτας. Η πρώτη κάρτα είναι η `0`:

```sh
./seine --backend cpu,nvidia --nvidia-devices 0
```

Αυτό εξορύσσει με τον επεξεργαστή και την πρώτη κάρτα NVIDIA. Χρησιμοποιήστε `--nvidia-devices 0,1` για δύο κάρτες και παραλείψτε το `cpu,` για να απενεργοποιήσετε τον επεξεργαστή. Οι κάρτες AMD δουλεύουν με τον ίδιο τρόπο:

```sh
./seine --backend cpu,amd --amd-devices 0
```

Για να αφήσετε μνήμη βίντεο ελεύθερη για άλλες εφαρμογές, χρησιμοποιήστε `--nvidia-max-lanes 2` ή `--amd-max-lanes 2`. Κάθε lane χρησιμοποιεί περίπου 2 GB μνήμης βίντεο. Τα ενσωματωμένα γραφικά Radeon μένουν απενεργοποιημένα, εκτός αν προσθέσετε εσείς το `--backend amd`.

## Πώς κρατάτε τις ρυθμίσεις σας σε κάθε εκκίνηση;

Το seine αποθηκεύει μόνο του τη διεύθυνση, το pool και το όνομα worker σας. Ρυθμίσεις όπως οι `--threads` και `--backend` ισχύουν μόνο για εκείνη την εκτέλεση, οπότε βάλτε τες σε ένα μικρό αρχείο εκκίνησης και ανοίγετε αυτό το αρχείο αντί για το seine.

Στα Windows ανοίξτε το Σημειωματάριο, πληκτρολογήστε αυτές τις γραμμές με τις δικές σας ρυθμίσεις και αποθηκεύστε το αρχείο στον φάκελο του seine ως `start-mining.bat`, με το **Αποθήκευση ως τύπου** ορισμένο σε **Όλα τα αρχεία**:

```bat
seine.exe --backend cpu --threads 4
pause
```

Κάντε διπλό κλικ στο `start-mining.bat` για να ξεκινήσει η εξόρυξη. Η γραμμή `pause` κρατά το παράθυρο ανοιχτό αν το seine σταματήσει, ώστε να διαβάσετε το τελευταίο του μήνυμα.

Σε macOS ή Linux αποθηκεύστε αυτές τις γραμμές στον φάκελο του seine ως `start-mining.sh`:

```sh
#!/bin/sh
cd "$(dirname "$0")"
./seine --backend cpu --threads 4
```

Εκτελέστε μία φορά `chmod +x start-mining.sh` και μετά ξεκινήστε την εξόρυξη με `./start-mining.sh`. Οι αυτόματες ενημερώσεις επανεκκινούν το seine με τις ίδιες ρυθμίσεις. Για να ξεκινά η εξόρυξη κάθε φορά που συνδέεστε στα Windows, ακολουθήστε τον [οδηγό αυτόματης εκκίνησης](/el/blog/start-miner-automatically-windows/).

## Πώς αλλάζετε τη διεύθυνση, το pool ή το όνομα worker;

Κλείστε το seine και ανοίξτε το `seine-data/seine.config.json` σε έναν επεξεργαστή κειμένου. Ο φάκελος βρίσκεται μέσα σε αυτόν από τον οποίο ξεκινάτε το seine. Αλλάξτε την τιμή που χρειάζεστε και αποθηκεύστε το αρχείο:

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

Αφήστε τις άλλες γραμμές όπως είναι. Κρατήστε τα εισαγωγικά και τα κόμματα και μην προσθέτετε στο αρχείο τη φράση ανάκτησης ή ιδιωτικά κλειδιά.

Για να χρησιμοποιήσετε διαφορετική τιμή για μία εκτέλεση, προσθέστε την στην εντολή. Το αποθηκευμένο αρχείο μένει ως έχει:

```sh
./seine --pool-worker desktop-02
```

Οι άλλες δύο ρυθμίσεις είναι οι `--address` και `--pool-url`. Ο [οδηγός αλλαγής διεύθυνσης](https://bntpool.com/blog/el/change-mining-wallet-address/) εξηγεί πώς το pool πιστώνει τη δουλειά σας αφού αλλάξετε διεύθυνση.

Για solo εξόρυξη στο bntpool.com, βάλτε `solo:` μπροστά από τη διεύθυνση, για παράδειγμα `"address": "solo:@yourname"` στο αρχείο ή `--address solo:YOUR_ADDRESS` στη γραμμή εντολών. Το pool σας πληρώνει τότε ολόκληρη την ανταμοιβή κάθε μπλοκ που βρίσκει το μηχάνημά σας. Η [solo εξόρυξη στο bntpool.com](https://bntpool.com/blog/el/solo-mine-blocknet-on-bntpool/) εξηγεί πώς πληρώνονται τα solo μπλοκ.

## Τι κάνετε αν μια ρύθμιση δεν δουλεύει;

| Τι βλέπετε | Τι να κάνετε |
|---|---|
| `--nvidia-devices requires selecting nvidia in --backend` | Προσθέστε το `nvidia` στο backend: `--backend cpu,nvidia`. Το ίδιο ισχύει για το `amd`. |
| `configured CPU lanes need` περισσότερη RAM | Χρησιμοποιήστε μικρότερο αριθμό στο `--threads`, περίπου ένα νήμα για κάθε 2 GB ελεύθερης RAM. |
| `all GPU backends failed to start` | Εγκαταστήστε το τρέχον πρόγραμμα οδήγησης για την κάρτα σας. Ο [οδηγός AMD](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md) αναφέρει τι χρειάζονται οι κάρτες AMD στο Linux. |
| Το seine ζητά ξανά τη διεύθυνσή σας | Ξεκινήστε το seine από τον ίδιο φάκελο με πριν ή ορίστε τον φάκελο με `--data-dir`. |
| Οι ρυθμίσεις σας γύρισαν σε αυτόματες | Ξεκινήστε το seine από το αρχείο εκκίνησης. Τα πλήκτρα `-` και `+` ισχύουν μόνο μέχρι να κλείσετε το seine. |

Η [αναφορά επιλογών](https://github.com/zpalmtree/seine/blob/master/docs/MINER_FLAGS.md) απαριθμεί κάθε ρύθμιση.
