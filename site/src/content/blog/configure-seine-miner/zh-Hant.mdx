seine 不需要任何設定就能良好運作。本指南介紹你最可能想做的變更：關閉 CPU 或 GPU 挖礦、使用較少的執行緒、選擇顯示卡，以及變更地址或礦池。

## 如何變更 seine 的設定？

<Answer>
關閉 seine，在它的資料夾中開啟終端機，然後在指令中加上設定並重新啟動，例如 `./seine --threads 4`。在 Windows 上，請使用 PowerShell 和 `.\seine.exe --threads 4`。seine 會保留你已儲存的地址和礦池，所以只需輸入想要變更的內容。
</Answer>

- **Windows：**在檔案總管中開啟 seine 資料夾，在網址列輸入 `powershell` 並按 Enter。
- **macOS 和 Linux：**開啟終端機，用 `cd` 進入 seine 資料夾。

下面的範例使用 `./seine`。在 Windows 上請改為輸入 `.\seine.exe`。

## 如何關閉 CPU 或 GPU 挖礦？

seine 預設使用 CPU 和每一張受支援的顯示卡挖礦。`--backend` 設定用來選擇使用哪些裝置：

| 你想要的效果 | 加上 |
|---|---|
| 只用 CPU，關閉 GPU | `--backend cpu` |
| 只用 NVIDIA GPU，關閉 CPU | `--backend nvidia` |
| 只用 AMD GPU，關閉 CPU | `--backend amd` |
| 使用 NVIDIA 和 AMD GPU，關閉 CPU | `--backend nvidia,amd` |

例如，要使用 NVIDIA 顯示卡挖礦並讓 CPU 閒置：

```sh
./seine --backend nvidia
```

[儀表板](/zh-hant/blog/seine-dashboard-explained/)中的 Devices 面板會為每個正在挖礦的裝置顯示一列。

## 如何使用較少的 CPU 執行緒？

加上 `--threads` 和你想要的數字：

```sh
./seine --threads 4
```

每個執行緒大約使用 2 GB 記憶體，所以 4 個執行緒大約使用 8 GB。在你移除該設定之前，seine 會一直使用這個數字。

要找到合適的數字，請正常啟動 seine，在儀表板中按 `-` 減少一個執行緒，或按 `+` 增加一個執行緒。變更需要片刻生效，儀表板會顯示新的執行緒數量。等電腦用起來合適時停下，然後把這個數字用於 `--threads`，因為這些按鍵只在你關閉 seine 之前有效。

如果想讓 seine 自己選擇較輕的執行緒數量，請改用：

```sh
./seine --cpu-profile efficiency
```

[桌上型電腦指南](/zh-hant/blog/mine-while-using-pc/)說明了更多在使用電腦的同時挖礦的方法。

## 如何只選擇一張顯示卡？

加上顯示卡的編號。第一張顯示卡是 `0`：

```sh
./seine --backend cpu,nvidia --nvidia-devices 0
```

這會使用 CPU 和第一張 NVIDIA 顯示卡挖礦。兩張顯示卡請用 `--nvidia-devices 0,1`，要關閉 CPU，就移除 `cpu,`。AMD 顯示卡的用法相同：

```sh
./seine --backend cpu,amd --amd-devices 0
```

要為其他應用程式留出顯示記憶體，請使用 `--nvidia-max-lanes 2` 或 `--amd-max-lanes 2`。每條通道（lane）大約使用 2 GB 顯示記憶體。除非你自己加上 `--backend amd`，否則內建的 Radeon 顯示卡保持關閉。

## 如何讓設定每次啟動都生效？

seine 會自動儲存你的地址、礦池和礦工名稱。`--threads` 和 `--backend` 這類設定只對當次執行有效，所以請把它們寫進一個小的啟動檔，並執行這個檔案，而不是直接執行 seine。

在 Windows 上，開啟記事本，輸入下面的幾行並換成你自己的設定，然後把檔案儲存到 seine 資料夾中，檔名為 `start-mining.bat`，並把**存檔類型**設為**所有檔案**：

```bat
seine.exe --backend cpu --threads 4
pause
```

按兩下 `start-mining.bat` 開始挖礦。`pause` 這一行會在 seine 停止後保持視窗開啟，方便你閱讀它的最後一則訊息。

在 macOS 或 Linux 上，把下面的幾行儲存到 seine 資料夾中，檔名為 `start-mining.sh`：

```sh
#!/bin/sh
cd "$(dirname "$0")"
./seine --backend cpu --threads 4
```

執行一次 `chmod +x start-mining.sh`，之後用 `./start-mining.sh` 開始挖礦。自動更新會用同樣的設定重新啟動 seine。要在每次登入 Windows 時開始挖礦，請參考[自動啟動指南](/zh-hant/blog/start-miner-automatically-windows/)。

## 如何變更地址、礦池或礦工名稱？

關閉 seine，用文字編輯器開啟 `seine-data/seine.config.json`。這個資料夾位於你啟動 seine 的資料夾之內。修改需要的值並儲存檔案：

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

其他行保持原樣。保留引號和逗號，並且不要把復原詞或私密金鑰寫進這個檔案。

如果只想在某一次執行中使用不同的值，請把它加到指令裡。已儲存的檔案不會改變：

```sh
./seine --pool-worker desktop-02
```

另外兩個設定是 `--address` 和 `--pool-url`。[變更地址指南](https://bntpool.com/blog/zh-hant/change-mining-wallet-address/)說明了變更地址後礦池如何計入你的工作量。

## 設定沒有生效怎麼辦？

| 你看到的內容 | 該怎麼做 |
|---|---|
| `--nvidia-devices requires selecting nvidia in --backend` | 在 backend 中加上 `nvidia`：`--backend cpu,nvidia`。`amd` 同理。 |
| `configured CPU lanes need` 更多記憶體 | 給 `--threads` 使用較小的數字，大約每 2 GB 可用記憶體對應一個執行緒。 |
| `all GPU backends failed to start` | 為你的顯示卡安裝最新驅動程式。[AMD 指南](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md)列出了 AMD 顯示卡在 Linux 上需要什麼。 |
| seine 再次詢問你的地址 | 從之前的同一個資料夾啟動 seine，或用 `--data-dir` 指定資料夾。 |
| 你的設定恢復成了自動 | 從你的啟動檔啟動 seine。`-` 和 `+` 鍵只在你關閉 seine 之前有效。 |

[參數參考](https://github.com/zpalmtree/seine/blob/master/docs/MINER_FLAGS.md)列出了每一項設定。
