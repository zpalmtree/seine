seine는 아무 설정 없이도 잘 작동합니다. 이 가이드는 바꾸고 싶을 가능성이 가장 높은 항목을 다룹니다. CPU나 GPU 채굴 끄기, 더 적은 스레드 사용, 그래픽 카드 선택, 주소나 풀 변경입니다.

## seine 설정은 어떻게 바꿉니까?

<Answer>
seine를 닫고, 해당 폴더에서 터미널을 열고, 설정을 명령에 추가해 다시 시작하세요. 예: `./seine --threads 4`. Windows에서는 PowerShell을 사용하고 `.\seine.exe --threads 4`를 입력하세요. seine는 저장된 주소와 풀을 유지하므로 바꾸려는 항목만 입력하면 됩니다.
</Answer>

- **Windows:** 파일 탐색기에서 seine 폴더를 열고, 주소 표시줄에 `powershell`을 입력한 뒤 Enter를 누릅니다.
- **macOS와 Linux:** 터미널을 열고 `cd`로 seine 폴더로 이동합니다.

아래 예시는 `./seine`을 사용합니다. Windows에서는 대신 `.\seine.exe`를 입력하세요.

## CPU나 GPU 채굴은 어떻게 끕니까?

seine는 기본적으로 CPU와 지원되는 모든 그래픽 카드로 채굴합니다. `--backend` 설정으로 사용할 대상을 고릅니다.

| 원하는 설정 | 추가할 내용 |
|---|---|
| CPU만 사용, GPU 끔 | `--backend cpu` |
| NVIDIA GPU만 사용, CPU 끔 | `--backend nvidia` |
| AMD GPU만 사용, CPU 끔 | `--backend amd` |
| NVIDIA와 AMD GPU 사용, CPU 끔 | `--backend nvidia,amd` |

예를 들어 NVIDIA 카드로 채굴하고 CPU를 비워 두려면 다음과 같이 합니다.

```sh
./seine --backend nvidia
```

[대시보드](/ko/blog/seine-dashboard-explained/)의 Devices 패널에는 채굴 중인 장치마다 한 줄이 표시됩니다.

## CPU 스레드를 더 적게 쓰려면 어떻게 합니까?

원하는 숫자와 함께 `--threads`를 추가하세요.

```sh
./seine --threads 4
```

스레드 하나는 약 2 GB의 RAM을 사용하므로, 스레드 4개는 약 8 GB를 사용합니다. seine는 설정을 지울 때까지 그 숫자를 유지합니다.

알맞은 숫자를 찾으려면 seine를 평소처럼 시작하고 대시보드에서 `-`를 눌러 스레드를 하나 줄이거나 `+`를 눌러 하나 늘리세요. 변경에는 잠시 시간이 걸리며, 대시보드에 새 개수가 표시됩니다. 컴퓨터가 알맞게 느껴질 때 멈추고 그 숫자를 `--threads`에 사용하세요. 키 입력은 seine를 닫을 때까지만 유지되기 때문입니다.

seine가 더 가벼운 스레드 수를 직접 고르게 하려면 대신 다음을 사용하세요.

```sh
./seine --cpu-profile efficiency
```

컴퓨터를 사용하면서 채굴하는 방법은 [데스크톱 가이드](/ko/blog/mine-while-using-pc/)에서 더 자세히 다룹니다.

## 그래픽 카드 하나만 고르려면 어떻게 합니까?

카드 번호를 추가하세요. 첫 번째 카드는 `0`입니다.

```sh
./seine --backend cpu,nvidia --nvidia-devices 0
```

이렇게 하면 CPU와 첫 번째 NVIDIA 카드로 채굴합니다. 카드 두 장은 `--nvidia-devices 0,1`을 사용하고, CPU를 끄려면 `cpu,`를 뺍니다. AMD 카드도 같은 방식으로 설정합니다.

```sh
./seine --backend cpu,amd --amd-devices 0
```

다른 앱을 위해 비디오 메모리를 남기려면 `--nvidia-max-lanes 2` 또는 `--amd-max-lanes 2`를 사용하세요. 레인 하나는 약 2 GB의 비디오 메모리를 사용합니다. 내장 Radeon 그래픽은 직접 `--backend amd`를 추가하지 않으면 꺼진 상태로 유지됩니다.

## 매번 시작할 때 설정을 유지하려면 어떻게 합니까?

seine는 주소, 풀, 워커 이름을 자동으로 저장합니다. `--threads`나 `--backend` 같은 설정은 그 실행에서만 적용되므로, 작은 시작 파일에 넣고 seine 대신 그 파일을 실행하세요.

Windows에서는 메모장을 열어 다음 줄을 자신의 설정으로 입력하고, seine 폴더에 `start-mining.bat`으로 저장하세요. 이때 **파일 형식**은 **모든 파일**로 설정합니다.

```bat
seine.exe --backend cpu --threads 4
pause
```

`start-mining.bat`을 더블클릭하면 채굴이 시작됩니다. `pause` 줄은 seine가 멈춰도 창을 열어 두어 마지막 메시지를 읽을 수 있게 해 줍니다.

macOS나 Linux에서는 다음 줄을 seine 폴더에 `start-mining.sh`로 저장하세요.

```sh
#!/bin/sh
cd "$(dirname "$0")"
./seine --backend cpu --threads 4
```

`chmod +x start-mining.sh`를 한 번 실행한 다음 `./start-mining.sh`로 채굴을 시작하세요. 자동 업데이트는 같은 설정으로 seine를 다시 시작합니다. Windows에 로그인할 때마다 채굴을 시작하려면 [자동 시작 가이드](/ko/blog/start-miner-automatically-windows/)를 따르세요.

## 주소, 풀, 워커 이름은 어떻게 바꿉니까?

seine를 닫고 텍스트 편집기에서 `seine-data/seine.config.json`을 여세요. 이 폴더는 seine를 시작하는 폴더 안에 있습니다. 필요한 값을 바꾸고 파일을 저장하세요.

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

나머지 줄은 그대로 두세요. 따옴표와 쉼표는 유지하고, 이 파일에 복구 문구나 개인 키를 넣지 마세요.

한 번만 다른 값을 쓰려면 명령에 추가하세요. 저장된 파일은 그대로 유지됩니다.

```sh
./seine --pool-worker desktop-02
```

나머지 두 설정은 `--address`와 `--pool-url`입니다. 주소를 바꾼 뒤 풀이 작업을 어떻게 반영하는지는 [주소 변경 가이드](https://bntpool.com/blog/ko/change-mining-wallet-address/)에서 설명합니다.

bntpool.com에서 솔로 채굴하려면 주소 앞에 `solo:`를 붙이세요. 예를 들어 파일에서는 `"address": "solo:@yourname"`, 명령줄에서는 `--address solo:YOUR_ADDRESS`입니다. 그러면 풀이 장비가 찾은 모든 블록의 전체 보상을 지급합니다. 솔로 블록의 지급 방식은 [bntpool.com에서 솔로 채굴하기](https://bntpool.com/blog/ko/solo-mine-blocknet-on-bntpool/)에서 설명합니다.

## 설정이 작동하지 않으면 어떻게 합니까?

| 보이는 내용 | 할 일 |
|---|---|
| `--nvidia-devices requires selecting nvidia in --backend` | backend에 `nvidia`를 추가하세요: `--backend cpu,nvidia`. `amd`도 마찬가지입니다. |
| `configured CPU lanes need` 더 많은 RAM | `--threads`에 더 작은 숫자를 사용하세요. 여유 RAM 2 GB마다 스레드 하나 정도가 알맞습니다. |
| `all GPU backends failed to start` | 카드의 최신 드라이버를 설치하세요. [AMD 가이드](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md)에 Linux에서 AMD 카드에 필요한 내용이 정리되어 있습니다. |
| seine가 주소를 다시 물어봅니다 | 이전과 같은 폴더에서 seine를 시작하거나 `--data-dir`로 폴더를 지정하세요. |
| 설정이 자동으로 돌아갔습니다 | 시작 파일로 seine를 시작하세요. `-`와 `+` 키는 seine를 닫을 때까지만 유지됩니다. |

모든 설정은 [플래그 참조](https://github.com/zpalmtree/seine/blob/master/docs/MINER_FLAGS.md)에 나와 있습니다.
