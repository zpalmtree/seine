O seine funciona bem sem nenhuma configuração. Este guia cobre as mudanças que você mais provavelmente vai querer: desligar a mineração por CPU ou GPU, usar menos threads, escolher uma placa de vídeo e trocar seu endereço ou pool.

## Como alterar uma configuração do seine?

<Answer>
Feche o seine, abra um terminal na pasta dele e inicie-o de novo com a configuração adicionada ao comando, por exemplo `./seine --threads 4`. No Windows, use o PowerShell e `.\seine.exe --threads 4`. O seine mantém seu endereço e pool salvos, então você digita só o que quer mudar.
</Answer>

- **Windows:** abra a pasta do seine no Explorador de Arquivos, digite `powershell` na barra de endereços e pressione Enter.
- **macOS e Linux:** abra o Terminal e vá até a pasta do seine com `cd`.

Os exemplos abaixo usam `./seine`. No Windows, digite `.\seine.exe` no lugar.

## Como desligar a mineração por CPU ou GPU?

Por padrão, o seine minera na sua CPU e em todas as placas de vídeo compatíveis. A configuração `--backend` escolhe quais usar:

| O que você quer | Adicione isto |
|---|---|
| Só CPU, GPU desligada | `--backend cpu` |
| Só GPU NVIDIA, CPU desligada | `--backend nvidia` |
| Só GPU AMD, CPU desligada | `--backend amd` |
| GPUs NVIDIA e AMD, CPU desligada | `--backend nvidia,amd` |

Por exemplo, para minerar em uma placa NVIDIA e deixar a CPU livre:

```sh
./seine --backend nvidia
```

O painel Devices do [painel do seine](/pt-br/blog/seine-dashboard-explained/) mostra uma linha para cada dispositivo que está minerando.

## Como usar menos threads de CPU?

Adicione `--threads` com o número que você quer:

```sh
./seine --threads 4
```

Cada thread usa cerca de 2 GB de RAM, então 4 threads usam cerca de 8 GB. O seine fica nesse número até você remover a configuração.

Para achar um bom número, inicie o seine normalmente e pressione `-` no painel para remover uma thread, ou `+` para adicionar uma. A mudança leva um instante e o painel mostra a nova contagem. Pare quando o computador ficar confortável e use esse número com `--threads`, porque as teclas só valem até você fechar o seine.

Para deixar o seine escolher sozinho uma quantidade menor de threads, use isto:

```sh
./seine --cpu-profile efficiency
```

O [guia para desktop](/pt-br/blog/mine-while-using-pc/) explica mais sobre minerar enquanto você usa o computador.

## Como escolher uma só placa de vídeo?

Adicione o número da placa. A primeira placa é a `0`:

```sh
./seine --backend cpu,nvidia --nvidia-devices 0
```

Isso minera na CPU e na primeira placa NVIDIA. Use `--nvidia-devices 0,1` para duas placas e tire `cpu,` para desligar a CPU. As placas AMD funcionam do mesmo jeito:

```sh
./seine --backend cpu,amd --amd-devices 0
```

Para deixar memória de vídeo livre para outros aplicativos, use `--nvidia-max-lanes 2` ou `--amd-max-lanes 2`. Cada lane usa cerca de 2 GB de memória de vídeo. Os gráficos Radeon integrados ficam desligados, a menos que você mesmo adicione `--backend amd`.

## Como manter suas configurações a cada início?

O seine salva sozinho seu endereço, pool e nome do worker. Configurações como `--threads` e `--backend` valem só para aquela execução, então coloque-as em um pequeno arquivo de inicialização e abra esse arquivo em vez do seine.

No Windows, abra o Bloco de Notas, digite estas linhas com as suas configurações e salve o arquivo na pasta do seine como `start-mining.bat`, com **Salvar como tipo** definido como **Todos os arquivos**:

```bat
seine.exe --backend cpu --threads 4
pause
```

Dê dois cliques em `start-mining.bat` para começar a minerar. A linha `pause` mantém a janela aberta se o seine parar, para você ler a última mensagem.

No macOS ou Linux, salve estas linhas na pasta do seine como `start-mining.sh`:

```sh
#!/bin/sh
cd "$(dirname "$0")"
./seine --backend cpu --threads 4
```

Execute `chmod +x start-mining.sh` uma vez e depois comece a minerar com `./start-mining.sh`. As atualizações automáticas reiniciam o seine com as mesmas configurações. Para começar a minerar sempre que você entrar no Windows, siga o [guia de início automático](/pt-br/blog/start-miner-automatically-windows/).

## Como trocar seu endereço, pool ou nome do worker?

Feche o seine e abra `seine-data/seine.config.json` em um editor de texto. A pasta fica dentro da pasta de onde você inicia o seine. Mude o valor que precisa e salve o arquivo:

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

Deixe as outras linhas como estão. Mantenha as aspas e as vírgulas, e não coloque sua frase de recuperação nem chaves privadas neste arquivo.

Para usar um valor diferente em uma única execução, adicione-o ao comando. O arquivo salvo continua igual:

```sh
./seine --pool-worker desktop-02
```

As outras duas configurações são `--address` e `--pool-url`. O [guia para trocar o endereço](https://bntpool.com/blog/pt-br/change-mining-wallet-address/) explica como o pool credita seu trabalho depois que você troca de endereço.

## E se uma configuração não funcionar?

| O que você vê | O que fazer |
|---|---|
| `--nvidia-devices requires selecting nvidia in --backend` | Adicione `nvidia` ao backend: `--backend cpu,nvidia`. O mesmo vale para `amd`. |
| `configured CPU lanes need` mais RAM | Use um número menor em `--threads`, cerca de uma thread para cada 2 GB de RAM livre. |
| `all GPU backends failed to start` | Instale o driver atual da sua placa. O [guia da AMD](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md) lista o que as placas AMD precisam no Linux. |
| O seine pede seu endereço de novo | Inicie o seine da mesma pasta de antes, ou defina a pasta com `--data-dir`. |
| Suas configurações voltaram ao automático | Inicie o seine pelo seu arquivo de inicialização. As teclas `-` e `+` valem só até você fechar o seine. |

A [referência de opções](https://github.com/zpalmtree/seine/blob/master/docs/MINER_FLAGS.md) lista todas as configurações.
