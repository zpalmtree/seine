seine ทำงานได้ดีโดยไม่ต้องตั้งค่าใดๆ คู่มือนี้ครอบคลุมการเปลี่ยนแปลงที่คุณน่าจะต้องการมากที่สุด ได้แก่ ปิดการขุดด้วย CPU หรือ GPU ใช้เธรดให้น้อยลง เลือกการ์ดจอ และเปลี่ยนที่อยู่หรือพูลของคุณ

## เปลี่ยนการตั้งค่าของ seine ได้อย่างไร?

<Answer>
ปิด seine เปิดเทอร์มินัลในโฟลเดอร์ของ seine แล้วเริ่มใหม่โดยเพิ่มการตั้งค่าต่อท้ายคำสั่ง เช่น `./seine --threads 4` บน Windows ให้ใช้ PowerShell และพิมพ์ `.\seine.exe --threads 4` seine จำที่อยู่และพูลที่บันทึกไว้ คุณจึงพิมพ์เฉพาะสิ่งที่ต้องการเปลี่ยน
</Answer>

- **Windows:** เปิดโฟลเดอร์ seine ใน File Explorer พิมพ์ `powershell` ในแถบที่อยู่ แล้วกด Enter
- **macOS และ Linux:** เปิด Terminal แล้วใช้ `cd` ไปยังโฟลเดอร์ seine

ตัวอย่างด้านล่างใช้ `./seine` บน Windows ให้พิมพ์ `.\seine.exe` แทน

## ปิดการขุดด้วย CPU หรือ GPU ได้อย่างไร?

โดยค่าเริ่มต้น seine ขุดด้วย CPU และการ์ดจอที่รองรับทุกใบ ตัวเลือก `--backend` ใช้เลือกว่าจะใช้อะไร:

| สิ่งที่คุณต้องการ | เพิ่มสิ่งนี้ |
|---|---|
| ใช้เฉพาะ CPU ปิด GPU | `--backend cpu` |
| ใช้เฉพาะ GPU NVIDIA ปิด CPU | `--backend nvidia` |
| ใช้เฉพาะ GPU AMD ปิด CPU | `--backend amd` |
| ใช้ GPU NVIDIA และ AMD ปิด CPU | `--backend nvidia,amd` |

ตัวอย่างเช่น หากต้องการขุดด้วยการ์ด NVIDIA และปล่อย CPU ให้ว่าง:

```sh
./seine --backend nvidia
```

แผง Devices ใน[แดชบอร์ด](/th/blog/seine-dashboard-explained/)แสดงหนึ่งแถวสำหรับแต่ละอุปกรณ์ที่กำลังขุด

## ใช้เธรด CPU ให้น้อยลงได้อย่างไร?

เพิ่ม `--threads` พร้อมตัวเลขที่ต้องการ:

```sh
./seine --threads 4
```

แต่ละเธรดใช้ RAM ประมาณ 2 GB ดังนั้น 4 เธรดใช้ประมาณ 8 GB seine จะใช้ตัวเลขนั้นไปจนกว่าคุณจะเอาการตั้งค่าออก

หากต้องการหาตัวเลขที่เหมาะสม ให้เริ่ม seine ตามปกติ แล้วกด `-` ในแดชบอร์ดเพื่อลดหนึ่งเธรด หรือกด `+` เพื่อเพิ่มหนึ่งเธรด การเปลี่ยนแปลงใช้เวลาสักครู่ และแดชบอร์ดจะแสดงจำนวนใหม่ หยุดเมื่อคอมพิวเตอร์ใช้งานได้สบาย แล้วใช้ตัวเลขนั้นกับ `--threads` เพราะปุ่มเหล่านี้มีผลเพียงจนกว่าคุณจะปิด seine

หากต้องการให้ seine เลือกจำนวนเธรดที่เบาลงเอง ให้ใช้คำสั่งนี้แทน:

```sh
./seine --cpu-profile efficiency
```

[คู่มือเดสก์ท็อป](/th/blog/mine-while-using-pc/)มีรายละเอียดเพิ่มเติมเกี่ยวกับการขุดขณะที่คุณใช้คอมพิวเตอร์

## เลือกการ์ดจอใบเดียวได้อย่างไร?

เพิ่มหมายเลขของการ์ด การ์ดใบแรกคือ `0`:

```sh
./seine --backend cpu,nvidia --nvidia-devices 0
```

คำสั่งนี้ขุดด้วย CPU และการ์ด NVIDIA ใบแรก ใช้ `--nvidia-devices 0,1` สำหรับสองใบ และตัด `cpu,` ออกเพื่อปิด CPU การ์ด AMD ใช้วิธีเดียวกัน:

```sh
./seine --backend cpu,amd --amd-devices 0
```

หากต้องการเหลือหน่วยความจำวิดีโอไว้ให้แอปอื่น ให้ใช้ `--nvidia-max-lanes 2` หรือ `--amd-max-lanes 2` แต่ละ lane ใช้หน่วยความจำวิดีโอประมาณ 2 GB กราฟิก Radeon ในตัวจะปิดอยู่ เว้นแต่คุณจะเพิ่ม `--backend amd` เอง

## เก็บการตั้งค่าไว้ทุกครั้งที่เริ่มได้อย่างไร?

seine บันทึกที่อยู่ พูล และชื่อ worker ของคุณเอง การตั้งค่าอย่าง `--threads` และ `--backend` มีผลเฉพาะการรันครั้งนั้น ดังนั้นให้ใส่ไว้ในไฟล์เริ่มต้นขนาดเล็ก แล้วเปิดไฟล์นั้นแทนการเปิด seine

บน Windows ให้เปิด Notepad พิมพ์บรรทัดเหล่านี้พร้อมการตั้งค่าของคุณ แล้วบันทึกไฟล์ในโฟลเดอร์ seine ชื่อ `start-mining.bat` โดยตั้ง **บันทึกเป็นชนิด** เป็น **ไฟล์ทั้งหมด**:

```bat
seine.exe --backend cpu --threads 4
pause
```

ดับเบิลคลิก `start-mining.bat` เพื่อเริ่มขุด บรรทัด `pause` จะเปิดหน้าต่างค้างไว้หาก seine หยุด คุณจึงอ่านข้อความสุดท้ายได้

บน macOS หรือ Linux ให้บันทึกบรรทัดเหล่านี้ในโฟลเดอร์ seine ชื่อ `start-mining.sh`:

```sh
#!/bin/sh
cd "$(dirname "$0")"
./seine --backend cpu --threads 4
```

รัน `chmod +x start-mining.sh` เพียงครั้งเดียว แล้วเริ่มขุดด้วย `./start-mining.sh` การอัปเดตอัตโนมัติจะรีสตาร์ต seine ด้วยการตั้งค่าเดิม หากต้องการเริ่มขุดทุกครั้งที่ลงชื่อเข้าใช้ Windows ให้ทำตาม[คู่มือเริ่มอัตโนมัติ](/th/blog/start-miner-automatically-windows/)

## เปลี่ยนที่อยู่ พูล หรือชื่อ worker ได้อย่างไร?

ปิด seine แล้วเปิด `seine-data/seine.config.json` ในโปรแกรมแก้ไขข้อความ โฟลเดอร์นี้อยู่ภายในโฟลเดอร์ที่คุณเริ่ม seine เปลี่ยนค่าที่ต้องการแล้วบันทึกไฟล์:

```json
{
  "schema_version": 1,
  "mode": "pool",
  "address": "@yourname",
  "pool_url": "stratum+tcp://bntpool.com:3333",
  "pool_worker": "desktop-01"
}
```

ปล่อยบรรทัดอื่นไว้ตามเดิม เก็บเครื่องหมายคำพูดและจุลภาคไว้ และอย่าเพิ่มวลีกู้คืนหรือคีย์ส่วนตัวลงในไฟล์นี้

หากต้องการใช้ค่าอื่นเพียงครั้งเดียว ให้เพิ่มลงในคำสั่ง ไฟล์ที่บันทึกไว้จะไม่เปลี่ยน:

```sh
./seine --pool-worker desktop-02
```

อีกสองการตั้งค่าคือ `--address` และ `--pool-url` [คู่มือเปลี่ยนที่อยู่](https://bntpool.com/blog/th/change-mining-wallet-address/)อธิบายว่าพูลนับงานของคุณอย่างไรหลังเปลี่ยนที่อยู่

หากต้องการขุดเดี่ยวบน bntpool.com ให้ใส่ `solo:` หน้าที่อยู่ เช่น `"address": "solo:@yourname"` ในไฟล์ หรือ `--address solo:YOUR_ADDRESS` ในบรรทัดคำสั่ง จากนั้นพูลจะจ่ายรางวัลเต็มของทุกบล็อกที่เครื่องขุดของคุณพบ [การขุดเดี่ยวบน bntpool.com](https://bntpool.com/blog/th/solo-mine-blocknet-on-bntpool/)อธิบายวิธีจ่ายบล็อกขุดเดี่ยว

## ถ้าการตั้งค่าไม่ทำงานควรทำอย่างไร?

| สิ่งที่คุณเห็น | สิ่งที่ควรทำ |
|---|---|
| `--nvidia-devices requires selecting nvidia in --backend` | เพิ่ม `nvidia` ใน backend: `--backend cpu,nvidia` เช่นเดียวกับ `amd` |
| `configured CPU lanes need` RAM มากขึ้น | ใช้ตัวเลขที่ต่ำลงกับ `--threads` ประมาณหนึ่งเธรดต่อ RAM ว่างทุก 2 GB |
| `all GPU backends failed to start` | ติดตั้งไดรเวอร์ล่าสุดของการ์ด [คู่มือ AMD](https://github.com/zpalmtree/seine/blob/master/docs/guides/amd.md)ระบุสิ่งที่การ์ด AMD ต้องใช้บน Linux |
| seine ถามที่อยู่ของคุณอีกครั้ง | เริ่ม seine จากโฟลเดอร์เดิม หรือกำหนดโฟลเดอร์ด้วย `--data-dir` |
| การตั้งค่ากลับเป็นอัตโนมัติ | เริ่ม seine จากไฟล์เริ่มต้นของคุณ ปุ่ม `-` และ `+` มีผลเพียงจนกว่าคุณจะปิด seine |

[เอกสารอ้างอิงแฟล็ก](https://github.com/zpalmtree/seine/blob/master/docs/MINER_FLAGS.md)แสดงการตั้งค่าทั้งหมด
